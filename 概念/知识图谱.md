# 知识图谱

## 一句话定义
知识图谱是**概念网络的可视化形式**，通过节点和边展示概念之间的关系，帮助发现隐藏的知识关联。

## 核心属性
- **可视化**: 图形化展示概念关系
- **节点**: 概念笔记作为图谱节点
- **边**: 双向链接作为图谱边
- **中心性**: 可识别中心节点
- **社区**: 可发现概念集群

## 图谱类型
- **本地图谱**: 单个笔记的关联网络
- **全局图谱**: 整个知识库的网络
- **过滤图谱**: 按标签或路径过滤的子网络
- **时序图谱**: 按时间演化的网络

## 工作流位置
```
原子化笔记 → 双向链接 → 图谱构建 → 中心识别 → 社区发现
```

## 我的思考
- 知识图谱是概念网络的**可视化窗口**

- 中心节点是知识网络的**关键枢纽**
