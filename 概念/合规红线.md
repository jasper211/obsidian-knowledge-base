# 合规红线

## 一句话定义
合规红线是 RW 权益系统的**架构级约束**，确保系统不触《保险业条例》s.64G 受规管活动，不是靠培训约束，是靠系统里"没有那个功能"。

## 核心约束
- **不存保费金额**: 保单镜像只存派生标志
- **不存佣金**: 佣金数据不在 RW 系统
- **不存条款文本**: 条款内容不在 RW 系统
- **转介触发词**: 管家勾选触发词 → 系统生成转办工单
- **不设实质讨论**: RW 侧仅记录"何时/何事由/转给谁"，不设实质讨论内容字段

## 我的思考
- 合规红线是 RW 权益系统的**首要约束**
- 合规不是靠培训，是靠架构
- 合规红线需内建到系统，不可只靠培训
- 合规红线是项目的重要交付物
