# MVP

## 一句话定义
MVP 是 RW 权益项目的**最小可行产品**，P0 从 TOB/TOI 启动，TOC 后置，聚焦权益资产治理、TOB/TOI 运营规范化和价值证明。

## MVP 范围
- **A. 权益资产治理**: 权益目录、SKU 字段、定价、成本、毛利、合同主体、P&L 分类、权益台账
- **B. TOB 机构运营规范化**: 服务上架、合同附件、验收标准、RACI、结算/交付证据
- **C. TOI 保司价值证明**: 权益激活、服务完成、合规渠道、留存/续保触点、季度复盘报告
- **TOC 后置**: 客户话术、GL25 评估、授权、第三方准入、交付留痕模板，不做正式客户交付
