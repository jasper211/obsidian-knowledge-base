# AI 工程能力整改项目

## 一句话定义
AI 工程能力整改项目是 `Jasper AI协同经验引擎` 的一轮历史性能力整改计划，用来解释当前 Agent 体系、验证标准与基础设施能力是如何被逐步搭起来的。

## 核心属性
- **历史整改载体**: 它描述的是一轮阶段化补能力计划，而不是当前 Jasper 经验层的唯一主入口
- **阶段推进框架**: 通过 `Phase 0-4` 拆解，从基础设施、Agent 产品化到系统化扩展逐步推进
- **能力建设导向**: 目标不是只补单点工具，而是形成可复用的 Agent 搭建、验证与协同方法
- **外显化逻辑**: 核心是把“内部验证”逐步变成“外部可见、可交付、可复用”的运行能力
- **防冒进机制**: 强调阶段回退、多轮验证与边界控制

## 四阶段规划
- **Phase 0**: 第 0 周 — 启动准备（GitHub repo、看板、决策日志、周报模板）
- **Phase 1**: 第 1-4 周 — 补齐硬缺口 + 推上线（Computer Use、前端 App、MCP Server）
- **Phase 2**: 第 5-8 周 — Agent 产品化（B-RPT Agent、模型选型矩阵、Skill 发布）
- **Phase 3**: 第 9-12 周 — 系统性与扩展性（AI 技术雷达、飞书集成、成本优化）
- **Phase 4**: 第 13-16 周 — 长期补足 + 作品集（Hermes 试用、技术文章、个人作品集网站）

## 11 个能力维度
- AI Coding 工具链、Agent/Skills 设计、大模型使用与边界
- 全流程独立交付、技术嗅觉、工程落地效率
- 内容行业经验、企业协作平台集成、Computer Use/Browser Use
- 大模型成本优化、CS/AI 专业背景
