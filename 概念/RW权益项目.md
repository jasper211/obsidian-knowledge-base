# RW 权益项目

## 一句话定义
RW 权益 Layer B 事业线建设项目，是以 RW 权益体系为底座，把权益资产做成可定价、可入账、可交付、可分发、可审计的事业线能力，并通过 RW 四对象权益运营平台承载客户交付、证据档案、事件工单、合规留痕和价值证明。

## 核心属性
- **Layer B 定位**: 权益资产定价、入账、P&L、供应链和四对象分发
- **四对象**: TOI（对保司）、TOB（对机构）、TOA（对理财师）、TOC（对客户）
- **MVP 阶段**: P0 从 TOB/TOI 启动，TOC 后置
- **合规红线**: 不触《保险业条例》s.64G 受规管活动
- **审计评分**: 8.2/10，具备 MVP 立项条件

## 工作流位置
```
项目立项 → 权益资产治理 → SKU Pipeline → 四对象分发 → 价值证明 → TOC 成熟度准备
```

## 我的思考
- RW 权益项目是从"客户权益交付系统"升级为"权益 Layer B 事业线"
- 四对象分类是核心运营框架
- 合规是架构设计的首要约束
- 权益资产治理是项目的基础
- PTA 可用于 RW 权益项目的任务协同
- AIT 可用于 RW 权益项目的 AI 转型咨询
