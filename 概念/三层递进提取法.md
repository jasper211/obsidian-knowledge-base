# 三层递进提取法

## 一句话定义
三层递进提取法是**从会议录音到 D1-D4 交付的标准化工作流**，通过 L3→L4→L5 的逐层穿透，确保信号基线提取的完整性和准确性。

## 三层定义
- **第一层**: 价值节点识别（从会议录音中提取价值节点）
- **第二层**: 流程步骤映射（将价值节点映射到 L4 步骤）
- **第三层**: 活动细节提取（提取 L5 活动细节和规则）

- [[信号基线]] — 价值节点清单 + 流程蓝图交叉验证
- [[访谈规则继承]] — 从业务方访谈中提取隐含规则
- [[Computer Use]] — 前端信息完整性扫描（仅限 workflow 原始文档）

```
会议录音 → 第一层（价值节点）→ 第二层（流程步骤）→ 第三层（活动细节）→ D1-D4 交付物
```

## 我的思考
- 三层递进提取法是**标准化工作流**
- 每层提取都有明确的输入和输出
- 三层递进提取法是 Agent 自动化的关键场景
- 三层递进提取法需持续迭代和优化
