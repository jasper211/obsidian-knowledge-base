# PTA（项目任务协同 Agent）

## 一句话定义
PTA 是**项目任务协同 Agent**，负责任意项目/任务的自然语言指令解析、执行调度、主动巡检、执行记录和归档文档生成，当前主参考版本以 `三大主Agent体系架构_v1.4` 与 PTA 现行 README 为准。

## 核心属性
- **服务对象**: 任意项目/任务
- **核心问题**: "这个任务怎么做？"
- **输入**: 自然语言指令
- **输出**: 执行记录 + 归档文档
- **当前状态**: 现行结构已升级到 01-12 骨架，含主动巡检与本地任务驾驶舱

## 当前结构特征
- **01-12 骨架**: 现行标准模板，不再是早期扁平 S01-S05 结构
- **双能力线**: 被动执行 + 主动巡检
- **工作区隔离**: PTA 状态与运行产物与目标项目物理隔离
- **跨项目适用**: 可用于 EA、RW、P&L 及其他项目的任务协同
