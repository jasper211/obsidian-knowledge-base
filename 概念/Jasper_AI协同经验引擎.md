# Jasper AI 协同经验引擎

## 一句话定义
Jasper AI 协同经验引擎是**从业务运营到 AI 工程能力跃迁的系统性能力塑造项目**，目标是对标一线 AI 工程岗位标准，把已有的 Agent/Skills/方法论设计能力，转化为可上线、可验证、可复用的工程资产。

## 核心属性
- **16 周周期**: Phase 0-4 分阶段补齐 11 个能力维度
- **差异化定位**: 懂业务、懂方法论的 AI 工程师
- **核心逻辑**: 把"内部验证"变成"外部可见"，把"设计文档"变成"运行服务"
- **项目结构**: AI工程能力整改项目 + Agent库 + 方法论资产
- **阶段回退**: 严格遵循阶段回退+多轮验证+防冒进

## 项目结构
- [[AI工程能力整改项目]] — 16 周能力整改主线
- [[Agent库]] — 五大主Agent体系（PTA/VNW/AIT/方法论转正/Obsidian巡检）
- [[方法论资产]] — L0-L16 协同方法论、Skills、SOP
- [[能力整改看板]] — 11 个维度实时跟踪
- [[决策日志]] — 关键决策记录

## 核心概念
- [[PTA]] — 项目任务协同 Agent
- [[VNW]] — 价值节点驱动工作流 Agent
- [[AIT]] — AI 协同转型咨询 Agent
- [[方法论转正Agent]] — 验证标准统一沉淀
- [[Obsidian巡检Agent]] — 知识库基础设施
- [[AI工程能力整改项目]] — 16 周整改主线

## 跨项目关联
- [[价值节点]] — VNW 的分析对象（流程架构项目）
- [[流程蓝图]] — VNW 的输入来源（流程架构项目）
- [[信号基线]] — VNW 的输出目标（流程架构项目）
- [[规则空白]] — VNW 的关键发现（流程架构项目）
- [[四对象]] — AIT 的咨询对象（RW 权益项目）
- [[权益资产]] — AIT 的咨询内容（RW 权益项目）
- [[MVP]] — AIT 的咨询目标（RW 权益项目）

## 工作流位置
```
业务运营 → AI 协同方法论 → Agent 产品化 → 工程资产 → 外部可见
```

## 我的思考
- Jasper AI 协同经验引擎是**能力跃迁的载体**
- 从"业务运营+AI协同方法论设计者"向"AI工程师"转型
- 核心是把方法论能力封装成可复用的 Agent 和 Skills
- 项目强调"实际会用"而非"更大更全"
- VNW 与流程架构项目紧密关联
- AIT 与 RW 权益项目紧密关联
