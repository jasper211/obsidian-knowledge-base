# 双向链接

## 一句话定义
双向链接是**笔记之间的双向引用机制**，通过 [[wikilink]] 实现，让笔记之间形成网络结构而非树状结构。

## 核心属性
- **双向性**: A 链接 B，B 自动链接 A
- **上下文性**: 链接保留上下文关系
- **发现性**: 通过反向链接发现关联
- **网络性**: 形成知识网络而非树状结构
- **动态性**: 随笔记增长自动扩展

## 实践方法
1. **主动链接**: 在笔记中主动引用相关概念
2. **反向查看**: 通过 backlinks 面板查看引用关系
3. **图谱探索**: 通过图谱可视化探索关联
4. **定期维护**: 检查断裂链接和孤立笔记

```
原子化笔记 → 双向链接 → 反向链接 → 图谱可视化 → 知识发现
```

## 我的思考
- 双向链接是知识网络的**基础设施**
- 双向链接让知识从树状变为网状
- 双向链接是 AI 推理的**关键路径**
- 双向链接需要定期维护，避免断裂
