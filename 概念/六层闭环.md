# 六层闭环

## 一句话定义
六层闭环是**价值节点驱动的流程治理体系**，从价值识别到 Agent 化部署，形成完整的价值流管理闭环。

## 六层定义
- **L1**: 价值流识别（VS-1、VS-4 等）
- **L2**: 价值阶段划分（S1-S6）
- **L3**: 端到端流程定义（L3-COM 等）
- **L4**: 流程步骤细化（COM-01 等）
- **L5**: 活动细节描述（核对佣金明细）
- **L6**: Agent 化部署（自动化执行）
