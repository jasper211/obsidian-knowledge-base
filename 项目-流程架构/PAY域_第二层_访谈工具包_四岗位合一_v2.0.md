### 双区使用说明

每条规则空白卡片包含两个区域：

| 区域 | 受众 | 语言风格 | 内容 |
|------|------|----------|------|
| **执行区** | Jasper / AI 协作者 | 技术语言，含元数据 | 空白子类、规则子类、L层归属、五问框架侧重、预期产出 |
| **沟通区** | 受访人 | 业务语言，无技术术语 | 业务情景问题 + 描述框（可导出Word） |

**使用流程**:
1. Jasper在访谈前阅读执行区，理解规则空白的技术背景和提问策略
2. 访谈时仅使用沟通区，以业务语言向受访人提问
3. 受访人在描述框中填写/口述业务规则
4. 访谈后Jasper将沟通区填充结果回填到执行区产出模板

## 沟通区格式说明

### 三种问题格式

| 格式 | 触发条件 | 结构 |
|------|----------|------|
| Format 1 | 工具空白 | Yes/No + 描述框 |
| Format 2 | 制度（标准）空白 | 选项 + 补充说明 + 描述框 |
| Format 3 | 流程空白 | 开放描述 + 描述框 |

### 四种描述框模板

| 规则子类 | 描述框关键字段 |
|----------|---------------|
| 数据结构规则 | 字段名称 / 填写规则 / 枚举值 / 校验方式 |
| 流程触发规则 | 触发条件 / 执行步骤 / 完成标准 / 责任人 |
| 计算推导规则 | 计算公式 / 输入参数 / 输出 / 例外场景 |
| 合规约束规则 | 约束条件 / 触发判断 / 例外处理 / 裁定责任人 |
