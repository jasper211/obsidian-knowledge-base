# 方案A：7族36岗 — 岗位族设计书

> **版本**: v1.0 | **日期**: 2026-04-30 | **基于**: T1数据底座(82 L3 / 400 L4) + HR组织架构V4校准  
> **核心策略**: 保持L1价值链主轴不变，通过岗位揭示族内功能分层

---

## 一、搭建逻辑

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **族≈岗位群** | 岗位族是能力聚类单元（非部门、非单一岗位），一个族含3-8个具体岗位 |
| **L1主轴+VS例外** | L3按L1价值链归属分族，VS-5拆分L1-05、VS-3独立为KA族 |
| **族名校准** | 以HR组织架构为现实依据修正族名，确保名实一致 |
| **岗位分层** | 每岗覆盖2-4个L3流程，Tier分Manager/Specialist/Analyst三层 |
| **零迁移** | 不移动L3归属，仅修正族名和描述，已入库数据零风险 |

### 1.2 三层关系

```
部门（管理维度）  → 谁向谁汇报       HR有14个二级部门
岗位族（能力维度）→ 做什么事、需什么能力  本方案7个族
岗位（执行维度）  → 具体谁来做、做什么   本方案36个岗位
```

- 1个族 对应1-3个HR二级部门
- 1个HR二级部门 可能横跨1-2个族
- 1个族 下含3-8个具体岗位
