# EA 业务能力 SSOT 确认请求 v1.0（BO-1.2 锚定源）

> **签发**: Mark　**承接**: Jasper（执行负责人）→ Terresa（流程/架构）　**日期**: 2026-06-13
> **用途**: IE 业务锚（洞察引擎的顶层业务主题）须从 EA **权威能力结构零自创投影**。核查发现 EA 现有 3 套与"能力"相关的结构、彼此未完全对齐，需 EA 确认哪套是 SSOT 后才能投影。

## 1. 背景（一句话）

IE 要把洞察归到"业务锚"下，业务锚必须 = EA 的业务能力域（不是从数据反推、也不是协调角色自创）。但 EA 目前有 3 套能力相关结构，投影前需确认权威源。

## 2. 查到的 3 套结构

| # | 结构 | 位置 | 内容 |
|---|---|---|---|
| A | **价值流（5）** | 03 权威数据 | 保司 / 机构 / KA / 理财师 / 企业客户（利益相关者旅程） |
| B | **L1 价值链（5）** | 03 权威数据 | 资源获取与产品整合 / 市场设计与合作伙伴发展 / 运营反馈与路由决策 / 能力赋能与增长驱动 / 价值增值与生态绑定 |
| C | **业务能力地图·一级业务能力（11）** | 01 原料 M-02/A3 | 资源解决方案设计 / 赋能方案设计与标准化 / 路由策略与决策制定 / 市场进入方案设计 / 合作伙伴能力评估 / 决策分发与效果评估 / 赋能实施与运营 / 市场洞察 / 数据分析与洞察 / 绩效监控与增长驱动 / 客户体验运营与管理 |

## 3. 未对齐的证据（为什么必须先确认）

- B（L1价值链）是"价值链阶段"视角，C（能力地图）是"业务能力"视角，两套**名称与切法都不同**，无现成映射。
- 价值节点数据里的 **L3-CFM 现金流规划与资金调度管理**（支撑 VN-BAM-01/CFM-01）在 **B 的 L1↔L3 映射里找不到对应簇**——说明 B 可能未覆盖全部 L3，或 C/价值节点比 B 更新。
- C 在 01 原料、颗粒不均（市场洞察/数据分析/绩效监控仅 2–4 行），是否现行权威版未知。

## 4. 请 EA 确认（回执项）

1. **哪套是"业务能力"的 SSOT**？A 价值流 / B L1价值链 / C 业务能力地图 —— 还是另有其一？
2. 三套的**派生关系**是什么（谁是谁的投影/上卷）？是否需要**先对齐**再供 IE 用？
3. C（业务能力地图 11 一级能力）是否**现行权威版**？若否，现行权威的能力清单在哪？
4. 若短期无法定 SSOT，能否指定一个**临时权威源**供 IE 先搭骨架（IE 会标 provisional）？

## 5. 完成定义（双端）

- **EA 端**: Terresa 回执指明 SSOT 结构（+ 必要的派生/对齐说明），经 Jasper 回 Mark/协调角色。
- **IE 端**: 协调角色据确认的 SSOT，从该结构**零自创投影**业务锚（重做 anchor_taxonomy v4），不再自行合成。
