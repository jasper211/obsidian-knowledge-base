## 你需要在会议前想好 3 件事

### 问题1（EP-001）：什么级别的市场洞察值得你亲自看？

**背景**：BD 团队每周会收到大量保司动态、竞品信息、市场数据。
目前所有信息都可能流到你这里，你需要亲自判断哪些重要。
**规则化目标**：定出分级标准，让 A 族帮你过滤，只有"战略级"才触达你。

**请你在会议前想好**：
- 过去哪 2~3 条市场洞察，让你改变了战略方向？（这些就是"战略级"的样本）
- 哪些信息你事后觉得"这个不用报给我，BD 自己决定就好"？
- 你心里是否有一个粗略的分级？（比如：保司高层变动 = 必报 / 某产品小调整 = 不用报）

**提示框架（供参考，你可以推翻）**：
```
战略级（必触达 Mark）：影响合作续约判断 / 影响整体市场定位 / 竞品重大动作
执行级（A族判断处理）：日常数据波动 / 常规保司动态
信息级（BD 自理）：产品细节更新 / 行政变化
```

---

### 问题2（EP-002）：你给永明的价值主张，包含什么？

**背景**：每家保司的价值主张，目前存在 Mark 脑中，没有标准化模板。
BD 新人上手时不知道"MGA 能给这家保司什么"，每次都要问你。
**规则化目标**：定出一个模板，BD 能独立填写，你来审核是否达标。

**请你在会议前回忆**：
- 我们给永明（SLHK）的价值主张是什么？（用 3 句话说清楚）
- 给天领（AXA/其他）的和永明有什么不同？
- 一份"好的"价值主张，你看完会点头的，它有哪几个要素？

**提示框架（供参考）**：
```
要素1：我们能替保司交付什么业务成果（APE 数字 / 渠道覆盖）
要素2：我们的独特资源（牌照 / 财富师网络 / 中台能力）
要素3：合作的边界和条件（独家 or 非独家 / 授权范围）
审核红线：哪些说法是不能出现在对外价值主张里的
```

---

### 问题3（EP-004）：面对竞品 MGA，你的标准应对是什么？

**背景**：市场上有其他 MGA 在抢同一批保司资源。
目前 BD 遇到竞品时，应对方式不统一，有时需要找你决策。
**规则化目标**：定出"竞品应对框架"，BD 遇到竞品时有标准动作可以执行。

**请你在会议前想好**：
- 过去我们赢过哪家竞品 MGA？赢在什么地方？
- 过去我们输过哪家竞品 MGA？输在哪里？
- 面对竞品时，有哪 3 个动作是你认为"必须做"的？

**提示框架（供参考）**：
```
应对动作1：快速评估竞品威胁等级（谁在谈 / 谈到什么阶段）
应对动作2：差异化强化（我们有、竞品没有的是什么）
应对动作3：升级触发条件（什么情况下你需要亲自介入）
```
