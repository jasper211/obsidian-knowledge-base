## 一、EP-001：洞察分级规则（草稿）

### 1.1 问题定义

Mark 当前是所有市场洞察的终审人。目标：定义分级规则后，只有 S 级和 A 级洞察到 Mark，B/C 级由 A 族 + BD 自行处理。

### 1.2 洞察分级框架（草稿）

| 级别 | 定义 | 示例场景（待 Mark 补充真实案例） | 处理方式 | 到达 Mark？ |
|:---:|------|------|------|:---:|
| **S 级** | 可能改变公司战略方向或商业模式的洞察 | 监管政策重大变化（如跨境 MGA 牌照新规）；头部保司战略转向（如永明退出某市场） | Mark 亲自评估 + 48h 内召开战略会 | **是** |
| **A 级** | 影响某条价值流年度目标达成的洞察 | 竞品 MGA 拿下某家独占协议；某保司佣金政策大幅调整；关键 KA 流失风险 | Mark 周报阅读 + 月度 Review 讨论 | **是**（周报） |
| **B 级** | 影响单个 L3 流程或单家保司关系的洞察 | 某保司产品条款调整；某区域市场活动效果反馈；BD 反馈的保司 RM 人事变动 | A 族判断 + 行动 → 月报汇总 | 否（月报可见） |
| **C 级** | 日常运营信息，无需决策 | 行业报告常规数据更新；保司例行通知；市场活动参与确认 | BD/运营自行处理 | 否 |

### 1.3 洞察分级判定规则（草稿）

判定一条洞察属于哪个级别，按以下 4 个维度打分（每维度 1~5 分）：

| 维度 | 说明 | 5 分 | 1 分 |
|------|------|------|------|
| **影响范围** | 影响几条价值流？ | 影响 3+ 条 VS | 仅影响单个活动 |
| **时间紧迫性** | 多久内需要响应？ | 48h 内必须响应 | 可排入季度计划 |
| **不可逆性** | 错过后损失是否可挽回？ | 不可逆（如牌照/独占） | 完全可逆 |
| **Mark 独有判断** | 是否只有 Mark 能做决策？ | 涉及战略方向/保司顶级关系 | 有规则可循，A 族可判 |

**分级阈值（草稿，待 Mark 校准）：**
- S 级：总分 ≥ 17 分，或"Mark 独有判断"维度 = 5 分
- A 级：总分 13~16 分
- B 级：总分 8~12 分
- C 级：总分 ≤ 7 分

### 1.4 洞察处理流程（草稿）

```
洞察来源（BD/保司RM/行业报告/Agent监控）
        │
        ▼
    A族初筛（4维度打分）
        │
        ├── S级 → 48h内报Mark + 召开战略会
        ├── A级 → 写入周报 + 月度Review讨论
        ├── B级 → A族自行处理 → 月报汇总
        └── C级 → BD/运营自行处理
```

### 1.5 需要 Mark 会上裁定的问题

1. **4 个维度是否完整？** 是否有其他维度 Mark 认为重要？
2. **分级阈值是否合理？** 特别是 S 级的门槛
3. **请举 2~3 个真实案例** 分别对应 S/A/B 级，校准打分标准
4. **"Mark 独有判断"这个维度是否一票否决？** 即只要这项 = 5，无论总分多少都是 S 级？

## 二、EP-002：价值主张模板 + 审核标准（草稿）

### 2.1 问题定义

每家保司合作前需要一份"我们为你带来什么价值"的主张文档。当前由 Mark 逐家定制。目标：标准化模板 + 审核标准，A 族/BD 起草，Mark 只审核 S/A 级保司的最终版。

### 2.2 价值主张模板（草稿）

基于知识库 OP-VP 框架和 MGA 核心价值定义（"替保司运营半个业务"），每家保司的价值主张应包含以下 7 个模块：

| 模块 | 内容 | 必填？ | 说明 |
|:---:|------|:---:|------|
| **1. 保司画像** | 保司名称、Tier 级别、主力产品线、年度 APE 目标 | 是 | 背景信息 |
| **2. 痛点诊断** | 该保司在香港市场面临的 Top 3 痛点 | 是 | 为什么需要 MGA |
| **3. MGA 价值承诺** | 我们为这家保司具体做什么（从 3 项授权出发：分销/创新/渠道管理） | 是 | 核心部分 |
| **4. 差异化要素** | 与其他 MGA/渠道相比，我们的独特优势 | 是 | 为什么选我们不选别人 |
| **5. 资源投入计划** | 我们将投入的人力、技术、渠道资源 | 是 | 量化承诺 |
| **6. 预期收益** | 该保司通过合作预期获得的量化收益（APE 增长/渠道覆盖/客户触达等） | 是 | ROI 预期 |
| **7. 合作路径** | 从签约到全面运营的分阶段路径（通常 3~6 个月） | 是 | 时间线 |

### 2.3 审核标准（草稿）

| 审核维度 | 通过标准 | 否决条件 |
|------|------|------|
| **痛点真实性** | 痛点来自保司 RM 访谈或市场数据，非 BD 臆测 | 无数据支撑的痛点 |
| **价值承诺可交付** | 承诺的每项都有对应 L3 流程和岗位支撑 | 承诺了公司目前做不到的能力 |
| **差异化真实** | 差异化要素有事实依据（如独占协议/技术能力/渠道覆盖数据） | "我们更专业"等空话 |
| **资源可行** | 投入计划在当前编制和预算范围内 | 需要额外招人或超预算但未审批 |
| **收益合理** | 预期收益基于历史数据或行业基准，非虚高 | APE 预测偏离基准 > 50% |

### 2.4 审核分级（草稿）

| 保司 Tier | 起草人 | 审核人 | Mark 参与？ |
|:---:|:---:|:---:|:---:|
| Tier 1（如永明） | A 族 + BD | Mark 终审 | **是 — 亲自审** |
| Tier 2 | BD 起草 | A 族审核 | 仅看终稿摘要 |
| Tier 3 | BD 起草 | A 族审核 | 否 |

### 2.5 需要 Mark 会上裁定的问题

1. **7 个模块是否完整？** 是否有 Mark 认为必须加的模块？
2. **"替保司运营半个业务"这句话在模板中怎么具体化？** 希望 Mark 用永明的案例讲解
3. **审核分级是否合理？** Tier 1 Mark 亲自审，Tier 2/3 授权 A 族，是否可以？
4. **否决条件是否太严或太松？**

## 三、EP-004：竞争策略框架 + 获客手册框架（草稿）

### 3.1 问题定义

面对竞品 MGA 排挤时，当前由 Mark 临场决策应对。目标：标准化应对框架，A 族/BD 按框架执行标准动作，仅升级到 Mark 处理的情况需规则化。

### 3.2 竞争态势分类（草稿）

基于知识库 OP-CA 竞争策略框架，将竞争态势分为 4 类：

| 态势 | 定义 | 典型场景 | 响应级别 |
|:---:|------|------|:---:|
| **红色** | 竞品正在抢夺我方核心保司/KA | 竞品 MGA 向永明提交独占提案；竞品挖角我方 Top 理财师 | Mark 直接介入 |
| **橙色** | 竞品在我方目标市场发力 | 竞品拿下新保司授权；竞品推出低佣金策略 | A 族牵头 + 报 Mark |
| **黄色** | 竞品常规市场动作 | 竞品参加行业峰会；竞品发布新产品 | BD 监控 + A 族周报 |
| **绿色** | 无直接竞争威胁 | 市场平稳；竞品无新动作 | 常规监控 |

### 3.3 标配应对动作矩阵（草稿）

| 态势 | 动作 1 | 动作 2 | 动作 3 | 升级 Mark？ |
|:---:|------|------|------|:---:|
| **红色** | 48h 内启动保司关系加固（A族联系保司高层） | 72h 内出竞争分析报告（BD 提供数据） | 1 周内提交反制方案给 Mark | **是** |
| **橙色** | 1 周内完成竞品动作分析 | 2 周内调整该市场/保司的价值主张 | 月度 Review 汇报 | 周报 |
| **黄色** | 记录竞品动态到知识库 | 季度竞争分析中纳入 | — | 否 |
| **绿色** | 日常监控 | — | — | 否 |

### 3.4 获客手册框架（草稿）

获客手册 = 面对竞争时"怎么赢客户"的标准打法。基于 OP-CA 框架：

**第一章：客户优先级**
| 优先级 | 定义 | 策略 |
|:---:|------|------|
| P0 灯塔客户 | 行业标杆，拿下后有示范效应 | 定制方案 + Mark 参与 |
| P1 高潜客户 | APE 贡献大，合作意愿明确 | 标准方案 + A 族主导 |
| P2 培育客户 | 有潜力但需培育 | 轻量接触 + BD 跟进 |
| P3 观望客户 | 当前无明确需求 | 品牌触达 + 等待时机 |

**第二章：标准获客流程**
```
阶段 1：识别（BD）
  └─ 目标客户清单 + 初步画像 + 竞品分析

阶段 2：接触（BD + A族）
  └─ 首次接触话术 + 价值主张传递 + 需求初诊

阶段 3：深化（A族主导）
  └─ 深度需求诊断 + 定制方案设计 + 资源展示

阶段 4：谈判（A族 + Mark介入Tier1）
  └─ 商务条款谈判 + 合同框架 + 让步边界（EP-063）

阶段 5：签约启动（A族 + 交付团队）
  └─ 合同签署 + 资源对接 + 运营启动
```

**第三章：竞品 MGA 应对话术（框架，待 Mark 填充）**

| 场景 | 竞品话术（常见） | 我方应对话术（待 Mark 定） |
|------|------|------|
| "我们佣金更高" | 竞品用高佣金吸引 | [待 Mark 裁定] |
| "我们有独占" | 竞品宣称独占协议 | [待 Mark 裁定] |
| "我们技术更强" | 竞品展示系统能力 | [待 Mark 裁定] |
| "我们牌照更全" | 竞品强调牌照数量 | [待 Mark 裁定] |

### 3.5 需要 Mark 会上裁定的问题

1. **4 类竞争态势分类是否准确？** 是否有 Mark 遇到过但不在这 4 类中的？
2. **红色态势的 3 个标配动作是否是 Mark 期望的？** 还是有其他"第一时间必须做的事"？
3. **请举 1~2 个真实竞争案例**，校准态势分类和应对动作
4. **获客手册中，哪些话术是 Mark 亲测有效的？** 特别是面对"佣金更高"和"独占"两个场景
5. **P0 灯塔客户的定义是否需要调整？** Mark 心中谁是灯塔客户？
