> 产出日期: 2026-04-12
> 范围: **L1-05 权益中台 + L3-COM 佣金合规** (F 族 + G 族)
> 状态: V0 — **简版** (F+G 只有 1.5 人, 局部图价值主要是"与业务线的横切关系")

## 0. 为什么是简版

L1-05 局部图不需要像 VS-1/VS-2/VS-4 那样做结构选型 + 4 个备选 + 隐含假设审视。F+G 设计简单到没有选型空间:
- F 族 1 人 (单人独立)
- G 族 0.5 FTE 兼职 (没有子结构)
- 合计 1.5 人 (没有子岗位)

**但简版不等于"没画",它仍然提供 1 个独特价值**: **可视化 F 族与 3 条 VS 的横切关系**,这是全图的关键连接点。

## 2. F 族 KPI 混合机制的可视化

F 族是 M3 组织设计里第一个"双考核"岗位。图上必须清晰表达"谁考核战略 / 谁考核服务质量":

```
                       Mark (CEO)
                       │     ↑
                       │     │
                       │ KPI-S 战略考核 (60%)
                       │     │
                       ▼     │
                  F 族 权益中台负责人
                       │     ↑
                       │     │
                       │ KPI-Q 服务质量考核 (40%)
                       │     │
                       ▼     │
          ┌────────────┼─────┴─────┐
          │            │           │
          ▼            ▼           ▼
       A 族 VS-1    C0 VS-2    D 族 VS-4
       (12%)        (12%)       (12%)

       每条业务线对 F 族的年度评分,
       三方合计 = 服务质量 KPI 的 40%
```

**关键符号**:
- ↑↓ 双向箭头: 表示"考核关系"(既汇报也被评)
- 数字百分比: KPI 权重
- 虚线框 (F 族周围): 表示"战略独立性保护"

## 3. G 族 "佣金争议裁定委员会" 的可视化

G 族的独特性是它不是个人岗位,而是**委员会里的一个成员**。图上必须画出委员会:

```
                  ┌─────────────────────────┐
                  │   佣金争议裁定委员会       │
                  │                          │
                  │   CFO (主席) ←裁决权      │
                  │    │                     │
                  │    ├─ G 族 (规则解读)    │
                  │    ├─ A/C/D 业务线代表   │
                  │    ├─ 合规部代表         │
                  │    └─ Ivan (观察员)      │
                  │                          │
                  │  裁决流程:               │
                  │  1. 争议上报             │
                  │  2. G 初审              │
                  │  3. 委员会开会 (3-5 工作日)│
                  │  4. 投票或主席裁决       │
                  │  5. 执行                │
                  │  6. 判例库              │
                  └─────────────────────────┘
```

这个委员会不是一个常设岗位,而是一个**虚拟治理节点** — 只有在争议发生时召开。M3 阶段不任命委员会主席,由 CFO 默认承担。

## 4. L1-05 局部图的 3 个关键洞察

### 洞察 1: L1-05 是全图里最复杂的 "横向连接器"

F 族服务 3 条 VS,但不隶属任何一条。这意味着在全图中:
- F 族必须放在 "Mark 下面 + 3 条 VS 之间" 的中心位置
- F 族的线条是全图最多的 (与 A/C0/D 三方都有连线)
- F 族的位置决定了全图的视觉重心

### 洞察 2: G 族是全图唯一的 "委员会型" 岗位

G 族本质不是一个"人的岗位",是一个"治理机制"。全图里 G 族的表示方式:
- 不画单独的岗位框
- 画一个"争议裁定委员会"虚拟框
- G 族只是框内的一个成员

这是全图的又一个符号创新 (继 E 族防火墙之后)。

### 洞察 3: M4 Agent 节点的统一位置

Carrie 挂名的 agent 节点服务 VS-1/VS-2/VS-4 三条线。在全图中它应该:
- 不在任何 VS 下方
- 平行于 F 族 (都是横切能力)
- 但与 F 族职责完全不同 (F 做权益,Carrie 做 agent 治理)

这暗示 **M4 可能会有一个"横切能力层"子组织**,包括 F+G+Agent 节点。M3 阶段不实体化这个子组织,但在图上预留。
