## 为什么这个文件是"历史版"

本文件（v1）存在以下结构性问题，导致其无法作为当前权威数据源：

1. **L3编码非标准**：使用旧编码（BMD/BME/MSI/MSE等），这些编码已在编码修复策略（R1-R6）中被废弃或合并
2. **L4编码非标准**：使用KN1-7、业务缩写（ATTR/CAP/MKT等）、L4-01~13等格式，不符合数据字典V1的 `L4-XXX-NN` 规范
3. **覆盖不完整**：仅覆盖24个L3，而当前标准L3库为82个
4. **无L4溯源**：未标注每条L4的原始文档来源
5. **无六维度评分**：仅有M2_Tier一级分类，缺少D1-D6评分细节
