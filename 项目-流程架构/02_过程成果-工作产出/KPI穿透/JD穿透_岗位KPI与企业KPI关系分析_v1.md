# 岗位级KPI与企业级KPI关系分析

> 基于7个岗位族JD + KPI_L3_Mapping_MASTERV1.1.xlsx对比梳理

---

## 一、两类KPI的本质区别

| 维度 | 32个企业级KPI | 7个族JD中的岗位级KPI |
|------|--------------|---------------------|
| **定位** | 公司级业务结果度量 | 个人/岗位绩效考核 |
| **数量** | 32个 | 约24个（7族合计） |
| **视角** | "业务结果是什么" | "我如何支撑业务结果" |
| **颗粒度** | 端到端流程结果 | 岗位职责执行质量 |
| **设计原则** | 数据可算、可追踪 | 行为导向、防跑偏 |
| **反KPI设计** | 无 | 每个族都有明确的"反KPI"（防止动作变形） |

## 三、映射关系总览

### 3.1 企业级KPI → 岗位级KPI的分解路径

```
┌─────────────────────────────────────────────────────────────┐
│                    32个企业级KPI                             │
│  (公司级业务结果度量：APE/保费/转化率/留存率/ROI等)           │
└──────────────────────┬──────────────────────────────────────┘
                       │ 分解/支撑
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                   24个岗位级KPI                              │
│  (7族JD中的KPI：关系健康度/规则执行/满意度/减负完成度等)     │
└──────────────────────┬──────────────────────────────────────┘
                       │ 进一步分解到
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                    L3流程执行节点                            │
│  (181条KPI-L3映射：具体流程节点对KPI的贡献权重)              │
└─────────────────────────────────────────────────────────────┘
```

## 四、关键发现

### 4.1 企业级KPI覆盖情况
- **完全被岗位级KPI覆盖**（有明确对应）：约18个企业级KPI
- **部分被覆盖**（间接关联）：约8个企业级KPI
- **无直接岗位级KPI对应**（纯业务结果指标）：约6个（如KPI_12集中度、KPI_18核保转化率、KPI_22长周期件数、KPI_24撤单率、KPI_50赔付率、KPI_51理赔时效）

### 4.2 "反KPI"设计的岗位保护作用
每个族的JD都设计了"反KPI"，防止岗位动作变形：
- **B族**：不考核签约速度/保司数量 → 防止BD为冲数字忽略关系质量
- **D族**：无权单独考核E族 → 防止用业绩指标绑架情感支持岗位
- **F族**：不考核权益上线数量 → 防止为上线而忽略成本与质量

### 4.3 Mark减负类KPI（组织效能层）
A族和C0的KPI中包含了"Mark减负完成度"和"Mark介入次数"指标，这类KPI在32个企业级KPI中没有直接对应，属于**组织治理效能类KPI**。
