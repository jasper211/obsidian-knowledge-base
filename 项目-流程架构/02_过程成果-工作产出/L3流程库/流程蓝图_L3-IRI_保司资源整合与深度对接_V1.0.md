# 流程蓝图 · L3-IRI 保司资源整合与深度对接 V1.0

> **生成日期**: 2026-05-28
> **价值流**: VS-1 保司投放 / VS1-S3 资源整合与深度对接
> **主责岗位**: A族-保司交付
> **协作岗位**: B族-保司关系经理
> **前置流程**: L3-IAC（合同生效 → DIM_License更新后触发）
> **后续流程**: L3-IBE 保司业务运营赋能

---

## 一、基本信息

| 字段 | 内容 |
|------|------|
| L3编码 | L3-IRI |
| 触发条件 | L3-IAC合同生效 + DIM_License写入 → 自动触发 |
| 流程终点 | 《整合就绪确认书》签字 → 触发L3-IBE |
| 前置依赖 | 已签合同 + 权限范围确认 |

---

## 二、输入物

- L3-IAC产出的已签合同 + 备案号
- 保司授权的权限范围（来自DIM_License）
- 保司IT系统联系人

---

## 三、关键步骤（6步）

```
步骤1：权限清单谈判与确认
  └─ 执行L4-IRI-01：A族 + Mark确认权限边界 → 输出《权限清单》（Mark必须介入）

步骤2：资源盘点与对接规范制定
  └─ 执行L4-IRI-02：盘点保司可用资源 → 输出《资源对接清单》
  └─ 执行L4-IRI-06：制定《对接技术规范》（API/SSO/联调）

步骤3：系统与数据团队对接
  └─ 执行L4-IRI-03：系统+数据+人员三线对接 → 输出对接完成报告

    【判断节点1】系统对接是否通过技术验证？
      ├─ 通过 → 步骤4
      └─ 未通过 → 返回L4-IRI-06修订技术规范，重新联调

步骤4：权限生效与配置
  └─ 执行L4-IRI-04：系统自动化配置权限 → 输出权限生效通知

    【判断节点2】权限生效测试是否通过？
      ├─ 通过 → 步骤5
      └─ 未通过 → 返回L4-IRI-03技术团队修复

步骤5：保司内部培训与人员换手
  └─ 执行L4-IRI-07：对保司人员开展培训 → 输出《培训换手记录》

步骤6：整合就绪确认
  └─ 执行L4-IRI-05：各项checklist核验 → 签字输出《整合就绪确认书》
  → 触发L3-IBE
```
