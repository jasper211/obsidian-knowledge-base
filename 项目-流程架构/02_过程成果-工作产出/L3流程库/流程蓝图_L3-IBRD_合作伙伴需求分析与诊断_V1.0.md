## §1 流程概览

本流程由前端渠道（江通）完成IBEC转介后启动，中台C族-机构BD接收转介信息，通过资格预审、牌照核查与保司确认、尽职调查三步完成合作机构的全面诊断，为谈判与签约（L3-NG）提供决策依据。

**前置流程**：L3-IBEC（前端渠道完成筛选并输出《转介信息包》）
**后续流程**：L3-NG（商务谈判与合同制定） / L3-URF（联合运营资源规整与框架方案设计）

> ⚠️ **架构说明**：L3-JOD（联合运行方案设计）已废弃，业务已并入L3-URF（来源：D2偏差分析报告_20260523）
> ⚠️ **重要修订**：原L4-IBRD-04"业务目标量化"已从蓝图删除；新增L4-IBRD-04"牌照核查与保司确认"（来源：D1修正版L4清单_20260528 / D3架构重构方案_20260528）

## §3 主干步骤（4步）

```
[Step 1] 合作资格预审与流程启动
  L4-IBRD-01 合作资格预审与流程启动 → 《合作资格预审与流程启动计划》(Aug)
  核查准入资格：合规状态 / 资质 / 历史记录
        ↓
        ◆ Q1：机构是否通过资格预审？
        ↓
[Step 2] 牌照核查与保司确认
  L4-IBRD-04 牌照核查与保司确认 → 《牌照核查与保司确认记录》(Human)
  IA网站查询牌照状态 + 保司Alice确认（永明签约/佣金率核查）
  合作路径判断：9付 vs UNIVIN（需书面化决策标准，A-02赵琦负责梳理）
        ↓
[Step 3] 项目沟通机制建立
  L4-IBRD-02 项目沟通机制建立 → 《项目沟通机制建立》(Auto)
  建立双方沟通频次、联络人、信息共享规则
        ↓
[Step 4] 尽职调查执行
  L4-IBRD-03 尽职调查执行 → 《尽职调查执行记录》(Aug)
  深度调查：牌照状态/保司合约/团队配置/业务模式/过往经验/风险评估
  → 输出至L3-NG谈判底稿
        ↓
        ◆ Q2：尽职调查结论？
```

## §4 判断节点

### Q1：机构是否通过资格预审？（Step 1后）
| 结论 | 后续路径 |
|------|---------|
| 通过 | → Step 2牌照核查与保司确认 |
| 不通过 | → 终止流程，记录原因，进入观察池 |

### Q2：尽职调查结论？（Step 4后）
| 结论 | 后续路径 |
|------|---------|
| 低风险 | → 推进至L3-NG谈判 |
| 中风险 | → 附条件推进，标注风险项至谈判底稿 |
| 高风险 | → 暂停，上报C族负责人决策 |
