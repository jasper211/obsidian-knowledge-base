# 流程蓝图 · L3-IBE 保司业务运营赋能 V1.0

> **生成日期**: 2026-05-28
> **价值流**: VS-1 保司投放 / VS1-S4 业务运营赋能
> **主责岗位**: A族-保司交付
> **协作岗位**: B族-保司关系经理 / E族-理财师辅导长（培训交付）
> **前置流程**: L3-IRI（整合就绪确认书签字后触发）
> **后续流程**: L3-IPI 保司产品上架与业务运营

---

## 一、基本信息

| 字段 | 内容 |
|------|------|
| L3编码 | L3-IBE |
| 触发条件 | L3-IRI《整合就绪确认书》签字后启动 |
| 流程终点 | 赋能效果验证完成 → 持续运营（进入L3-IPI并行） |
| 前置依赖 | 系统权限就绪 + 保司人员换手完成 |

---

## 二、输入物

- L3-IRI产出的《整合就绪确认书》
- Mark确认的赋能深度分级标准（L4-IBE-14前置）
- 保司人员名单 + 业绩归属规则（L4-IBE-01前置）

---

## 三、关键步骤（7步）

```
步骤1：赋能框架确定
  └─ 执行L4-IBE-14：Mark定《深度分级标准》（Mark必须介入）
  └─ 执行L4-IBE-01：Mark确定《归属规则》（Mark必须介入）
  └─ 执行L4-IBE-03：财务建模《成本分摊方案》

步骤2：能力基线诊断
  └─ 执行L4-IBE-02：评估保司团队能力基线 → 输出《能力基线报告》

    【判断节点1】赋能需求是否需要定制化方案？
      ├─ 是 → 执行L4-IBE-06 制定定制《营销方案书》
      └─ 否 → 使用标准赋能方案，直接进入步骤3

步骤3：培训课程设计与认证体系
  └─ 执行L4-IBE-15：LMS课程设计+交付 → 输出《培训完成报告》
  └─ 执行L4-IBE-16：认证考核 → 输出《认证名单》（Auto执行）

步骤4：场外人员招募与合规
  └─ 执行L4-IBE-11：招募场外支持人员 → 输出《场外人员清单》

    【判断节点2】场外人员是否通过合规审查？
      ├─ 通过 → 进入步骤5
      └─ 不通过 → 退回补充合规材料

步骤5：营销活动执行与销售协同
  └─ 执行L4-IBE-07：营销活动执行 → 输出《活动执行报告》
  └─ 执行L4-IBE-12：销售协同 → 输出《销售签单记录》

步骤6：激励结算与ROI核算
  └─ 执行L4-IBE-13：分佣激励结算 → 输出《分佣结算单》（Auto）
  └─ 执行L4-IBE-08：营销ROI分析 → 输出《ROI报告》（Auto）

步骤7：知识沉淀与退出机制备案
  └─ 执行L4-IBE-10：跨保司经验复用沉淀 → 更新《经验库》（Auto）
  └─ 执行L4-IBE-05：IP保护归档 → 更新《IP保护清单》
  └─ 执行L4-IBE-04：备案《退出流程》（条件触发：合作终止时启用）
  └─ 执行L4-IBE-09：竞业约定归档 → 输出《竞业约定》
```
