# 流程蓝图 · L3-IPI-Ops 日常运营 V1.0

> **生成日期**: 2026-06-01
> **版本说明**: 本流程由原L3-IPI拆分而来（P0裁定，Mark确认，D4 A-04）
> **拆分背景**: 原L3-IPI"产品上线与日常运营"合并了两个独立工作流，Mark确认上架和日常运营业务边界清晰，需拆分
> **价值流**: VS-1 保司投放 / VS1-S5 产品上架与业务运营（运营段）
> **主责岗位**: A族-保司交付
> **协作岗位**: F族-权益中台 / G族-佣金合规专家
> **前置流程**: L3-IPI-Onb（产品全面上架完成后触发）
> **后续流程**: L3-IMF 保司市场反馈与数据回流（数据管道对接）
> **数据来源**: D2_L4偏差分析报告_20260528 / D3_L3架构重构方案_20260528 / D4_Mark裁定清单_20260528

## 三、关键步骤（持续循环）

```
[持续运营循环]

步骤1：Portfolio管理与业绩监控
  └─ 执行L4-IPI-08：多维Portfolio分析 → 输出《Portfolio分析报告》
  └─ 执行L4-IPI-12：业绩数据反馈管道接通 → 输出《反馈记录》（Auto，对接L3-IMF）
  └─ 执行L4-IPI-13：客户体验NPS监控 → 输出《体验监控报告》（Auto）

    【判断节点1】是否需要跨业务线迁移？（条件触发）
      ├─ 需要 → 执行L4-IPI-10跨业务线迁移
      └─ 不需要 → 继续监控循环

步骤2：产品生命周期持续管理
  └─ 执行L4-IPI-10：跨业务线迁移（按需）→ 输出《迁移记录》
  [循环返回步骤1]
```
