## 一、模板用途

本模板由**前端渠道**（江通等）在向**中台**（菲菲 / MOMO）移交同行机构信息时填写。

**核心目标**:
1. 统一前端向中台转介的信息标准，消除"信息不全导致反复沟通"的堵点
2. 明确最低准入门槛，避免无效转介浪费中台资源
3. 为中台执行 L3-IBRD（合作伙伴需求分析与诊断）提供完整输入物
4. 与 A-02 决策树配套：模板填写完整 → 中台收件确认 → 启动合作路径判断

**适用场景**:
| 来源线 | 填写人 | 接收人 | 移交方式 |
|:---|:---|:---|:---|
| 江通线 | 江通（前端渠道） | 菲菲（同行业中务条线负责人） | 微信/邮件 + 本模板 |
| 白博文线 | 白博文（Uniwind市场拓展） | MOMO（商务条款对接） | 内部系统/邮件 + 本模板 + 画像描述表 |

> **边界说明**: L3-IBEC 为前端市场流程，中台不直接执行。本模板仅规范 IBEC → IBRD 的交接界面，不干预前端渠道内部的市场接触行为。

## 二、最低准入门槛

以下**任一条件不满足**，中台有权退回前端重新补充或终止转介：

| # | 门槛项 | 标准 | 验证方式 | 不满足处理 |
|:---:|:---|:---|:---|:---|
| 1 | **牌照有效性** | 牌照在有效期内，且为合法持牌机构 | 附牌照截图/官方查询记录 | **退回**：无有效牌照，不具备合作基础 |
| 2 | **合作意向明确性** | 同行机构已明确表达合作意向（口头/书面） | 附沟通记录截图或文字说明 | **退回**：意向不明，无法推进 |
| 3 | **信息完整性** | A类字段（资质信息）全部填写完整 | 中台逐项核对 | **退回**：信息缺失，无法启动资质审查 |
| 4 | **来源可追溯** | 推荐人及推荐背景清晰可溯 | 填写C类字段 | **退回**：来源不明，无法评估推荐质量 |

> **v1.1更新·来源：Q-11·菲菲momo二轮调研**
> 牌照有效期当前**无硬性门槛要求**（菲菲确认"是没有的"）。是否设定正式门槛（≥90天/≥180天/分档）需Mark/法务后续裁定。当前暂不将"牌照有效期"作为准入硬性门槛。

## 四、中台收件确认流程

前端渠道提交完整模板后，中台按以下流程确认：

```
前端提交转介信息模板 + 画像描述表 ★v1.1更新
    ↓
中台收件登记（记录接收时间+来源线）
    ↓
Step 1: 准入门槛审查（对照§二 4条门槛）
    ├─ 任一不满足 → 退回前端，注明缺失项
    └─ 全部满足 → 继续
    ↓
Step 2: A类字段完整性核查 + Alice查询永明合约状态
    ├─ 不完整 → 退回前端补充
    └─ 完整 → 继续
    ↓
Step 3: 合作路径初判（参照A-02决策树）
    ├─ 资管牌 → 初判：DW路径
    ├─ 经纪行+有永明合约 → 初判：JF路径
    ├─ 经纪行+无永明合约 → 初判：UNIVIN路径
    └─ 信息不足以判断 → 退回前端补充
    ↓
Step 4: 分配执行人
    ├─ 江通线 → 分配给菲菲
    ├─ 白博文线 → 分配给MOMO
    ↓
Step 5: 启动L3-IBRD流程
```

### 中台收件确认清单

中台（菲菲 / MOMO）在收到模板后，勾选确认：

- [ ] **A类字段全部填写完整**（机构名称、牌照号码、牌照类型、有效期、永明合约状态、佣金率状态、牌照截图）
- [ ] **永明合约状态已通过Alice查询确认** ★v1.1更新
- [ ] **B类字段关键项已填**（业务模式、团队规模至少已填）
- [ ] **C类字段已填**（推荐人、推荐背景清晰）
- [ ] **画像描述表已由前端BD填写** ★v1.1更新
- [ ] **牌照截图已附且清晰可辨认**
- [ ] **合作路径初判已完成**（DW / JF / UNIVIN）
- [ ] **已分配给对应执行人**（菲菲 / MOMO）
- [ ] **已登记收件时间，进入L3-IBRD流程**

> **时效要求**: 中台应在收到完整模板后 **3-5个工作日内** 完成收件确认并反馈前端 ★v1.1更新。若退回补充，应在 **1个工作日内** 明确告知缺失项。

> **v1.1更新·来源：Q-17·菲菲momo二轮调研**
> 收件时效从2个工作日修正为3-5个工作日。菲菲确认DD Form从发出到回收一般3-5个工作日（"是很及时回复的比较少"），原因：DD Form较复杂，包含业务数据+财务数据+RO审阅。

### 退回与关闭机制

若前端提交不完整或中台判断不符合准入条件：

- **退回**: 中台在1个工作日内反馈缺失项
- **观察期**: 若退回后前端/合作方迟迟未补，中台**一季度的观察期**后如仍无进展，确认无合作意向后关闭 ★v1.1更新
- **关闭条件**: 确认无合作意向（人为判断，无硬性时限卡点）

> **v1.1更新·来源：Q-16·菲菲momo二轮调研**
> DD Form一般不会退回去（"只会有少少签"）。退回后若合作方不签，菲菲的当前做法是"挂在上面，差不多一个季度都没有签的话就把它毁掉"。关闭条件为"确认没有合作意向"（人为确认过程，无硬性时限）。

## 五、与A-02决策树的衔接

| 本模板字段 | 对应A-02决策树 | 用途 |
|:---|:---|:---|
| A类·牌照类型 | 判断节点0（牌照类型判断） ★v1.1更新 | 资管牌→DW / 经纪行→JF/UNIVIN判断 |
| A类·是否有永明合约 | 判断节点1 | 决定JF/UNIVIN路径 |
| A类·是否有佣金率 | 判断节点1（辅助信息） | 记录但不影响路径判断 |
| B类·业务模式 | 步骤3 | 影响合作方案设计 |
| B类·团队规模 | 步骤3 | 影响服务能力评估 |
| C类·推荐背景 | 判断节点0b（来源线判断） | 决定分配江通线或白博文线 |

**衔接规则**:
1. 本模板填写完整 → 中台收件确认 → 通过Alice查询永明合约 → 启动A-02决策树
2. A类字段是决策树的**必要输入**，缺失则无法启动判断
3. 牌照类型字段驱动第一步判断（资管→DW/经纪行→JF/UNIVIN）
4. 永明合约状态通过中台（Alice）查询回填，前端无权限
