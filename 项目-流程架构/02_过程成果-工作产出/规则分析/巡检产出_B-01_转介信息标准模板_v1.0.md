## 一、模板用途

本模板由**前端渠道**（江通等）在向**中台**（菲菲 / MOMO / 交付经理）移交同行机构信息时填写。

**核心目标**:
1. 统一前端向中台转介的信息标准，消除"信息不全导致反复沟通"的堵点
2. 明确最低准入门槛，避免无效转介浪费中台资源
3. 为中台执行 L3-IBRD（合作伙伴需求分析与诊断）提供完整输入物
4. 与 A-02 决策树配套：模板填写完整 → 中台收件确认 → 启动合作路径判断

**适用场景**:
| 来源线 | 填写人 | 接收人 | 移交方式 |
|:---|:---|:---|:---|
| 江通线 | 江通（前端渠道） | 菲菲（同行业中务条线负责人） | 微信/邮件 + 本模板 |
| 白博文线 | 白博文（Uniwind市场拓展） | MOMO（商务条款对接）→ 交付经理 | 内部系统/邮件 + 本模板 |

> **边界说明**: L3-IBEC 为前端市场流程，中台不直接执行。本模板仅规范 IBEC → IBRD 的交接界面，不干预前端渠道内部的市场接触行为。

## 二、最低准入门槛

以下**任一条件不满足**，中台有权退回前端重新补充或终止转介：

| # | 门槛项 | 标准 | 验证方式 | 不满足处理 |
|:---:|:---|:---|:---|:---|
| 1 | **牌照有效性** | 牌照在有效期内，且为合法持牌机构 | 附牌照截图/官方查询记录 | **退回**：无有效牌照，不具备合作基础 |
| 2 | **合作意向明确性** | 同行机构已明确表达合作意向（口头/书面） | 附沟通记录截图或文字说明 | **退回**：意向不明，无法推进 |
| 3 | **信息完整性** | A类字段（资质信息）全部填写完整 | 中台逐项核对 | **退回**：信息缺失，无法启动资质审查 |
| 4 | **来源可追溯** | 推荐人及推荐背景清晰可溯 | 填写C类字段 | **退回**：来源不明，无法评估推荐质量 |

> **说明**: 以上门槛基于调研中确认的痛点设计——当前前端转介信息不完整，导致中台反复索要材料，严重影响效率。

## 四、中台收件确认流程

前端渠道提交完整模板后，中台按以下流程确认：

```
前端提交转介信息模板
    ↓
中台收件登记（记录接收时间+来源线）
    ↓
Step 1: 准入门槛审查（对照§二 4条门槛）
    ├─ 任一不满足 → 退回前端，注明缺失项
    └─ 全部满足 → 继续
    ↓
Step 2: A类字段完整性核查
    ├─ 不完整 → 退回前端补充
    └─ 完整 → 继续
    ↓
Step 3: 合作路径初判（参照A-02决策树）
    ├─ 有合约无佣金率 → 初判：JF路径
    ├─ 无合约 → 初判：UNIVIN路径
    ├─ 有合约有佣金率 → 标注：边界Case，待Mark确认
    └─ 信息不足以判断 → 退回前端补充
    ↓
Step 4: 分配执行人
    ├─ 江通线 → 分配给菲菲
    ├─ 白博文线 → 分配给MOMO（商务条款）→ 交付经理（签单）
    ↓
Step 5: 启动L3-IBRD流程
```

### 中台收件确认清单

中台（菲菲 / MOMO / 交付经理）在收到模板后，勾选确认：

- [ ] **A类字段全部填写完整**（机构名称、牌照号码、牌照类型、有效期、永明合约状态、佣金率状态、牌照截图）
- [ ] **B类字段关键项已填**（业务模式、团队规模至少已填）
- [ ] **C类字段已填**（推荐人、推荐背景清晰）
- [ ] **牌照截图已附且清晰可辨认**
- [ ] **合作路径初判已完成**（JF / UNIVIN / 边界Case待确认）
- [ ] **已分配给对应执行人**（菲菲 / MOMO / 交付经理）
- [ ] **已登记收件时间，进入L3-IBRD流程**

> **时效要求**: 中台应在收到完整模板后 **2个工作日内** 完成收件确认并反馈前端。若退回补充，应在 **1个工作日内** 明确告知缺失项。

## 五、与A-02决策树的衔接

| 本模板字段 | 对应A-02决策树 | 用途 |
|:---|:---|:---|
| A类·是否有永明合约 | 判断节点1 | 决定是否进入判断节点2 |
| A类·是否有佣金率 | 判断节点2 | 决定JF/UNIVIN路径 |
| B类·业务模式 | 江通线步骤2 / 白博文线步骤2 | 影响合作方案设计 |
| B类·团队规模 | 江通线步骤2 | 影响服务群配置 |
| C类·推荐背景 | 来源线判断（判断节点0） | 决定分配江通线或白博文线 |

**衔接规则**:
1. 本模板填写完整 → 中台收件确认 → 启动A-02决策树
2. A类字段是决策树的**必要输入**，缺失则无法启动判断
3. B类字段是决策树的**辅助输入**，影响后续步骤但不阻断判断
4. C类字段决定**执行路径分配**（江通线 vs 白博文线）
