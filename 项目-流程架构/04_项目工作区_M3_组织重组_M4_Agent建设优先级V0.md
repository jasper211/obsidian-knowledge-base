> 产出日期: 2026-04-12

> 服务 M3 北极星交付物 #5 (M4 Agent 优先级)

---

## 0. 这份清单的用途

这是从 M3 到 M4 的桥梁。M3 完成后,80 条 Auto L4 必须有**明确的建设顺序**,否则 M4 会陷入 "100 个 agent 同时开工" 的混乱。

**本清单回答 3 个问题**:
1. 先建哪些 agent? (优先级排序)
2. 分几个阶段建? (4 阶段路线图)
3. 投入多少、回报多少? (ROI 估算)

---

## 1. 核心原则: 基础设施优先 + 技术栈复用

### 原则 1: 基础设施先建,业务后建

**错误方式**: 按业务价值排序,先建佣金/报告/健康度等业务型 agent
**正确方式**: 先建数据管道/规则引擎/告警系统等基础设施,再建业务型

**原因**: 80 条 Auto L4 里有 18 条 "规则引擎型" + 9 条 "数据管道型" + 7 条 "告警型" = 34 条依赖共同基础设施。先建基础设施,后续 34 条 agent 只需"调用基础设施 + 配置规则",开发效率提升 3~5 倍。

### 原则 2: 按技术栈分 4 阶段, 不按 L3

**传统方式**: 每个 L3 独立建 agent (按业务线)
**M4 方式**: 按技术栈分 4 阶段 (规则引擎 → 数据管道 → 告警 → ML),每阶段跨 L3 完成

**好处**: 同技术栈的 agent 可以共用开发团队、调试工具、部署流水线。

### 原则 3: 每个 agent 必须有"主人"

从 M3 全图看,每条 Auto L4 都会服务某个肉身岗位 (A/B/C/D/E/F/G)。**每个 agent 必须明确"主人" — 哪个岗位用它、向谁汇报状态、谁负责维护**。

**主人清单** (M3 JD 决定):
- A/B 族使用的 agent: Carrie 运维 (VS-1 子集)
- C0 使用的 agent: Carrie 运维 (VS-2 子集)
- D/E 族使用的 agent: Carrie 运维 (VS-4 子集)
- F 族使用的 agent: F 族负责人 (L1-05 权益)
- G 族使用的 agent: G 族兼职 (L3-COM 佣金)

## 4. ROI 估算

### 4.1 投入

**基础设施建设成本** (M4.1, 34 条):
- 数据管道: ~200 万 HKD (含 ETL + 数仓 + BI)
- 规则引擎: ~150 万 HKD (引擎选型 + 定制)
- 告警系统: ~80 万 HKD (告警平台 + 集成)
- **小计**: ~430 万 HKD

**业务 agent 建设成本** (M4.2 + M4.3 + M4.4, 46 条):
- 每条平均 15 万 HKD (基于行业经验)
- **小计**: ~690 万 HKD

**总一次性投入**: **~1,120 万 HKD**

**年度运维成本**:
- Carrie + Agent 节点团队 (~3 人): ~180 万 HKD/年
- 云服务 + 第三方 API: ~50 万 HKD/年
- **合计**: ~230 万 HKD/年

### 4.2 收益

**人力成本节省** (主要收益):
- M3 减员 ~90 人 (124 → 34)
- 人均成本 ~27 万 HKD/年 (HR 数据)
- **年度节省**: ~2,430 万 HKD

**业务收益**:
- Agent 质量提升 (规则一致/24x7/零错误) 带来的 APE 提升 (估 ~5%)
- 按 2025 APE 6.3 亿 × 5% = **~3,150 万 HKD/年**

**年度总收益**: ~5,580 万 HKD

### 4.3 ROI 计算

- 一次性投入: 1,120 万
- 年度净收益: 5,580 - 230 = **5,350 万 HKD/年**
- **回本周期**: 1,120 / 5,350 ≈ **0.21 年 = 2.5 个月**

**3 年累计净收益**: 5,350 × 3 - 1,120 = **14,930 万 HKD** (~1.5 亿 HKD)

### 4.4 ROI 的敏感性

上述是 "乐观情景"。如果:
- 建设延期 50% (15 个月 vs 10 个月)
- 实际 APE 提升只有 2% (vs 5%)
- 建设成本超支 30% (1,456 万 vs 1,120 万)

**保守情景 ROI**:
- 收益: (2,430 + 1,260) - 230 = 3,460 万/年
- 回本周期: 1,456 / 3,460 ≈ **5 个月**
- 3 年累计: 3,460 × 3 - 1,456 = **8,924 万 HKD**

即便保守,**ROI 仍然极高**。这证明 Mark 推进 AI 组织化的战略完全正确。
