## T1-Step1：扫描并确认来源文件

扫描项目目录下所有CSV/Excel/JSON文件，输出清单：

```
文件路径 | 推断内容类型 | 行数 | 主要字段 | 是否纳入底座
```

**判断规则**：
- 包含 l3_code / vs_code / l4_code / kpi_id 等标准化编码字段 → 纳入
- 包含 job_family / ep_code / jd_ 前缀字段 → 排除，标注"岗位JD来源，T1不纳入"
- 包含原始文档直接导出的自由文本（未经标准化） → 排除，标注"待T1处理后纳入"

输出：`T1_source_scan_report.txt`

## T1-Step2：建立/更新数据库Schema

数据库文件：`ea_knowledge_base.db`

执行以下建表语句（已存在的表用 `CREATE TABLE IF NOT EXISTS`，不覆盖已有数据）：

```sql
-- 表1：L3流程库（核心锚点表）
CREATE TABLE IF NOT EXISTS dim_l3 (
    l3_code             TEXT PRIMARY KEY,   -- 格式：L3-[A-Z]{2,4}，如L3-IAO
    l3_name             TEXT NOT NULL,
    l3_name_en          TEXT,
    l1_code             TEXT NOT NULL,      -- L1-01~L1-05
    l1_name             TEXT NOT NULL,      -- 来自方法论纠偏文档，不可自行修改
    vs_code             TEXT,               -- VS1~VS5，横切能力层为NULL
    vs_stage_code       TEXT,               -- 归属阶段编码
    is_vs_level         INTEGER DEFAULT 1,  -- 1=VS级，0=非VS级
    source_doc          TEXT NOT NULL,      -- 必填：来源文件名
    source_row_ref      TEXT,               -- 来源文件的行号或唯一标识
    confirmation_status TEXT DEFAULT 'draft',
    created_at          TEXT DEFAULT (datetime('now')),
    updated_at          TEXT DEFAULT (datetime('now'))
);

-- 表2：价值流全量表
CREATE TABLE IF NOT EXISTS dim_value_stream (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    vs_code         TEXT NOT NULL,          -- VS1~VS5
    vs_name         TEXT NOT NULL,
    stage_code      TEXT NOT NULL,          -- 如IAO/IAC/IRI
    stage_name      TEXT NOT NULL,
    activity_code   TEXT,                   -- 对应L3编码（外键→dim_l3）
    activity_name   TEXT,
    activity_desc   TEXT,
    sort_order      INTEGER,
    source_doc      TEXT NOT NULL,
    FOREIGN KEY (activity_code) REFERENCES dim_l3(l3_code)
);

-- 表3：L4活动表
CREATE TABLE IF NOT EXISTS dim_l4_activity (
    l4_code         TEXT PRIMARY KEY,       -- 格式：L4-[A-Z]{2,4}-NN
    l4_name         TEXT NOT NULL,
    l3_code         TEXT NOT NULL,          -- 外键→dim_l3
    activity_type   TEXT,                   -- 执行类/判断类/协调类/监控类
    source_doc      TEXT NOT NULL,
    source_row_ref  TEXT,
    confirmation_status TEXT DEFAULT 'draft',
    FOREIGN KEY (l3_code) REFERENCES dim_l3(l3_code)
);

-- 表4：L4→交付物+Agent映射
CREATE TABLE IF NOT EXISTS dim_agent_capability (
    l4_code         TEXT NOT NULL,          -- 外键→dim_l4_activity
    deliverable     TEXT,                   -- 核心交付物名称
    deliverable_type TEXT,                  -- 文档/数据/系统记录/签字/凭证
    agent_type      TEXT NOT NULL,          -- Auto / Assist / Human
    m2_tier         TEXT,                   -- M2业务评审Tier（优先级最高）
    infer_tier      TEXT,                   -- 推导Tier（参考）
    source_doc      TEXT NOT NULL,
    confirmation_status TEXT DEFAULT 'draft',
    PRIMARY KEY (l4_code),
    FOREIGN KEY (l4_code) REFERENCES dim_l4_activity(l4_code)
);

-- 表5：KPI-L3映射
CREATE TABLE IF NOT EXISTS dim_kpi (
    corp_kpi_id     TEXT NOT NULL,          -- 企业KPI编码，如KPI-01
    corp_kpi_name   TEXT NOT NULL,
    l3_code         TEXT NOT NULL,          -- 外键→dim_l3
    alignment_score INTEGER,                -- 对齐度1-5
    kpi_type        TEXT,                   -- 结果型/过程型
    measure_freq    TEXT,                   -- 月度/季度/年度
    source_doc      TEXT NOT NULL,
    confirmation_status TEXT DEFAULT 'draft',
    PRIMARY KEY (corp_kpi_id, l3_code),
    FOREIGN KEY (l3_code) REFERENCES dim_l3(l3_code)
);
```

**⚠️ 不建以下表（T3阶段才建）**：
- `dim_job_family`（岗位族定义）
- `bridge_job_l3`（岗位-L3映射）
- `bridge_job_kpi`（岗位-KPI映射）
- `dim_ep`（介入点清单）

## T1-Step3：数据写入

写入顺序（保证外键依赖）：
1. `dim_l3`（无外键，先写）
2. `dim_value_stream`（依赖dim_l3）
3. `dim_l4_activity`（依赖dim_l3）
4. `dim_agent_capability`（依赖dim_l4_activity）
5. `dim_kpi`（依赖dim_l3）

**写入规则**：
- 使用 `INSERT OR REPLACE INTO`（幂等，可重跑）
- `source_doc` 字段必填，填写来源文件的完整文件名（如 `L3编码标准化结果_v1.csv`）
- `source_row_ref` 尽量填写，便于T2溯源校验
- `m2_tier` 优先级高于 `infer_tier`，若两列都有数据，以m2_tier为准
- `l1_name` 使用以下权威名称，不得修改：
  - L1-01 → 保险业务赋能
  - L1-02 → 代理人事业发展
  - L1-03 → 机构合作拓展
  - L1-04 → 数据与技术中台
  - L1-05 → 横切能力层

## T1-Step4：数据质量校验

写入完成后执行以下SQL，输出结果：

```sql
-- 1. 各表行数
SELECT 'dim_l3'               AS tbl, COUNT(*) AS rows FROM dim_l3
UNION ALL SELECT 'dim_value_stream',    COUNT(*) FROM dim_value_stream
UNION ALL SELECT 'dim_l4_activity',     COUNT(*) FROM dim_l4_activity
UNION ALL SELECT 'dim_agent_capability',COUNT(*) FROM dim_agent_capability
UNION ALL SELECT 'dim_kpi',             COUNT(*) FROM dim_kpi;

-- 2. 外键孤儿检查
SELECT 'orphan_in_value_stream' AS check_name, COUNT(*) AS cnt
FROM dim_value_stream WHERE activity_code IS NOT NULL
  AND activity_code NOT IN (SELECT l3_code FROM dim_l3)
UNION ALL
SELECT 'orphan_in_l4_activity', COUNT(*)
FROM dim_l4_activity WHERE l3_code NOT IN (SELECT l3_code FROM dim_l3)
UNION ALL
SELECT 'orphan_in_agent_cap', COUNT(*)
FROM dim_agent_capability WHERE l4_code NOT IN (SELECT l4_code FROM dim_l4_activity)
UNION ALL
SELECT 'orphan_in_kpi', COUNT(*)
FROM dim_kpi WHERE l3_code NOT IN (SELECT l3_code FROM dim_l3);

-- 3. source_doc空值检查（T2溯源的基础）
SELECT 'dim_l3_no_source'     AS check_name, COUNT(*) AS cnt FROM dim_l3 WHERE source_doc IS NULL OR source_doc=''
UNION ALL SELECT 'dim_l4_no_source', COUNT(*) FROM dim_l4_activity WHERE source_doc IS NULL OR source_doc=''
UNION ALL SELECT 'dim_agent_no_source', COUNT(*) FROM dim_agent_capability WHERE source_doc IS NULL OR source_doc=''
UNION ALL SELECT 'dim_kpi_no_source', COUNT(*) FROM dim_kpi WHERE source_doc IS NULL OR source_doc='';

-- 4. l3_code格式校验
SELECT l3_code FROM dim_l3
WHERE l3_code NOT REGEXP '^L3-[A-Z]{2,5}$';

-- 5. agent_type枚举值校验
SELECT DISTINCT agent_type FROM dim_agent_capability
WHERE agent_type NOT IN ('Auto','Assist','Human');

-- 6. confirmation_status分布
SELECT confirmation_status, COUNT(*) AS cnt FROM dim_l3
GROUP BY confirmation_status;

-- 7. 非VS级L3确认
SELECT l3_code, l3_name, l1_code FROM dim_l3
WHERE is_vs_level = 0;
```
