## 四、数据映射全链路

### 架构层穿透链

```
L1 价值链节点(5个)           -- 企业唯一价值链的战略活动分解
  └── L2 业务能力(18个)       -- 使能L1的稳定能力集合
        └── L3 端到端流程(82个) -- 实现业务能力的跨部门可执行流程
              └── L4 核心交付物(400个) -- L3内的原子工作单元, 含D1-D6评分
                    └── L5 经营活动(若干) -- L4内的具体执行步骤
```

### 价值交付穿透链

```
VS 价值流(5条)               -- 外部利益相关者视角
  ├── VS-1 保司资源投放旅程(7个L3)
  ├── VS-2 机构合作伙伴旅程(27个L3)
  ├── VS-3 KA上架旅程(7个L3)
  ├── VS-4 理财师发展旅程(6个L3)
  └── VS-5 权益服务企业客户旅程(9+8个L3)

非VS级(16个L3):
  ├── 战略赋能层(L1-01): 8个  (MIO/VPV/MED/CAS/SPE/SRE/MEI/SFC)
  ├── 佣金合规层(L1-03): 4个  (CBD/CMU/COM/CVI)
  └── 权益中台横切层(L1-05): 4个 (EO/RSD/SLCM/SLM)
```

### KPI穿透链

```
企业KPI(32个) ──映射──> L3流程(235条映射)
  └── 岗位KPI(9族) ──穿透──> M0-M8战略矩阵(7族x9维)
        └── 岗位报告(7份HTML) ──渲染──> 数据驱动输出
```

### Agent化穿透链

```
L4核心交付物(400个)
  └── D1-D6评分(0-18分) ──映射──> 四Tier
        ├── Auto(77个, 19.3%)   -- Agent独立执行, 人仅异常介入
        ├── Aug(108个, 27.0%)   -- Agent主导, 人关键确认
        ├── Hybrid(176个, 44.0%) -- 人Agent协作
        └── Human(39个, 9.8%)   -- 人主导, Agent辅助
  └── 8大Agent能力组合
        ├── NLP生成+模板填充+格式转换(76个)
        ├── 流程自动化+任务调度+状态跟踪(46个)
        ├── 规则引擎+数据处理+API调用(23个)
        ├── 数据参考+辅助分析(13个)
        ├── 规则引擎+合规检查+自动预警(11个)
        ├── 数据辅助+流程支持(5个)
        ├── 数据分析(5个)
        └── ML模型+规则引擎(4个)
```

## 八、已验证的方法论

| 方法论 | 说明 |
|--------|------|
| 三层映射穿透 | M0-M8(战略) -> VS(价值流) -> L3(流程) -> L4(活动) -> KPI 形成完整分析框架 |
| L1权威名称 | 来自方法论纠偏文档, 5个飞轮节点名称不可修改 |
| M2_Tier优先于推导Tier | 报告使用M2业务评审结果, 推导Tier仅作参考 |
| 非VS级16条L3 | 归属L1横切能力层, 不强行归入任何VS |
