## 0. 一句话岗位定义

> **保司关系经理 = 2~3 家保司的"一张嘴"全流程接口人。**
> **承接 A 族定义的执行规则,把规则落地到具体保司的实际场景,并维护保司关系的日常健康。**

**与 A 族的一句话区别**:
- A 族 (1 人): 规则执行器 + 跨保司战略分析 + VS-1 归口人
- B 族 (3~5 人): 单家保司全流程接口人 + 关系维护者 + 规则落地者

## 2. 岗位存在的根本理由

**没有这个岗位,A 族 1 个人无法承担所有保司的关系维护**。

具体依据:
- A 族 1 人无法对接 N 家保司的日常关系 (物理上不可能)
- 保司需要"一张嘴"的稳定接口人,不能每次换人
- B 族 32 条中 **10 条关系谈判 + 9 条合规签字** = 19 条 (60%) 是日常重复性工作,需要专人承担
- 内部现有 BD/业务发展团队已有积累,裁撤换新会伤害关系连续性

**本质定位**: B 族是"**保司关系的记忆体**" — 每个成员保留 2~3 家保司的历史/上下文/人脉,这些是 Mark 和 A 族都无法替代的。

- **5% 工作量**: 危机应对 + 创意判断 (低频高价值)

## 4. 按保司分片 — 工作分配模型

**分配规则** (M3.4 组织架构时细化):

### 示例分配 (假设 5 位 B 族成员, ~15 家合作保司)

| B 族成员 | 负责保司 | 复杂度 | 备注 |
|---------|---------|------|-----|
| B-01 | **永明** + 深度合作保司 1 | 高 | **双线汇报**: 日常 → A, 战略关系 → Mark |
| B-02 | 战略级保司 2~3 家 | 高 | → A 汇报 |
| B-03 | 常规合作保司 3 家 | 中 | → A 汇报 |
| B-04 | 常规合作保司 3 家 | 中 | → A 汇报 |
| B-05 | 新开发保司 + 潜在保司 3~4 家 | 低 | → A 汇报, 主攻开发 |

**关键设定**:
- **每人负责 2~3 家保司**是上限,超过会导致关系质量下降
- **B-01 是例外**,因为永明需要 Mark 亲自参与战略 (M2 裁定)
- **新开发保司**需要较低门槛的 B 族成员做 IAO 阶段 (EP-048~057)

**编制总数**: 3~5 人 (根据实际保司数量 + 开发 pipeline 定)

## 5. KPI 核心 3 项

**设计原则**: KPI 以"保司关系健康度"为主,不以 APE 为主 (避免短期动作伤害长期关系)。

| KPI | 目标 | 权重 |
|-----|-----|-----|
| **KPI-1 保司关系健康度** | 负责保司的"关系健康得分" ≥ 80/100 (多维度: 续约意愿/升级意愿/冲突数/满意度) | **40%** |
| **KPI-2 规则执行准确度** | 按 A 族规则执行的偏离率 ≤ 5% (Mark 定的让步边界/Tier分级/归属规则等) | **35%** |
| **KPI-3 负责保司 APE 贡献** | APE 增长率 ≥ 公司整体 (合作稳定性要求) | **25%** |

**反 KPI** (防止跑偏):
- 不考核"谈判签约速度" (避免急躁)
- 不考核"合作保司数量" (避免广而不深)
- **不考核 Mark 个人介入次数** (避免避免 escalate 正当问题)

## 6. 能力模型

### 6.1 硬能力 (必备)

| 能力 | 要求 |
|-----|-----|
| **保司关系管理** | 3+ 年保险/经代 保司对接经验,能识别保司决策链 |
| **合同谈判** | 能按让步边界独立主导合同谈判 (不超边界需要 escalate A) |
| **规则理解与执行** | 能把 A 族规则文档转化为具体保司场景的动作 |
| **跨部门协调** | 能协调合规/法务/产品/权益/财务多方 |

### 6.2 软能力 (关键)

| 能力 | 要求 |
|-----|-----|
| **关系敏感度** | 能及早识别保司决策层变动/关系降温信号 |
| **执行纪律** | 能严格按 A 族规则办事,不随意超规 |
| **同理心** | 能理解保司痛点,不只是推销 |
| **抗压** | 保司关系是慢工细活,能承受长周期无反馈的压力 |

### 6.3 红灯 (不适合此岗位)

- ❌ 只会硬推销 (伤害长期关系)
- ❌ 不能容忍规则约束 (会跳过 A 族直接找 Mark)
- ❌ 短期业绩导向 (透支长期关系)
- ❌ 不善于沉淀关系上下文 (导致离职时交接灾难)

## 7. 汇报与协同关系

### 7.1 常规汇报线 (B-02~B-05)

```
                      Mark (CEO)
                         │
                         │
                   A 族 保司交付 (1 人)
                         │
                ╱   ╱    │    ╲    ╲
               ╱   ╱     │     ╲    ╲
            B-02 B-03  B-04   B-05
           (2~3保司) (3保司) (3保司) (开发)
```

### 7.2 战略级保司双线 (B-01 例外)

```
                      Mark (CEO)
                      ╱     ╲
                     ╱       ╲ (战略关系直连)
                    ╱         ╲
              A 族 保司交付    B-01 (永明 + 深度合作)
                    │          │
                    └─ 行政线 ─┘
```

**解读**: B-01 日常运营由 A 族管理(工作安排/考核/规则),战略关系由 Mark 直接介入(永明级别的重大决策/关系升级)。

### 7.3 协同对象与频率

- **A 族 保司交付**: 每周 1 次 sync (30 分钟) + 规则执行月度 review
- **B 族内部**: 每周 1 次 sync (共同学习保司经验)
- **合规/法务**: 每次合同推进时协同
- **F 族 权益中台**: 涉及权益产品时协同
- **B 族 ↔ Mark 1:1**: **仅 B-01 有**,其他成员只在 A 族升级时见 Mark

## 8. 从现有 BD 团队重新定位的迁移路径

**核心前提**: Mark 指定 "保留现有,重新定位",不裁员不外招。

### 8.1 现状假设 (待 HR 数据确认)

HR 基线预填数据显示,业务交付部约 25 人,其中可能有 10~15 人与 BD/关系型工作相关:
- 业务交付部 - 业务交付部 (3 人)
- 业务交付部 - 业务线交付部 (18 人)
- 永明事业部 - 业务发展 (6 人) 

### 8.2 重新装配流程

1. **M3.5 Week 1**: Ivan + A 族交付负责人 盘点现有人员实际工作,画出"现状 → B 族" 映射草案
2. **M3.5 Week 2**: 草案与每人 1:1 沟通 (Ivan 主持,A 族陪同)
3. **M3.5 Week 3**: 调整方案 + 培训计划 (规则执行+合规流程)
4. **M3.5 Week 4**: 新结构试运行
5. **M4 启动后**: 完全到位

### 8.3 重新定位不是降级

**重要**: 重新定位可能涉及:
- 岗位名调整 (从"业务发展经理"改为"保司关系经理")
- 负责保司的重新分配 (按关系连续性)
- **级别/薪资不降** (否则引发流失)
- 培训补齐能力缺口 (规则执行/合规/MGA 本质)

## 9. 与 A 族的协同矩阵 (关键章节)

以下矩阵定义了 A/B 两族在 VS-1 全流程中的分工:

| L3/阶段 | A 族做什么 | B 族做什么 | Mark 做什么 |
|--------|----------|---------|----------|
| **L3-MSI 战略情报** | 按规则出解读报告 | 不介入 | 定解读框架 (规则化) |
| **L3-MSE 战略执行** | 按规则跟踪 KPI | 不介入 | 定 KPI 体系 |
| **L3-IAO 保司接洽** | 定 Tier 规则, 审目标清单 | 执行接洽, 建关系, 做可行性 | 仅战略级保司亲自见 |
| **L3-IAC 保司合同** | 定让步边界, 审合同终稿 | 主导合同谈判 (按边界) | 战略级签字 |
| **L3-IRI 资源整合** | 跟踪整合进度 | 一线执行整合 (IT/数据/团队) | 不介入 |
| **L3-IBE 保司赋能** | 定深度分级, 定归属规则, 审赋能方案 | 执行具体保司的赋能动作 | 年度 review |
| **L3-IPI 产品上架** | 跨保司组合决策 | 单保司产品执行 | 战略级下架 |
| **L3-IMF 市场反馈** | 汇总跨保司洞察 | 单保司报告+沟通 | 不介入 |
| **L3-IRR 保司续约** | 分析+评估 | 执行续约谈判 | 战略级签字 + 关系变动介入 |

**关键点**:
- **A 做战略,B 做执行** — 每一列都体现这个原则
- **Mark 只出现在 3 列**: 战略级保司/战略级签字/关系变动 — 与 V0.2 减负清单一致
- **B 是"一张嘴"** — 一家保司的所有列都由同一个 B 族成员负责
