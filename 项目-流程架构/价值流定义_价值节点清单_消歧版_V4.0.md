## 一、方法论锚点

### 1.1 核心定义（沿用V3.0）

| 概念 | 定义 |
|------|------|
| 价值节点 | 多个L4在L3端到端闭环中咬合 → 真实数据冲刷 → 凝结成物理资产 |
| 不是什么 | 不是概念描述、不是SOP动作、不是L5动作单元、不是L4流程清单的1:1映射 |
| L3边界规则 | 「不能把佣金表到佣金表拆开」(Mark); L3属全公司, L4属部门; 严禁部门切碎L3 |

### 1.2 4大硬性属性 + 3重验证Gate（沿用V3.0）

| 属性/Gate | 含义 |
|-----------|------|
| ①业务定位 | 嵌入M0-M8战略闭环(每节点至少锚定1个M*) |
| ②价值属性 | 明确商业价值(对业务端/管理端的可表述价值) |
| ③物理对应 | 实体存在(Excel/PDF/系统记录·机器可读) |
| ④数据验证 | 跑得通底层数据(真实数据冲刷·非纸面流程) |
| Gate①挂数 | ≥1个量化KPI |
| Gate②落地 | 机器/系统可读物理产物 |
| Gate③追溯 | 100%回溯到L3+原始输入 |

### 1.3 M0-M8战略闭环（沿用V3.0）

| M* | 含义 |
|----|------|
| M0 | 底层数理基建(Carrie牵头): 产品标准化/ETL/数据字典/商业结算主题 |
| M1 | 中台品牌运营框架 |
| M2 | KPI报表体系 |
| M3 | NGP运营结构 |
| M4 | 业务与市场渗透 |
| M5 | AI与自动化战略 |
| M6 | 业务渗透 |

| M8 | 财务结算 |
