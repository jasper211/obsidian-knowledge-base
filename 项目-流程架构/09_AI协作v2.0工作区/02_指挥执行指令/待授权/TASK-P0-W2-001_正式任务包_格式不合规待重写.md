## 四、执行规范

### 4.1 核心规范（v3.0）

- **分析单元**：交付物（唯一主单元）
- **四标签**：A（类型规则风险）/ B（责任与执行断点）/ C（流转验证断点）/ D（授权级别）
- **E列**：每条规则空白必须写E列「业务语言翻译」
  - 禁止技术术语（不用「枚举」「ETL」「字段」「聚合逻辑」）
  - 必须指向具体业务方受访人
  - 格式：`这个数据空白意味着... / 应该去问... / 问的核心问题...`
- **数据表角色**：可选校验输入，不驱动规则空白识别。无数据表时字段信息标注⛔待确认

### 4.2 P0判断规则（三项同时满足）

```
P0 = B🔴交付物责任断点（单点/无复核/自填自审/治理真空）
   + D🔴高授权交付物（财务结算/合规/准入确权）
   + ❌规则缺口（完全无记录）
```

### 4.3 集群风险识别（规则空白地图完成后执行）

- 条件A：同一岗位归口P0级空白 ≥ 2条，且该岗位对应交付物 ≥ 3个
- 条件B：C4信号命中字段数 ≥ 20个，且集中在同一域/同一Owner
