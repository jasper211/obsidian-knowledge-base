# 财务管理重构 · 小组分工与工作计划

**版本**：V1.1 · 2026-05-16 · 已更新本周工作进展
**工作组**：Terresa（流程架构层）· Carrie（数据底座层）· 袁林（人员职责层）· 赵琦（规则治理层）
**对齐目标**：mp_086 SSOT 机制落地，构建财务 SPOF 防御底座

---

## 一、工作背景：为什么需要重构

### 三层问题叠加

**① 分析未结合实际管理现状**
- 现有 L3/L4 分析基于文档推演，缺乏对实际执行情况的核实
- 交付物状态（有执行/无标准/不存在）依赖主观判断，未经访谈验证
- 付款流程（L3-PAY）等核心流程的实际操作与数据库记录存在偏差

**② SPOF 风险实证暴露（Masaki 离职）**
- 财务关键岗位单点依赖，个人经验未代码化、未制度化
- 决策层 + 合规层 + 资金权限层三重失控同时暴露
- mp_086 五大机制当前全部 NO-GO，SSOT 数据模型尚未落地

**③ 工作缺乏围绕 L4 的结构化推进**
- 领导明确要求：工作需围绕 L4 展开
- 通过识别实际交付物和执行情况来核对数据库中现有 L4 是否准确
- 从 L4 修正向上驱动 L3→L2→L1 流程架构的重构

### 工作组应对策略

以 **L4 交付物** 为核心锚点，四人分别从**流程架构、数据底座、人员职责、规则治理**四个维度并行推进，产出互为输入，最终汇聚为财务 SSOT 数据模型（A5 行动项，Q3 末交付）。
