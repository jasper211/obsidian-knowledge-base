## 2. 岗位存在的根本理由 (为什么 M3 必须有这个岗位)

没有这个岗位,M3 的 Mark 减负就是空话,M4 的 AI 组织化就没有根。

**具体依据**:
- Mark 当前直接卷入 **29 条介入点**,其中 **16 条** 需要通过"授权 + 规则化"转出 → 全部落到这个岗位
- 保司相关 (VS-1) 介入点占全局 **50%** → 必须有专人承接战略层
- Mark 没有时间做日常保司战略分析+规则执行,但这些又不能交给普通 BD (过于战术)
- 这个岗位填补的是 "**CEO 战略级决策** 和 **BD 战术执行**" 之间的战略层空档

## 3. 核心职责 (直接引用介入点清单)

### 3.1 主导类 — 14 条 (Mark 授权 / 规则化)

**情报与战略分析** (L3-MSI / L3-MSE):
- **EP-001** 市场洞察战略解读 *(Mark 定框架,本岗位执行)*
- **EP-002** 价值主张设计与验证
- **EP-004** 竞争与获客策略制定
- **EP-006** 战略目标与 KPI 体系设计
- **EP-007** 市场进入策略整合

**保司接洽** (L3-IAO):
- **EP-047** 目标保司识别与 Tier 分级执行 *(Mark 定规则,本岗位跑规则)*
- **EP-051** 意向确认与可行性报告起草 *(给 Mark 看结论)*

**合同与授权** (L3-IAC / L3-IRI):
- **EP-062** 授权分级获取策略执行
- **EP-063** 合同谈判让步边界执行 *(Mark 定清单,本岗位谈)*
- **EP-067** 权限清单谈判支持

**赋能规则** (L3-IBE):
- **EP-075** 赋能深度分级规则执行
- **EP-077** 赋能业绩归属规则执行

**续约决策支持** (L3-IRR):
- **EP-089** 内部联合评估 (给 Mark 看结论)
- **EP-092** 续约条款升级谈判 (Mark 只签字)

### 3.2 支持类 — 8 条 (Mark 保留,本岗位准备弹药)

这 8 条 Mark **亲自做**,但本岗位负责分析/准备/跟进:
- **EP-003** 市场进入模式设计 (支持: 竞品扫描 + 可行性)
- **EP-005** 战略风险评估 (支持: 风险库 + 量化)
- **EP-008** 管理层汇报与决议 (支持: 决议材料)
- **EP-009** 战略调整与回滚机制 (支持: 数据 + 历史)
- **EP-055** 战略级保司差异化 (支持: 保司档案 + 方案)
- **EP-093** 保司决策层变动应对 (支持: 情报 + 应对库)
- **EP-094** Phase 3 升级联动 (支持: 数据 + 时机判断)
- **EP-096** 多年长约战略绑定 (支持: 合同草案 + ROI)

### 3.3 日常监控类 — 5 条 (A 族其余)

- **EP-066** 紧急授权调整 (按 SOP 执行,红线才到 Mark)
- **EP-082** 产品下架流程 (战术执行)
- **EP-088** 多保司数据对比授权
- **EP-091** 续约谈判或终止 (非战略级的)
- **EP-095** 终止后关系维护

### 3.4 职责不包括 (红线)

- ❌ 不负责 BD 一线执行 (BD团队负责)
- ❌ 不负责 CFO / 合规 / 法务专业审批
- ❌ 不负责权益中台的产品决策 (F 族)
- ❌ 不负责 VS-2/3/4 (只看 VS-1 保司)
- ❌ **不做秘书/助理类工作** — 这是战略岗,不是辅助岗

## 4. KPI 核心 3 项 (年度考核)

| KPI | 目标 | 权重 |
|-----|-----|-----|
| **KPI-1 保司战略 APE 贡献度** | VS-1 APE 增长率 ≥ 公司整体增长率 | 40% |
| **KPI-2 Mark 减负完成度** | Mark 在 A 族 14 条减负点的介入次数 ≤ 每月 2 次 | 35% |

- 不考核保司数量 (避免冲数字忽略质量)
- 不考核合同签约速度 (避免推动 Mark 过快决策)

## 5. 能力模型 (按优先级)

### 5.1 硬能力 (必备)

| 能力 | 要求 |
|-----|-----|
| **保险/MGA 行业洞察** | 5 年以上保险/经代/MGA 行业战略或 BD 经验 |
| **战略分析** | 能用数据 + 定性判断做可行性分析 + 风险评估 |
| **规则设计** | 能把 Mark 的战略意图转化为可执行的规则文档 (Tier/让步/归属/KPI) |
| **商务谈判** | 能独立主导保司商务谈判至终稿阶段,Mark 只需签字 |

### 5.2 软能力 (关键)

| 能力 | 要求 |
|-----|-----|
| **Mark 代言能力** | 能准确理解 Mark 战略意图并对外传达,不走形 |
| **跨部门协调** | 能协调 BD / 合规 / 财务 / 产品 / 权益 5 个团队 |
| **自驱** | Mark 不可能日常过问,需要高度自驱 + 定期 sync |
| **关系敏感** | 能识别保司决策层变动的早期信号 |

### 5.3 成长性能力 (可培养)

- Agent 协作能力 (M4 后会有战略分析 agent 给这个岗位用)
- 全球视野 (Phase 3 升级涉及跨境)

### 5.4 红灯 (不适合此岗位的特征)

- ❌ 只会执行不会思考 (此岗位 70% 是判断)
- ❌ 不能容忍 Mark 的战略改变 (Mark 会频繁调方向)
- ❌ 过于依赖权威 (需要有独立战略判断力)
- ❌ 情感型管理者 (此岗位更需要理性 + 规则思维)

**主要协同对象**:

- **合规部**: EP-062/063 合同谈判让步边界 → 每合同 1 次
- **F 族 权益中台**: EP-036/082 权益产品跨族协同 → 月度 1 次
- **Mark**: 每周 1 次 1:1 (30 分钟) + 月度战略 review (2 小时)

## 7. 招聘可行性评估

### 7.1 市场上能否招到?

**✅ 可以招到的来源**:
- 大型保司 (国寿/平安/太保/友邦) 的战略部/市场部 总监级
- 其他 MGA 平台的战略负责人 (竞品挖角)
- 外资险企 (AIA/Prudential) 的战略规划
- 咨询公司 (Oliver Wyman/BCG) 的保险条线资深顾问

**⚠️ 难点**:
- 真正懂 MGA 模式的战略人才稀缺 (MGA 在大陆是新物种)
- 能接受"服务 1 个 CEO + 高度执行压力"的战略人才少 (多数战略人偏好独立决策)
- 薪酬区间可能需对标大型保司总监级 (预计 120~180 万 HKD/年 包干)

### 7.2 内部提拔可能性

**✅ 内部候选观察点** (HR 模板回传后识别):
- 代理人事业部的资深 BD (熟悉业务但缺战略训练)
- 永明事业部的 GTD (Go-To-Market) 岗位
- 业务交付部的业务发展岗位
- Mark 个人认识的外部顾问

**建议**: **外招1正 + 内部培养1副** 的组合,既补外部视野,也留内部传承。

### 7.3 推荐招聘窗口

- **P0**: M3.4 新组织架构确认后立即启动 (外招 HR + 猎头)
- **P1**: M3.5 过渡路径确认后,副职从内部选拔
- **最迟**: M4 启动前到岗 (否则 Mark 减负落空, M4 没有接收人)

## 9. 与 M4 Agent 的协作边界 (前瞻)

此岗位在 M4 时会成为 **"肉身 + N 个 agent"** 的前沿案例:

| Agent | 用途 | 该岗位的使用方式 |
|------|-----|--------------|
| 保司情报 agent | 自动扫描保司动态 | 每天收 agent 简报,发现异常才深挖 |
| 竞品监控 agent | 竞品 MGA 动态追踪 | 周度 review |
| Pipeline agent | 保司机会池自动更新 | 每天看看板 |
| 合同条款 agent | 合同起草 + 差异对比 | 谈判前让 agent 出草稿 |
| 续约预警 agent | 流失信号预警 | 收到预警后人工介入 |

**预期效果**: 这个岗位 1 人管理 5~10 个 agent,产出效率相当于 3~5 个传统战略分析师。

5. **未考虑公司文化适配** — Mark 可能对某些软能力有隐藏偏好
