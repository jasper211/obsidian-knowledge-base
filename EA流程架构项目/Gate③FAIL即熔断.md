# Gate③FAIL即熔断

价值节点信号基线评估中，若Gate③追溯基础FAIL，即使Gate①和Gate②通过或部分通过，节点也被综合判定为熔断。例如VN-KAEM-02（Gate①PASS/Gate②PARTIAL/Gate③FAIL）和VN-KASC-01均因此熔断。
