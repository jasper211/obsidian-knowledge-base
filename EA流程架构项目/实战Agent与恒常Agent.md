# 实战Agent与恒常Agent

Agent分为两类：实战阶段性Agent（A0-A4）用于数据底座建设期，解决数据溯源、修复、缺口感知、增量更新、版本管理等临时性任务；恒常运转Agent（B1-B8）在系统成熟后长期运行，负责文档解析、质量巡检、报告生成、交互、洞察推理、反馈回写等持续任务。
