# Gate评估体系

VN-PAY项目使用三个Gate（挂数、落地、追溯）评估数据流程成熟度：Gate①挂数指数据是否已接入系统；Gate②落地指数据是否已持久化存储；Gate③追溯指数据是否可追溯来源和变更历史。状态分为PASS、PARTIAL、FAIL。
