# 独立基础设施级项目

experience-engine 被设计为独立的基础设施级项目，而非某个业务项目的子模块。这一架构判断的战略意义在于：独立版本号、API 调用复用、跨项目集成简单、估值倍数从 3-4x 提升至 8-15x，战略叙事从保险业务的工具变为行业 OS 的核心引擎。
