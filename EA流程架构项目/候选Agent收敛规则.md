# 候选Agent收敛规则

Skill候选先按l3_domain分组，再按l3_code细化。L3流程下Skill候选≥5条则独立为一个Agent，按核心职能命名；<5条则同一业务域内零散L3合并为长尾合并Agent。原则是功能聚焦，避免过度碎片化。
