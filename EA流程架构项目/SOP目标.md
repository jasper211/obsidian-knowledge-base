# SOP目标

本SOP用于将机构/Broker侧权益方案与服务项设计，从候选文案/资产台账/服务目录推进为可评审、可确认、可归档的方案输入包。只处理TOB机构侧服务配置，不处理TOC客户权益包，不承诺终端客户投保、转化、保费、佣金、返佣或无条件权益。

## EQ方案草稿阅读顺序

本页复用为 EQ 方案草稿的局部入口，适用范围是 TOB 机构侧服务配置，不是全公司 SOP 总入口。2026-08-30 已核对源 v0.1 SOP 第1节及第4节流程顺序；源文件仍声明为草稿，不替代机构确认版方案。

1. [[路径分流]]、[[方案编号规范]]、[[旧文档状态标记]]：分类、建档、识别候选材料状态。
2. [[服务项拆解要求]]：拆出候选 SKU、范围、排除项、供应来源和财务状态。
3. [[Gate检查]]：按风险触发确认要求。
4. [[方案评审与冻结]]、[[方案冻结前状态约束]]：评审、机构确认、冻结或记录待补，再移交下游。

需要进入服务项寻源与上架时，转到 [[L3-SOB流程目标]]。上述导航描述草稿步骤，不证明某个方案、财务结果或服务项已确认。原有 `as_of` 保留，不用本次核验日期覆盖。
