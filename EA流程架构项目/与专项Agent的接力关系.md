# 与专项Agent的接力关系

联合运营项目交付Agent与联合运营专项Agent是紧密相关但阶段不同的两个Agent：专项Agent负责需求诊断和条款/资源设计，交付Agent负责设计完成后的实际项目落地交付。两者共用同一份项目档案，建议不要拆成两份。
