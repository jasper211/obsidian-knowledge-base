# 主数据层

五层架构的第一层，包含19张表（17张维度表+2张桥接表），分为产品体系（4张）、渠道体系（5张）、合规体系（5张）、通用维度（5张）。所有下游事实表或规则表的外键最终指向该层的DIM表，数据质量决定整个体系准确性。
