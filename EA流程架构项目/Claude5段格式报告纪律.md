# Claude5段格式报告纪律

D 类配置示例：所有 Claude 实例必须遵守 5 段格式报告纪律，强制级别 MANDATORY。5 段内容：做了什么 / 检查了什么 / 没检查什么 / 决策分歧 / 已知未完成。禁用词汇：合规 / 通过 / 达标 / 0 重叠 / 验收通过。
