# 三级串联验证链

佣金Agent的验证环节必须设计为三级串联：一级自动对账（COM-11差异对照表）、二级人工强制签字（COM-13实派清单确认）、三级合规独立评估（COM-17 IA拦截），且第二级必须是Human gate，不能自动放行。
