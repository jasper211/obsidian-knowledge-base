# Gate检查

五个Gate及其通过标准：合规Gate（外宣、客户可见内容等需Teresa或合规法务确认）、法务Gate（合同范围、责任边界等需法务确认）、财务Gate（价格、成本、毛利等需Roy/财务BP/P&L owner确认）、供应商Gate（第三方履约、SLA等需供应商准入记录和SLA确认）、Mark Gate（高风险承诺、战略范围等需Mark裁定或审核记录）。
