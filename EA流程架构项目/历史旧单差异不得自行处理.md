# 历史旧单差异不得自行处理

历史旧单（14-23年）应收实收差异核对流程断代，原负责人已离职。不得自行处理，标记为'历史旧单-流程断代-待追溯'，上报管理层决定是否启动专项清理或豁免历史差异。
