# 预寻源与框架协议机制

为平衡上架效率与流程合规，推行预寻源与框架协议机制。服务采购专员前瞻性地根据产品规划，针对通用性高的A/B线资源，提前与优选供应商签署年度框架协议。当具体方案提出需求时，可在已批准的协议内直接调用，缩短寻源周期并满足合规要求。
