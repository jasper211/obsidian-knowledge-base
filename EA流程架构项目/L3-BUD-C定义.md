# L3-BUD-C定义

L3-BUD-C（预算执行与管控）是业务主导的预算执行监控流程，主责(A)为中台/业务线，财务承担R角色（月度监控报告编制、差异分析）。当前L4-BUD-C-02/03完全缺失，费用无管控，老板指标（费率=10）无跟踪机制。
