# L3-BUD-C预算执行流程

L3-BUD-C是预算执行与管控流程，属于B类（业务主导、财务参与）。拆分为3个L4子流程：月度业务执行数据收集、执行监控与超预算审批、差异分析与滚动预测。财务角色为R（监控报告）。核心风险是L4-BUD-C-02/03完全缺失，费用无管控，老板指标（费率=10）无跟踪机制。
