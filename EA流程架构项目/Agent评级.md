# Agent评级

Agent评级表示该L4交付物由何种Agent处理，包括Auto（自动）、Aug（增强）、Hybrid（混合）、Human（人工）四种类型。例如，L4-HRD-01人才招聘交付的Agent评级为Aug，L4-FOB-01合同签署的Agent评级为Auto。
