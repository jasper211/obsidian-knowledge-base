# release判定条件

进入production-ready的最低条件：P0决策全部有owner/date/evidence；registry中无未解释的hold/merge冲突；T1 schema校验通过；promotion manifest中无production blocker；每个被提升节点都有证据路径。未满足时只能作为staging或reviewed draft。
