# BSRV结算路径

BSRV层为核对确认层，机构结算由中台统一执行。结算路径为：牌照 → 塞尔斯 / RW / NGM / NGA（各机构对应路径不同）。下游关联L3包括L3-COM（佣金结算）、L3-SSVA（权益服务结算）、L3-STLM（塞尔斯结算）。
