# 优先级规则冲突处理

当同一L4存在多个数据来源时，优先级：1) Agent评分(Mark)优先；2) 价值节点+Agent都有则Agent优先，价值节点入备注；3) 仅价值节点则以其为准并语义补全评分；4) 语义推导准确性最低。
