# D1内部节点数量不一致

D1价值节点清单文件内部不同sheet的价值节点数量不一致：总览76节点，详情卡82节点，验证矩阵82节点，映射表86节点。标题声称72节点/9域，但实测不符。因此D1不能直接作为单一权威表，必须先裁定canonical node set。
