# TA作为新主逻辑

证据链主轴不应只按 TOB/TOI 分，应增加 TA 主轴：保司 -> JF -> RW -> 实际交付/成本 -> 合规留档。TA 是比 TOB/TOI 更上游的逻辑，现有证据箱需增加资金/合同/凭证串联视角。
