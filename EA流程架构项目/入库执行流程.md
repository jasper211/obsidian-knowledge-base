# 入库执行流程

读取源文件中的L3编码和名称后，依次检查：是否在删除列表（RD）→ 是否在R1~R5映射表 → 格式是否符合标准 → 同步更新L4前缀 → 写入数据库。无法匹配或格式不合规的记录标记“待人工确认”并不入库。
