# 生效通知断点

生效通知作为系统自动化产出，转达环节如有延迟或遗漏（代理人离职/漏发/渠道错误），客户对保障起始时间可能存在误解；缺少客户确认回执的系统闭环机制，无送达状态追踪。单点风险低。
