# Agent分类维度A业务颗粒度

按业务颗粒度分为：领域级Agent（横跨多个L4/Skill，类似项目经理）、VN/L3级专精Agent（对应具体价值节点或端到端流程）、子Agent（当VN/L3内部混杂多个不同触发节奏/验证标准的子流程时需再拆）。
