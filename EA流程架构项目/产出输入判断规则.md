# 产出输入判断规则

按优先级判断L4是否有产出表：P0强规则映射（如COM-03→Agg_Commission_Payable），P1 L4编码特定规则，P2关键词匹配（建档/录入/配置/上架/签订/生成），P3单表+创建类活动启发式，P4兜底归为输入表。分析/报告/监控/评估类活动即使有创建关键词也不判定为产出表。
