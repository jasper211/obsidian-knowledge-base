# L4唯一物理交付物

任何L4切分必须挂一个唯一的物理价值交付物（single physical deliverable），即可被他人接收、审计、引用的具体产物（如文档、数据表、系统记录、签字文件、凭证）。一个L4 = 一个交付物 = 一个A责任人 = 一段可独立完成的流程。不能是'完成某动作'或'状态变化'。
