# 决策支持协同型Agent

指H+H占比（Human+Hybrid步骤占全部L4的比例）超过50%的Agent，其定位类型为“决策支持/协同型”，表示该Agent以辅助人工决策和协同工作为主，而非完全自动化执行。在30个全量L4口径下，此类Agent从v2的7个增至12个。
