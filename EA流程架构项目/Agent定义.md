# Agent定义

Agent是一个具备五要素的闭环循环：发现（什么时候该干活）、交接（调用Skill执行）、验证（独立评估结果）、持久化（记住状态）、调度（决定下次触发时间）。跳过任何一个要素，循环会中断或盲目运行。
