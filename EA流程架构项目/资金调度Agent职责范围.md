# 资金调度Agent职责范围

资金调度Agent处理多主体间的资金调拨、归集、报告等资金流动本身，与银行账户管理Agent区分，后者负责账户基础设施维护。

2026-09-02回源边界：这是过程层Agent职责设计，不是获批岗位职责、系统实现或资金操作授权。主链、触发和当前注册范围统一从 [[资金调度流程]] 阅读。
