# L3-TRVL流程定义

L3-TRVL（机酒车服务执行）是出行公司负责的权益服务执行流程，属于价值流VS-5（权益服务企业客户旅程）的VS5-S5（服务执行）阶段。前置流程为L3-COB（客户入驻权益服务启动），后续流程为L3-SPO（服务跟踪处理与优化）。
