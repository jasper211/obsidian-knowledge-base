# 经代Agent覆盖范围

经代机构全周期Agent属于C族JF-03经代机构合作岗，覆盖6个L3：L3-ASD、L3-BSRV、L3-CRR、L3-IBEC、L3-NG、L3-RSJD，共10条L4，Agent类型为专家型Orchestrator。

2026-09-01定向回源：源Agent说明的“10条L4”对应正文主链选取，不是6个L3的注册全集。`[DATA]_L3L4_现行关系_v1.0.csv` 在这6个L3下有18个不同的已注册L4，10条主链编码均可在表中找到；其余8条未被机制说明列入主链，不能据此判定应删除或由其他Agent负责。关系表仅BSRV两行的maturity/evidence为PASS/VERIFIED，其余16行为PARTIAL；所有18行assessment仍是DRAFT，所以注册、发布或局部验证不证明完整Agent已实现、获批或运行验收。
