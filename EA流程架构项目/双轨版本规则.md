# 双轨版本规则

应派清单的版本管理分为业务轨和财务轨，独立运行不混用。业务轨：蔡依娜制作业务V0 → 王总/某某审批 → 理财师确认 → 业务V1（对账派发用）。财务轨：某某邮件发送财务V0 → Carrie接收 → 财务V1（记账付款用）。财务侧只接收最终版V1，不参与业务轨中间版本流转。
