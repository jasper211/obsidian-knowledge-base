# 闭环定义

单节点闭环指 3 个 Gate（挂数/落地/追溯）复评由 FAIL 变为 PASS，或经 Mark 显式延期（须带理由和重新触发条件）。整包目标为 T+3 月熔断率降至 0%，25 节点全 PASS 或显式延期。
