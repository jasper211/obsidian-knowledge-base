# 架构原则即时spec化

任何foundational原则（如L4唯一物理交付物）必须在发现后立即写入方法论spec，不允许“记在脑子里”。M2中G3-5a发现原则问题后立即暂停评审，先写入spec再继续，避免了后续返工。
