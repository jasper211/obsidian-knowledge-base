# 关系推导方法

实体间关系从两处推导，均在价值库内：①价值流的阶段动作 = '实体A对实体B做了什么'，例如VS-1保司→MGA的全生命周期（评估→授权→资源整合→上架→数据回流→续约）定义一组保司↔MGA关系；②价值节点的数据流 = 产出物在实体间流转，例如VN-PAY链给出佣金价值流：保司→MGA→理财师/销售员，MGA→转介渠道。每条关系挂具体价值节点+Gate+KPI。
