# L4 Agent化Tier分类

将L4活动按Agent化程度分为4级：Auto（完全Agent化，人只监督，15-18分）、Aug（Agent主导+人审批，10-14分）、Hybrid（人主导+Agent辅助，5-9分）、Human（必须人工，0-4分）。基于6维度评分（每维度0-3分，满分18分）。
