# 能力问题收割原则

能力问题不是设计的，是从已建好的价值链里'收割'的。EA价值库已经把能力做了正式建模——价值流/L1/L3/L4/价值节点 + S2B2A分层 + Gate分级 + 节点边界。能力问题模型 = 把这套既有结构投影成'本体必须能回答的问题集'，再由问题反推关系。协调角色只做投影与对齐，不新造能力。
