# source_absent 规则

当正式匿名汇总报表源缺失时，所有指标必须保持 source_absent 状态，不得填入估算数或业务预期，不得用于外发或价值承诺。指标仅保留口径，待正式源补齐并完成审批后方可冻结数值。
