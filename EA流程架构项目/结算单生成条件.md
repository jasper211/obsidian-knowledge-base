# 结算单生成条件

生成正式结算单需同时满足：服务已完成并有凭证、客户/机构验收或授权确认、Roy/财务字段为confirmed或not_applicable、双口径差异已说明、合同/法务/合规触发项已确认。否则仅生成内部草稿，不得外发。
