# 三类核心授权定义

分销授权(AUTH-D)：代理销售保司产品的基础授权，需通过KYC合规审查和系统对接；创新授权(AUTH-I)：与保司联合开发定制产品的授权，需精算团队配合和监管备案；渠道管理授权(AUTH-C)：管理保司在特定渠道分销的全权委托，需高层信任和长期业绩验证。难度排序：AUTH-D < AUTH-I < AUTH-C。
