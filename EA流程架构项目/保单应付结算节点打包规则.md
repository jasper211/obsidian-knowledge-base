# 保单应付结算节点打包规则

保单应付结算流程的4个P1节点（Agg_Commission_Payable、应派保单清单、应收实收差异对比表、实收表）属同一L3流程，建议打包为一个SOP制作任务，由业务支持牵头、财务配合，可减少独立任务数。
