# EA与experience-engine关系

公司有两个并行知识系统：EA 知识库面向组织运作（流程/岗位/价值流），experience-engine 面向经验资产化（原则/机制/Playbook/Agent 配置）。EA 为 experience-engine 提供 L3-L5 流程骨架，experience-engine 为 EA 提供 L0-L2 原则输入，两者通过 API 交互。
