# 四层产出物架构

系统核心架构分为四层：A 思维体系库（L0-L1，Mark怎么想，永不变的判断框架）、B 机制设计 Playbook（L2，组织怎么运转，让原则可执行的系统）、C 业务诊断 Playbook（L3，业务怎么做，数据驱动的执行工具）、D Agent Runtime Config（跨层，AI怎么协作，Agent实例的运行时纪律）。
