# L1价值链飞轮节点

企业只有1条价值链，由5个飞轮节点构成（L1-01至L1-05）：战略与市场洞察、保司资源整合、合作伙伴赋能、终端交付与结算、权益中台横切能力层。岗位分析需确定岗位主要归属的飞轮节点。
