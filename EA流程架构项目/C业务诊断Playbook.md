# C业务诊断Playbook

C 类产出物对应 L3 业务诊断，回答“业务怎么做”，是数据驱动的执行工具。例如诊断 #001：销售网络效率诊断。C 类 30-50% 业务通用，位于 domains/{insurance,新动力,...}/，跨保司需重新校准阈值和数据接口。
