# 保司长尾合并Agent身份

保司长尾合并Agent是B族(JF-02)的专家型Orchestrator，对应L3-IAO(保司合作接洽与评估)和L3-IRR(保司绩效评估与续约决策)两个L3流程，共6条L4，属于长尾合并类中保持不拆的Agent。

2026-09-03定向回源：源机制说明的“6条L4”是IAO选2条、IRR选4条的主链节点数量。现行关系表在L3-IAO和L3-IRR下分别有12条、13条已注册L4，共25条；源中6条均可找到。6与25是主链选取和注册全集两种口径，不是版本替代。25行assessment均DRAFT；IAO均PARTIAL，IRR虽PASS/VERIFIED仍不证明Agent合并设计获批或已运行。
