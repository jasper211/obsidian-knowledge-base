# KPI体系与Agent关联

不同Agent类型对应不同KPI维度：佣金Agent负责财务KPI（佣金利润率/成本率），自动计算偏离度触发预警；业绩Agent负责财务+客户KPI，自动生成业绩看板标注红黄绿灯；产品Agent负责客户KPI（SKU数/上架数），产品校验异常时联动KPI预警；赋能Agent负责能力KPI，赋能进度不达标时推送提醒。
