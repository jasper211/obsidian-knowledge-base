# GTM-C产品试点执行路径

GTM-C模式分三个阶段：快速验证（W1-W4，选定1~2个SKU、最小化合同签署、产品上架，退出条件：W4内未完成上架则终止）、数据收集（W5-W12，跑出首单数据、收集市场反馈、评估扩展可行性，退出条件：试点数据不达标则终止）、扩展决策（W13，达标则升级为GTM-B，不达标则终止并复盘）。
