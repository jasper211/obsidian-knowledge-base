# Agent分类维度C自动化定位

按自动化定位分为：自动化执行型（Agent能独立跑完绝大部分工作，人只在关键节点确认，所辖L4的Hybrid+Human占比<60%）和决策支持/协同型（Agent负责理清信息、摆出方案，实质判断由人主导，Hybrid+Human占比≥60%）。介绍候选Agent时应标注其类型。
