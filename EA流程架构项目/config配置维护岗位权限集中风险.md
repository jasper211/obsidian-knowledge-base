# config配置维护岗位权限集中风险

config配置维护岗位同时掌控dim_partner、dim_license、config_partner_routing、partner_tier_rules四张核心表的写入权限，且无独立复核机制。类比餐厅菜单定价、会员等级、折扣规则、收款账户由同一人维护，写错无人核对，导致自动计算错误且难以追溯。
