# 技术栈分阶段

M4 Agent建设不按L3业务线划分，而是按技术栈分为4个阶段：规则引擎→数据管道→告警→ML。每个阶段跨L3完成，同技术栈的Agent可共用开发团队、调试工具和部署流水线。
