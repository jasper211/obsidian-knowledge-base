# Multi-Agent协作链

存在三种协作链：数据维护协作链（并行触发型：源文件更新→A3→A0+A1并行→A4）；报告生成协作链（串行调用型：用户输入→B-RPT→Teresa界面→B-INT）；全局报告协作链（聚合型：管理层触发→B-GRP→全局报告→B8反馈回写）。
