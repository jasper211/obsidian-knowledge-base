# 标准处理动作

异常处理需执行8个标准动作：登记异常编号、记录触发时间来源和影响范围、判断等级、指定Owner和关闭时限、明确补救动作和沟通口径、记录每次沟通与状态变化、取得关闭确认、汇总复盘原因和预防动作。
