# 关单Gate条件

服务关单必须同时满足：需求编号和服务编号完整；已有服务商接单或执行确认；已有服务执行过程记录；已有合格交付凭证；已有客户/机构确认或等效确认；未关闭异常为0，或有经授权的带条件关闭说明；涉及费用、赔付、合同边界的事项已由财务/Roy、法务或合规确认。
