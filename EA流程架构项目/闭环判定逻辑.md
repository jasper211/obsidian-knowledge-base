# 闭环判定逻辑

Phase F提交Mark回执后，根据Mark回复决定闭环方式：Mark无回复→台账标注“完成-等待新任务”，任务挂起；Mark回复有问题→重新进入Phase A开启新轮次（任务编号加R2,R3...）；Mark下发新任务MD→旧任务关闭，新任务从Phase A开始。任务关闭的唯一方式是Mark明确说OK或下发新任务。
