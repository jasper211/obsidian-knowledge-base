# C族三岗位闭环

C族包含C0（机构归口管理）、C1（机构开发交付）、C2（机构日常运营）三个子岗位，形成“归口-开发-运营”闭环：C0定规则并管理团队，C1负责获取新机构并完成交付，C2维护存量机构健康度并提升运营效率。
