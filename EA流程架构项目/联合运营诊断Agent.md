# 联合运营诊断Agent

联合运营需求诊断Agent是C族(JF-03机构业务族，联合运营管理岗)中专用的合作伙伴需求分析与诊断Agent，负责处理新合作伙伴的资格预审和尽职调查，涉及牌照核查、股东穿透查册等深度合规动作，合规调查性质在C族中最强。
