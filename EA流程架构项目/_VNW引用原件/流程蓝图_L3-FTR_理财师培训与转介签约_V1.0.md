## §1 流程概览

理财师完成入职（转介协议签署）后进入培训与产品认证阶段，核心产出为**培训课程体系（含配套工具）**（VN-FTR-01，P1）。

总部正在建设资料库，包含配套督导工具、表格、培训课程，通过**微盘分发**（理财师自取或行政再分发）。现状：资料分发形式单一，缺乏按**角色/阶段/产品线**的精准推送机制，理财师需求匹配度不高。

**培训内容三轨**：
- **产品培训**：产品知识、条款、费率、销售话术
- **合规培训**：保险销售资质要求、IA合规规范
- **实战培训**：陪访技巧、话术演练（与L3-FOR首单陪跑衔接）

**前置流程**：L3-FOB（协议签署完成，系统开通）
**后续流程**：L3-FOR（培训完成后启动运营支持）

## §3 主干步骤（4步）

```
[Step 1] 培训需求评估与课程匹配
  L4-FTR-01 培训需求评估与课程安排 → 《培训安排计划》(Human)
  根据理财师背景（新人/有经验/从其他渠道转入）匹配课程模块
  结合90天培养计划，安排月1/月2/月3课程节奏
  ⚠️ 实际：无系统化需求评估工具，由组织发展经理经验判断

[Step 2] 产品与合规培训执行
  L4-FTR-02 产品与合规培训执行 → 《培训出席记录》(Human)
  产品知识：主销产品特色/费率/条款讲解
  合规要求：IA合规规范、非持牌销售禁止事项
  资料分发：通过微盘推送或行政分发

        ◆ Q1：理财师培训出席率是否达标？
        ↓
[Step 3] 实战演练与陪访准备
  L4-FTR-03 实战演练与陪访配对 → 《实战演练记录》(Human)
  销售话术演练（角色扮演、模拟客户）
  配对组织发展经理/团队长开展陪访
  为L3-FOR首单陪跑做准备

[Step 4] 培训课程体系维护与分发
  L4-FTR-04 资料库维护与分发 → 《培训课程体系》+配套工具[P1 VN-FTR-01](Aug)
  总部更新资料库（课程/督导工具/表格）
  通过微盘发布，组织发展经理/行政再分发给理财师
  ⚠️ 实际：分发机制单一（微盘统一推送），缺乏按角色/阶段的精准推送
```

## §4 判断节点

### Q1：培训出席率是否达标（Step 2后）
| 结论 | 后续路径 |
|------|---------|
| 出席率达标（核心课程全部完成） | → Step 3 实战演练 |
| 未达标 | → 补课安排，关键合规课程必须完成后方可出单 |
