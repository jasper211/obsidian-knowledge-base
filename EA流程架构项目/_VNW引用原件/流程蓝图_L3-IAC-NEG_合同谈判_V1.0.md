## 三、关键步骤（5步）

```
步骤1：让步边界确定
  └─ 执行L4-IAC-07：Mark确定《让步边界清单》（Mark必须介入）
  └─ 执行L4-IAC-06：制定《授权获取路线图》（分级策略）
  ⚠️ 注：《让步边界清单》目前无文档化基线，需建设合作范围/利益分配维度基线

步骤2：商务条款初步谈判
  └─ 执行L4-IAC-01：A族主导谈判 → 输出《商务条款备忘录》
  └─ 执行L4-IAC-12：如涉及跨境业务 → 处理《跨境合规附加条款》（条件触发）

    【判断节点1】商务条款是否在让步边界内达成一致？
      ├─ 是 → 进入步骤3
      └─ 否 → 上报Mark裁定 / 重新谈判

步骤3：合同草拟与内部审查
  └─ 执行L4-IAC-02：生成《合同草案V1》+ 内部合规审查
  └─ 执行L4-IAC-08：多部门会签并行（法务/合规/财务）→ 输出《会签记录》

步骤4：保司反馈与谈判迭代
  └─ 执行L4-IAC-03：处理保司修改意见 → 版本对比 → 输出《合同终稿》

    【判断节点2】合同终稿是否双方认可？
      ├─ 认可 → 进入步骤5，移交L3-IAC-AUTH
      └─ 有重大分歧 → 返回步骤2 / 升级Mark介入

步骤5：移交授权确认段
  └─ 《合同终稿》移交L3-IAC-AUTH → 触发授权签署与备案
```
