## 三、关键步骤（6步）

> **注：本流程已由7步调整为6步——删除原步骤3中的NDA签署动作（L4-IAO-11已废弃）**

```
步骤1：目标保司识别与优先级排序
  └─ 执行L4-IAO-01：多维度评分 → 输出《目标保司清单》
  └─ 执行L4-IAO-12：建立Pipeline看板持续追踪
  触发时机：季度考核节点 / 保司业绩跃升事件

步骤2：决策链图谱建立
  └─ 执行L4-IAO-06：识别保司内部关键决策人 → 输出《决策链图谱》
  └─ 执行L4-IAO-10：培养保司内部盟友（Human介入）

步骤3：首次接触与价值主张传递
  └─ 执行L4-IAO-02：B族负责首次接触 → 输出接触反馈
  （注：NDA签署步骤已删除，Mark确认实际不存在）

    【判断节点1】保司是否有初步合作意向？
      ├─ 有意向 → 进入步骤4
      └─ 无意向 → L4-IAO-08 长周期维护 / L4-IAO-13 记录备案

步骤4：定制化能力展示与尽调配合
  └─ 执行L4-IAO-03：生成《能力展示材料》并现场展示
  └─ 执行L4-IAO-04：配合保司尽调 → 输出《尽调回复材料》

    【判断节点2】尽调结果是否通过？
      ├─ 通过 → 进入步骤5
      └─ 未通过 / 有顾虑 → L4-IAO-07 竞品应对 → 重新展示

步骤5：竞品排挤应对与差异化策略
  └─ 执行L4-IAO-07：分析竞品MGA动向 → 输出《应对策略记录》
  └─ 执行L4-IAO-09：战略级保司差异化方案（Mark亲自主导，条件触发：仅战略级保司）

步骤6：意向确认与可行性评估 → 移交
  └─ 执行L4-IAO-05：整合信息 → 输出《可行性报告》草稿（⚠️ 待建设：报告框架存在，首次交付作为闭环锚点）
  └─ Pipeline状态更新（L4-IAO-12）

    【判断节点3】Mark是否批准推进合作？
      ├─ 批准 → 《可行性报告》Mark签批 → 触发L3-IAC-Neg
      └─ 暂缓 → L4-IAO-08 长周期维护，等待时机
```
