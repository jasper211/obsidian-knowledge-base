## 三、关键步骤（6步）

```
步骤1：产品元数据录入与佣金配置
  └─ 执行L4-IPI-01：结构化录入产品库 → 输出产品库条目（Auto）
  └─ 执行L4-IPI-02：佣金规则部署到规则引擎 → 输出佣金规则部署（Auto）

    【判断节点1】佣金规则沙箱测试是否通过？
      ├─ 通过 → 步骤2
      └─ 未通过 → 返回G族修正规则配置

步骤2：资源匹配与分发
  └─ 执行L4-IPI-03：规则路由将产品匹配至各业务线 → 输出《匹配表》
  └─ 执行L4-IPI-11：F族搭配权益方案 → 输出《组合方案》

步骤3：试运行与小范围测试
  └─ 执行L4-IPI-04：小范围测试 + 数据监控 → 输出《试运行报告》

    【判断节点2】试运行结果是否达标？
      ├─ 达标 → 步骤4
      └─ 未达标 → 修复问题后重新测试（执行L4-IPI-09异常处置）

步骤4：全面上架与发布
  └─ 执行L4-IPI-05：自动化发布 → 输出上架通知
  └─ 执行L4-IPI-06：版本管理归档 → 输出《版本变更记录》（Auto）

步骤5：Portfolio管理与业绩监控
  └─ 执行L4-IPI-08：多维Portfolio分析 → 输出《Portfolio分析报告》
  └─ 执行L4-IPI-12：业绩数据反馈管道接通 → 输出《反馈记录》（Auto，对接L3-IMF）
  └─ 执行L4-IPI-13：客户体验NPS监控 → 输出《体验监控报告》（Auto）

步骤6：产品生命周期管理（持续）
  └─ 执行L4-IPI-10：跨业务线迁移（按需）→ 输出《迁移记录》
  └─ 执行L4-IPI-07：产品下架（条件触发，需Mark战略确认）→ 输出《下架决议》
```
