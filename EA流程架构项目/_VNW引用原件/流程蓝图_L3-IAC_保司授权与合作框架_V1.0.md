## 三、关键步骤（7步）

```
步骤1：授权策略与让步边界确定
  └─ 执行L4-IAC-06：制定《授权获取路线图》（分级策略）
  └─ 执行L4-IAC-07：Mark确定《让步边界清单》（Mark必须介入）

步骤2：商务条款初步谈判
  └─ 执行L4-IAC-01：A族主导谈判 → 输出《商务条款备忘录》
  └─ 执行L4-IAC-12：如涉及跨境业务 → 处理《跨境合规附加条款》（条件触发）

    【判断节点1】商务条款是否在让步边界内达成一致？
      ├─ 是 → 进入步骤3
      └─ 否 → 上报Mark裁定 / 重新谈判

步骤3：合同草拟与内部审查
  └─ 执行L4-IAC-02：生成《合同草案V1》+ 内部合规审查
  └─ 执行L4-IAC-08：多部门会签并行（法务/合规/财务）→ 输出《会签记录》

步骤4：保司反馈与谈判迭代
  └─ 执行L4-IAC-03：处理保司修改意见 → 版本对比 → 输出《合同终稿》

    【判断节点2】合同终稿是否双方认可？
      ├─ 认可 → 进入步骤5
      └─ 有重大分歧 → 返回步骤2 / 升级Mark介入

步骤5：合同签署与监管备案
  └─ 执行L4-IAC-04：正式签署 + 监管备案 → 输出已签合同+备案号

    【判断节点3】是否需要紧急授权调整？（条件触发）
      ├─ 需要 → L4-IAC-13 Mark紧急裁定
      └─ 不需要 → 进入步骤6

步骤6：履约前置准备
  └─ 执行L4-IAC-09：跨部门履约前置清单确认 → 输出《履约前置清单》

步骤7：合同生效与信息同步
  └─ 执行L4-IAC-05：自动触发下游（DIM_License更新）→ 输出进入指令
  └─ 执行L4-IAC-10：生效通知自动分发 → 输出《生效通知记录》
  └─ 执行L4-IAC-11：版本归档 → 输出《版本变更记录》
  → 触发L3-IRI
```
