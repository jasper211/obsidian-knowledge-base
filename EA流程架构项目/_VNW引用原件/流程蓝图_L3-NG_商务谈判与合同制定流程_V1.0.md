## §1 流程概览

本流程承接 L3-IBRD「合作伙伴需求分析与诊断」输出的《尽职调查执行记录》与谈判策略，完成同行合作协议/合同的法律审核、商务谈判、正式签署与归档，输出 VN-NG-01「同行合作协议/合同终稿」，为后续合作运行与复盘提供合规依据。

**前置流程**：L3-IBRD（合作伙伴需求分析与诊断）
**后续流程**：L3-IBRD 合作运行 / L4-IBRD-09 合作复盘与决策

> ℹ️ **结构性偏差（D2 #14）**：实际执行中合同谈判与签署严重后置，常由交付经理在签单后补签；缺乏法务前置审核、SLA 标准模板与合同管理系统化归档。已按现状逻辑描述本蓝图，P0 建议建立合同前置签署机制与模板库。

## §3 主干步骤（2步）

```
[Step 1] 合同谈判与法律审核
  L4-NG-01 → 《合同谈判纪要》+《法律审核意见》(Aug)
  · BD/交付经理与同行机构就合作模式、分润、SLA 进行谈判
  · 法务合规介入审核合同条款与风险
  · 形成合同谈判纪要及法律审核意见（无标准模板，逐案产出）
        ↓
[Step 2] 合同签署与信息同步
  L4-NG-02 → 《合同终稿》+ 签署文件/协议(Auto)
  · 完成合同终稿定稿与双签
  · 将签署版合同 PDF 归档至合同管理系统
  · 同步关键条款至业务、财务、运营相关方
```
