## §1 流程概览

本流程是VS-1保司投放价值流的终结环节，在合作周期届满前启动，通过数据汇总→内部评估→联合评审→续约/终止决策的闭环，决定保司合作关系的延续、升级或终止，并触发后续处置动作。

**前置流程**：L3-IMF（保司市场反馈与数据回流）
**后续流程**：续约→重新进入VS1-S2（L3-IAC-Neg）；终止→资产回收；升级→L1-01战略层

> **V1.1核心修订**：
> - 续约/终止底线评估改为**定性评估，Mark逐案裁定**（删除APE达成率伪阈值）
> - 核心判断链：战略规划→策略执行→绩效反馈是否闭环
> - Phase 3升级触发标准：**保司意愿 + 内部团队匹配度 + 业务策略适当性（三条件AND）**

## §2 触发条件与输入物

### 触发条件
- **主触发**：合作协议到期前90天，系统自动触发续约评估流程
- **条件触发**：保司决策层发生重大人事变动（L4-IRR-09）
- **条件触发**：流失预警模型评分低于阈值（L4-IRR-06）
- **条件触发**：Mark发起Phase 3战略升级评估（L4-IRR-10），需满足三条件AND

### 输入物
| 输入物 | 来源 |
|--------|------|
| 合作周期业绩数据（保费/件数/活跃度） | FCT_POLICY / FCT_SALES_ACTIVITY |

| 保司满意度调研结果 | B族关系经理收集 |
| 原合作协议及条款 | 合同管理系统 |

## §4 判断节点

### Q1：内部评估结论（Step 2后）

> **V1.1修订：删除APE达成率伪阈值，改为定性评估**

| 结论 | 判断依据 | 后续路径 |
|------|---------|---------|
| 续约（标准） | 战略规划→策略执行→绩效反馈闭环，保司合作健康 | → Step 3保司联合评估会议 |
| 续约（升级） | 闭环良好 + Phase 3三条件AND均满足 | → Step 3 + 触发L4-IRR-07升级谈判 |
| 终止 | 战略规划→策略执行→绩效反馈链条断裂，无修复价值 | → Step 3 + 触发L4-IRR-04终止路径 |
| **Mark裁定** | 内部评估分歧，或链条部分断裂难以判断 | **Mark逐案裁定续约/终止/升级方向** |

### Q2：续约决策方向（Step 3后）

| 决策 | 后续路径 |
|------|---------|
| 标准续约 | → L4-IRR-04签署新合同 → Step 5执行 |
| 条款升级 | → L4-IRR-07升级谈判 → L4-IRR-13长约绑定（可选） |
| 终止合作 | → L4-IRR-04签署终止协议 → Step 6终止路径 |

### Phase 3升级触发（Step 7，三条件AND）

| 条件 | 说明 |
|------|------|
| 保司意愿 | 保司主动表达深度合作意愿 |
| 内部团队匹配度 | 我方具备支撑Phase 3的团队能力与资源 |
| 业务策略适当性 | 当前业务策略适合推进更深层次合作 |
> 三条件缺一不可（AND），任一条件不满足则不触发Phase 3
