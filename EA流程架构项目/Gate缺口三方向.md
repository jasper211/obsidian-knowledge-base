# Gate缺口三方向

每个熔断节点的Gate缺口分为三个方向：Gate①挂数（KPI挂接未建立，需访谈确认KPI并完成挂接）、Gate②落地（交付物不可机器读取或缺乏实体载体，需建立标准化模板）、Gate③追溯（数据链路不可追溯，需建立输入-处理-输出追溯链）。
