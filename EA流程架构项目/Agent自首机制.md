# Agent自首机制

SOP的终极效果不是拦住违规，而是让违规可被察觉并披露。Agent能自首 = SOP真正运作的标志。自首率是SOP质量的KPI，不是违规率。好公司不是员工不犯错，而是员工犯错时能第一时间说出来。
