# 节点ID格式

每个价值节点有唯一的节点ID，格式为VN-{域缩写}-{序号}，例如VN-PAY-01表示PAY域的第一个节点。域缩写包括PAY、MGA、EQ、HR、INS、IBRD、URD、KASC、KAEM、KAET、KAOP、KAGA、BAM、CFM、FLM、FOB、FTR、FOR、FBA、FPG、RSJD、ASD、HRD。
