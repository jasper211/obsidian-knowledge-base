# L3-TRVL重复编码拆分

原L3-TRVL编码下包含8个不同业务域的活动，通过按业务域关键词（如'机酒车'、'商考'等）拆分为对应的L3编码（L3-TRVL、L3-ACTV、L3-IMED等），确保每个L3编码只对应一个业务域。
