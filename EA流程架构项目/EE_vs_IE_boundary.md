# EE vs IE boundary

EE receives stable objects, object attributes, artifact/evidence descriptors, KPI anchors, provenance, and domain relations. IE receives workflow boundaries, L3/L4 process relations, gate assessment, improvement backlog, action/decision candidates, and status-machine fields. Shared audit records preserve source file, version, update date, registry evidence, decision owner, and promotion state.
