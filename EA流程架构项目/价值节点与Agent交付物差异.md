# 价值节点与Agent交付物差异

Phase2价值节点偏向系统/数据/配置的实体产出（如DIM_License、Config_XXX），而Agent物理交付物偏向管理/业务文档（如《标准化政策库》、《周度任务清单》）。同一L4的两类交付物描述存在显著差异，例如L4-COM-01的价值节点是“佣金准入表”，Agent交付物是《标准化政策库》。
