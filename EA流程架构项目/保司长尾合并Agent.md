# 保司长尾合并Agent

保司长尾合并Agent是B族（JF-02保司关系族）下的一个专家型Agent，对应L3-IAO（保司合作接洽与评估）和L3-IRR（保司绩效评估与续约决策）两个L3，共6条L4。该Agent规模小，且两个L3是保司关系生命周期的前后阶段，因此保持不拆。
