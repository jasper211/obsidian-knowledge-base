# Gate确认矩阵

Gate确认矩阵定义了六个Gate（法务、合规、财务/Roy、运营owner、机构接口人、MARK），每个Gate有特定的触发条件和确认问题。例如，法务Gate涉及合同主体、责任边界等，合规Gate涉及客户数据、监管等。每个Gate需要确认人、日期和证据链接才能生效。
