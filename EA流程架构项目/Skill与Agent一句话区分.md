# Skill与Agent一句话区分

Skill回答'这一步具体怎么做'，Agent回答'这一整件事什么时候该做、做完了怎么判断对不对、下次什么时候再做'。写Skill前先问生成前提是否满足，说一个东西是Agent前先问五要素能否填满、独立评估者是谁。
