# 基础设施优先原则

M4 Agent建设应优先建设数据管道、规则引擎、告警系统等基础设施，再建设业务型Agent。原因是80条Auto L4中有34条依赖共同基础设施，先建基础设施可使后续Agent开发效率提升3~5倍。
