# 路径分类

服务资源分为三类：外部标准服务资源（如出行、酒店）、内部服务能力（如培训、运营支持）、外部专业服务（如法律、税务）。不同类型上架重点不同，外部标准需供应商准入和SLA，内部需Owner和SOP，外部专业需专家资质和合规法务。
