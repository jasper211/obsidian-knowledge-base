# 自首机制

Agent 主动察觉并披露自身违规的行为，是 SOP 真正生效的标志。自首需要三个条件：违规概念存在、可见信号（如 CI 失败）、自首获得正反馈。自首率（自首次数/违规次数）是 SOP 质量的 KPI。
