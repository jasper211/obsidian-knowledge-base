# 理财师业务分析Agent定义

D族(JF-04)与E族(JF-05)共享的专家型Agent，对应L3-FBA理财师业务分析，仅1条L4，为理财师全周期各阶段提供数据参考，自身不是周期环节。

2026-09-06定向回源及关系表校准：源Agent说明的“仅1条L4”是当时只选L4-FBA-01的极简设计；现行关系表在L3-FBA下注册FBA-01至04共4条，均DRAFT/REGISTERED/PUBLISHED/PARTIAL。故本页保留为历史设计入口，不能覆盖当前注册全集，也不能证明月度/季度调度、数据汇总或Agent已运行。

直接同源页已统一接回本入口：[[单一步骤编排]]、[[L4-FBA-01任务]]记录旧单步设计；[[纯周期性触发]]、[[调度固定月度季度]]记录调度设想；[[持久化单位]]记录数据持久化设想；[[验证标准为数据准确性]]与[[验证评估者待确认]]记录验证设计及未决角色；[[辅助职能定位]]记录横切能力定位。它们不再挂到SOB、A族、D/E族或理财师全周期Agent来冒充那些对象的正式事实。
