# 理财师全周期Agent

覆盖理财师从招募到常规运营完整生命周期的专家型Agent，由D族（运营族）和E族（发展族）共享，对应5个L3（FLM、FOB、FOR、FPG、FTR）共9条L4。目前共享是因为数据颗粒度不支持区分运营总监视角和辅导长视角。
