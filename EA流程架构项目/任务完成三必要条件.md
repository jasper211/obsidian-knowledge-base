# 任务完成三必要条件

熔断节点补建任务完成需同时满足：1) 交付物为物理产物（SOP文档/数据库表/系统/流程图等）；2) 交付负责人完成口述录音（SSOT）；3) 交付负责人确认Jasper转录内容无误。缺一不可。
