# MGA商业模式

本公司 = 保险行业MGA平台（S2B2A模型）。S = 平台/中台（本公司）— MGA授权+牌照+运营能力；B = TOB机构（经代/家办）+ KA/TOA（个人IP）；A = 理财师/代理人；C = 终端客户。MGA核心价值：替保司运营半个业务，从保司获取分销/定价/创新权，整合保司资源，并通过营销/销售/场外支持/一线培训全面赋能保司。
