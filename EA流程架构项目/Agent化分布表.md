# Agent化分布表

每个岗位族需输出一张Agent化分布表，包含L3编码、L3名称、L4总数、Auto（自动）、Aug（增强）、Hybrid（混合）、Human（人工）数量，以及自动化率（(Auto+Aug)/总数）。数据来自L4_核心交付物全量表_v5.csv的M2_Tier字段。
