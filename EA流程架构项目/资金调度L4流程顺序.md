# 资金调度L4流程顺序

L4流程顺序为：CFM-01收款预测收集 → CFM-02付款计划汇总 → CFM-04跨主体资金调拨方案制定 → CFM-05资金池归集与监控 → CFM-06体系外资金对账 → CFM-08现金流报告编制与报送，最终输出报告。

2026-09-02对照现行关系表：上述6条均为已注册L4，但L3-CFM另有已注册的CFM-03现金缺口识别与应对、CFM-07银行结余台账维护。故6条是源Agent说明的主链选取，不是L3-CFM完整注册覆盖；8行assessment均DRAFT且maturity/evidence均PARTIAL，不证明顺序已获批或执行。
