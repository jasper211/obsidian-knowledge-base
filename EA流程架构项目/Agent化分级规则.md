# Agent化分级规则

根据6维总分将L4分为四级：A-Auto（15-18分，可完全Agent化，P0优先建设）、A-Aug（10-14分，Agent主导+人审批，P1同步建设）、A-Hybrid（5-9分，人主导+Agent辅助，P2建设辅助）、A-Human（0-4分，必须人工）。
