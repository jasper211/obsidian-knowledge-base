# 分层七级加S2B2A

能力分层采用EA已有七级结构：价值流VS → 价值阶段S → 价值活动 → L1价值链 → L3流程 → L4交付物 → 价值节点VN（物理资产）。叠加纵向S2B2A分层（S上游=保司、B=机构·KA·企业客户、A=理财师·代理人、C=终端客户）。边界铁律：L3属全公司，L4属部门；严禁部门切碎L3。
