# 需求侧驱动转变

核心逻辑由「供给侧驱动」（中台产出什么给什么）转变为「需求侧驱动」（前线要执行哪类经营动作，中台按需配置对应内容物料）。落地路径：交付经理明确CTS动作类型 → 中台精准制作对应层级营销包 → 三级审核后推送 → 运营回收数据驱动迭代。
