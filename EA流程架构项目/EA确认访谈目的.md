# EA确认访谈目的

EA确认访谈不是重新审计EA项目，而是将已生成的reviewed draft转化为可进入下一轮EE/IE写回准备的确认结果。只确认四类事项：域边界是否成立、节点合并是否成立、hold节点状态、synthetic/replacement T1字段是否可作为EE/IE staging依据。
