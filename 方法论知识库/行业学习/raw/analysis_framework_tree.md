**使用建议**：
1. **先复制整棵树**到你的笔记工具（Obsidian/Notion/飞书均可）
2. **从 `Data → Dimensions` 开始填**，把你的实际维度和指标先放进去
3. **再填 `Themes`**，每个业务主题写一个 Domain 卡片
4. **最后填 `分析模型库`**，把你的分析方法论沉淀下来
5. 所有 `[+]` 标注的项都是**可选项**，根据你的项目阶段逐步补充，不要一上来就全填
