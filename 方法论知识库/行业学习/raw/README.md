# raw/

原始资料层。人工放入 AI 协同方法论相关的行业文章/报告/文字稿原文，AI 只读不改。

## 支持的文件格式

- **纯文本 / Markdown**：直接放入，最稳妥
- **PDF**：可以直接放入，Claudian 能原生读取解析
- **Word（.docx）等其他格式**：**不建议直接放入**——.docx 本质是压缩包裹的 XML，
  不是纯文本，Claudian 大概率读不出内容。放入前先导出成 PDF 或纯文本/Markdown。
- 图片类资料（截图、扫描件）同理，先转成 PDF 或用 OCR 转文字后再放入
