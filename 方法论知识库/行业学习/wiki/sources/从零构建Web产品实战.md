## 核心案例：AI内容创作助手

### 产品设计

**输入**：主题、平台、人群、风格、关键词、图片
**处理**：调用 DeepSeek V4 API 生成内容
**输出**：标题、正文、标签、封面建议、发布包

### MVP 边界（聚焦完成）

**做**：
- ✅ 表单输入与配置（主题、平台、风格、图片）
- ✅ 内容生成（调用 DeepSeek V4）
- ✅ 结果展示与复制
- ✅ 浏览器本地存储历史

**不做**：
- ❌ 用户登录/注册
- ❌ 支付与会员系统
- ❌ 后台管理
- ❌ 数据库存储

**核心原则**：先完成 "生成内容 + 复制发布" 的完整闭环

## 技术栈与工具

### 前端技术
- **框架**：Vite + React（启动快、配置少）
- **样式**：Tailwind CSS（快速美化UI，无需复杂CSS）
- **存储**：localStorage（浏览器本地保存）
- **API**：fetch（原生调用大模型接口）

### 关键工具
- **开发IDE**：Cursor（本节课主工具）
- **运行环境**：Node.js 18+
- **API调用**：DeepSeek V4 API

### 后续升级（可选）
- **框架升级**：Next.js（支持SSR和API Route）
- **API安全**：Serverless 函数转发请求
- **数据持久化**：数据库 + 云存储

---

## DeepSeek V4 API 特性

### 核心能力
- **100万token上下文**：一次处理整本长文档
- **双规格模型**：
  - V4-Pro：复杂推理首选
  - V4-Flash：速度快、成本低
- **OpenAI兼容格式**：直接适配现有工具链

### 定价策略
- **峰谷定价**：高峰时段（9-12/14-18）为平时2倍
- **推测性解码**：速度提升60-85%
- **非高峰调用**：成本极低

## 实战步骤总结

### 初始化项目（5条命令）
```bash
npm create vite@latest .      # 选择 React + JavaScript
npm install                    # 安装依赖
npm install -D tailwindcss    # 配置 Tailwind CSS
npm run dev                    # 启动开发服务器
# 浏览器打开 localhost:5173
```

### 开发流程
1. **Cursor 打开项目** → 让AI先读取目录结构
2. **分模块开发**：表单 → API调用 → 结果展示
3. **逐步验证**：每个模块完成后本地测试
4. **优化交互**：Loading状态、错误提示、历史记录

### API安全指南

**开发阶段**：
- 可使用临时Key在浏览器localStorage存储
- 仅限本地开发环境

**正式上线**：
- ❌ 不能将Key写死在前端代码
- ✅ 必须使用后端代理（Vercel Serverless Function等）
- ✅ 环境变量管理敏感信息

## 核心启示

### 1. MVP 的真正含义
**不是偷懒，而是聚焦**
- 先做最小可用版本
- 快速验证市场反馈
- 再逐步扩展功能

### 2. 非技术人也能做产品
- Cursor + 简单提示词 = 代码生成
- 不需要懂代码，只需懂业务逻辑
- 关键是清晰的Spec和验收标准

### 3. 从工具到产品的路径
```
想法（一句话描述）
  ↓ 五要素表达（维度4）
需求（具体的Spec）
  ↓ 工作流（核心工作流）
代码（Cursor生成）
  ↓ 测试验证
产品（可运行的网站）
  ↓ 部署上线
商业化（开放API、会员等）
```
