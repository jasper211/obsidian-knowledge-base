# 价值节点信号提取基线 V1.0

> **数据源**: `03_发布成果-交付物/权威数据/D1_价值节点清单_V3.22.xlsx`
> **方法论**: 4硬性属性 + 3重验证Gate + M0-M8锚定
> **用途**: Agent自动化评估(D1-D6) / KPI穿透 / 数据表建模 / 规则提取
> **版本**: V1.0 · 2026-06-12 · Jasper

---

## 一、信号提取规则

### 1.1 信号定义

每列"可提取字段"格式: `字段名(枚举/数值/文本) | 来源位置`

### 1.2 可提取性标记

| 标记 | 含义 |
|------|------|
| ✅ | 物理产物存在 + 数据可结构化 + 可直接提取 |
| ⚠️ | 物理产物存在但格式不标准 / 需OCR / 需要人工解析 |
| ❌ | 物理产物缺失 / 完全纸质化 / 零数据 |

### 1.3 自动化潜力评分(初步)

| 分数 | 含义 |
|------|------|
| D6=9 | 全自动(API/DB直连) |
| D5=7 | 半自动(ETL/脚本) |
| D4=5 | 模板驱动(Excel模板+宏) |
| D3=3 | 需AI解析(OCR/NLP) |
| D2=1 | 纯人工 |
| D1=0 | 不存在 |
