## 二、各表溯源方案

### 表1：dim_l3 — 全量82条

**校验对象**：全部82条，不抽样

**字段对照规则**：

| DB字段 | 来源文件 | 来源文件列名 | 合规标准 |
|--------|---------|-----------|---------|
| l3_code | S1 | L3编码 | 完全一致，格式L3-[A-Z]{2,6} |
| l3_name | S1 | L3名称 | 完全一致 |
| l1_code | S1 | L1编码 | 完全一致，值为L1-01~L1-05 |
| l1_name | S1 | L1名称 | **必须完全匹配以下5个权威名称之一，不得有任何偏差**：<br>资源获取与产品整合 / 市场设计与合作伙伴发展 /<br>运营反馈与路由决策 / 能力赋能与增长驱动 /<br>价值增值与生态绑定 |
| vs_code | S2 | vs_suggested | 一致，或非VS级=NULL |
| vs_stage_code | S2 | stage_suggested | 一致，或非VS级=NULL |
| is_vs_level | S2 | vs_suggested | vs_suggested='非VS级'→DB值=0；其他→DB值=1 |

**特殊处理**：
- S2中confidence='中'的3条L3（L3-CFRM/L3-SRA/L3-SPD），DB的confirmation_status应为`needs_review`，T2标注"待Mark裁定，已标记"，不算异常
- S1中`L3-ISD`在S2中出现但已被拆分为多个编码（ACTV/BRND/COCH等），T2确认dim_l3中**不存在**L3-ISD，拆分后的编码全部存在

**输出**：`T2_dim_l3_verification.csv`

```csv
l3_code,l3_name_db,l3_name_s1,l1_code_db,l1_code_s1,l1_name_db,l1_name_s1,vs_code_db,vs_code_s2,is_vs_level_db,is_vs_level_expected,result,note
```

**抽样规则**：每个VS（VS-1到VS-5）各取20行，共100行

**核心校验字段**：

| DB字段 | 来源文件S3 | 合规标准 |
|--------|---------|---------|
| vs_code | vs_code列 | 完全一致（VS-1~VS-5） |
| stage_code | stage_code列 | 完全一致 |
| activity_code | activity_code列（对应L3） | 完全一致，且存在于dim_l3 |
| stage_name | stage_name列 | 完全一致 |

**特殊校验**：确认dim_value_stream中**不存在**旧编码（如`L3-MSI`/`L3-MSE`/`L3-BMD`/`L3-BME`），这4个是已被移除的旧概念分组码。

```sql

WHERE activity_code IN ('L3-MSI','L3-MSE','L3-BMD','L3-BME');
```

### 表4：dim_agent_capability — 专项校验

**来源文件**：S5（`L4_核心交付物全量表_v5.csv`）

**4-A：m2_tier字段全量校验（400条）**

S5的M2_Tier列是DB的m2_tier字段的直接来源，必须完全一致：

| DB字段 | S5列名 | 合规标准 |
|--------|--------|---------|
| m2_tier | M2_Tier | **完全一致**，值为Auto/Aug/Hybrid/Human |
| agent_type | M2_Tier | **必须与m2_tier相同**（FIX-03执行后） |

**关键检查**：agent_type和m2_tier必须一致，如有不一致（如agent_type=Assist但m2_tier=Aug），标记为`FIX-03未完成`。

```csv
l4_code,m2_tier_db,m2_tier_s5,agent_type_db,is_agent_eq_m2tier,result,note
```

**4-B：deliverable字段抽样（120条）**

S5的核心交付物列 → DB的deliverable字段：

```csv
l4_code,deliverable_db,deliverable_s5,is_match,note
```

注意：S5中部分deliverable来源标注为"语义推导"（非直接从文档提取），这类记录T2标注`inferred`，不算MISMATCH，但要统计比例。

**4-C：D1-D6评分字段抽样（50条）**

S5包含D1_输入结构化到D6_合规可编码共6个评分维度，抽样确认dim_agent_capability中是否保留了这些字段，如有保留则校验一致性。

## 三、异常分类标准

| 类型 | 判定条件 | 处理 |
|------|---------|------|
| MATCH | DB值与来源文件完全一致 | 正常 |
| FORMAT_NORM | 格式标准化（中文→英文枚举，名称缩写展开等） | 可接受，标注 |
| MISMATCH | 内容实质不同（非格式转换） | 列入修复清单 |
| NOT_FOUND | DB有记录，来源文件找不到对应行 | 列入溯源缺失清单 |
| INFERRED | 来源文件标注"语义推导"，非直接提取 | 标注，统计比例 |
| NEEDS_REVIEW | confidence=中，待Mark裁定 | 标注，不算异常 |
