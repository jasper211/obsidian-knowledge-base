## 一、模板用途

本模板用于**结构化记录**中台（菲菲 / 交付经理）对同行机构开展的尽职调查全过程，将当前分散的口头沟通、微信记录、牌照截图等非标准化信息转化为**统一的、可归档的、可审计的**尽调执行记录。

**核心目标**:
1. 替代当前"分散记录（口头+微信+截图）"的非标准化状态，产出 VN-IBRD-01 的**机器可读物理产物**
2. 完整覆盖 VN-IBRD-01 价值节点的五项构成：牌照核查结果 + 保司Alice确认 + 团队配置 + 业务模式 + 过往经验
3. 作为 A-02 决策树的**前置输入**：尽调结论（J类）直接触发合作路径判断
4. 作为 B-01 模板的**下游文档**：B-01回答"是谁"，A-03回答"怎么样"

**使用场景**:
| 来源线 | 尽调执行人 | 填写人 | 使用时机 |
|:---|:---|:---|:---|
| 江通线 | 菲菲（主导）+ 相关部门协助 | 菲菲 | B-01收件确认后，启动L3-IBRD流程时 |
| 白博文线 | 交付经理（主导）+ MOMO协助 | 交付经理 | MOMO商务条款对接后，交付经理承接签单前 |

**与B-01的关系**:
- **B-01**（上游）：收集"同行是谁"——机构基本信息、牌照状态、来源追溯
- **A-03**（本模板）：记录"同行怎么样"——深度核查、团队详情、业务模式、风险评估、尽调结论
- **A-02**（下游）：基于A-03的J类结论，执行合作路径判断

> **边界说明**: 本模板仅规范尽调记录的**字段和格式**，不规定尽调的具体执行方式（现场/远程/第三方）。执行方式由中台根据同行机构情况灵活选择，但执行结果必须按本模板记录。

## 四、尽调执行流程与字段对应关系

尽调执行遵循 L3-IBRD 的 8 步流程，每步对应填写 A-03 的特定字段：

| 步骤 | 动作 | 对应A-03字段 | 说明 |
|:---|:---|:---|:---|
| **步骤1** | 根据牌照核查结果判断合作路径 | E类全部 + F类"是否有永明合约" | 核实B-01的A类字段，深化牌照核查 |
| **步骤2** | 与前端沟通了解详细背景 | G类"核心人员名单"初识 + H类"与竞品MGA合作情况" | 利用前端渠道的信息优势 |
| **步骤3** | 调研业务模式+团队配置 | G类全部 + H类全部 | 核心尽调内容，需与同行深入沟通 |
| **步骤4** | 建群邀请入群 | — | 组织层面的动作，不直接产生尽调字段 |
| **步骤5** | 安排会议 | — | 会议中核实和补充E/F/G/H类字段 |
| **步骤6** | 尽调+发协议+处理佣金 | F类"Alice确认记录"+I类全部 | 深度尽调阶段，识别风险 |
| **步骤7** | 签约后建立服务群 | — | 签约动作，不直接产生尽调字段 |
| **步骤8** | 首单特别跟进 | J类"后续跟进建议" | 基于尽调结论制定跟进计划 |

**白博文线差异**: 白博文线执行路径不同（MOMO对接商务条款→交付经理签单→合同后置），但尽调记录字段不变。差异在于：
- 步骤1-3由MOMO在商务条款对接阶段并行完成
- 步骤6的"尽调"深度可能较浅（因BD已谈好）
- 需在J类"尽调结论"中标注"白博文线·合同后置"，提示履约风险

## 五、与A-02决策树的衔接

| A-03字段 | 对应A-02决策树 | 衔接说明 |
|:---|:---|:---|
| **E类·牌照深度核查结论** | 判断节点0（来源线判断）的辅助输入 | 牌照合规性影响来源线分配（如牌照异常，可能需特殊处理） |
| **F类·是否有永明合约** | 判断节点1 | B-01已收集，A-03核实确认 |
| **F类·是否有佣金率** | 判断节点2 | B-01已收集，A-03核实确认 |
| **F类·Alice确认记录** | 判断节点1/2的验证依据 | Alice确认确保合约真实性，避免虚假信息 |
| **H类·业务模式评估结论** | 影响路径A/B的后续步骤设计 | 高匹配度→标准7步；低匹配度→定制化方案 |
| **I类·综合风险等级** | 影响合作优先级和审批严格程度 | 高风险→需额外审批；低风险→快速通道 |
| **J类·合作路径建议** | **直接输出至A-02判断结果** | J类结论是A-02的输入，触发后续执行流程 |
| **J类·合作优先级** | 影响资源分配和跟进频率 | 高优先级→TR重点跟进；低优先级→定期培育 |

**衔接规则**:
1. A-03 填写完成 → J类结论确定 → 启动 A-02 决策树
2. 若 J类建议"JF/UNIVIN"→ 按 A-02 对应路径执行
3. 若 J类建议"暂不推进"→ 退回前端或归档观察
4. 若 J类标注"边界Case：已有合约+已有佣金率"→ 提交 Mark 裁定
