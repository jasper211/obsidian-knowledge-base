## 执行逻辑

用Python脚本读取数据，结合JD内容，按标准生成每族的矩阵MD文件。

**核心逻辑（generate_m0m8_matrix.py）**：

```python
# 伪代码逻辑，VS Code自行完善

for job_family in ['B', 'C', 'D', 'E', 'F', 'G']:
    # 1. 读取该族JD（从MD文件提取岗位定位/职责/KPI/EP）
    jd_content = read_jd(f"JD_{job_family}_xxx.md")
    
    # 2. 确定该族主要L3
    l3_list = get_l3_by_vs(job_family_vs_mapping[job_family])
    
    # 3. 从v5文件提取L4/交付物/Agent数据
    l4_data = df_v5[df_v5['L3编码'].isin(l3_list)]
    
    # 4. 从穿透表提取KPI数据
    kpi_data = df_kpi_job[df_kpi_job['岗位族'].str.contains(job_family)]
    
    # 5. 按M0-M8逐层填充矩阵
    matrix = build_matrix(jd_content, l4_data, kpi_data)
    
    # 6. 写出MD文件
    write_md(matrix, f"output/{job_family}族_M0M8涉及度矩阵_V1.md")
```
