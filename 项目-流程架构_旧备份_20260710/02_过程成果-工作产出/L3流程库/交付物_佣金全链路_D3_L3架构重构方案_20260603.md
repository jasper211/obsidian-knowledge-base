# D3 - 佣金全链路 L3-L4 架构重构方案

> 生成时间: 2026-06-03
> 原则: 端到端完整性 + Mark 裁定执行 + L3 变更最小化 + 价值节点收敛
> 依据: Mark 2026-04-11 裁定方案 A（合并 COM-01/02/03 为 COM）

---

## 一、当前架构问题诊断

### 1.1 核心问题：合并裁定未执行

Mark 于 2026-04-11 已裁定将原 L3-COM-01(CMU) + L3-COM-02(CBD) + L3-COM-03(CVI) 合并为统一的 **L3-COM（佣金全链路管理）**，但 dim_process 中四者仍并存，导致：

1. **L4 重复定义**: 同一职能被定义多次（如"政策接收"在 COM-01 和 CMU-01 中重复）
2. **编码体系混乱**: CBD/CMU/CVI 的 L4 编码与 COM 不连续，且语义重叠
3. **RACI 分散**: 责任人无法确定是挂在 COM 还是 CBD/CMU/CVI 下
4. **交付物空洞**: CBD/CMU/CVI 的交付物名称与 L4 名称完全重复，无独立物理资产

### 1.2 数据一致性缺口

| 缺口 | 说明 | 影响 |
|---|---|---|
| 源头 PDF 无 OCR | EFA003-A 确认 D1=0 分，全部手工录入 | 误差率 15%，耗时 2h×4次/月 |
| 双轨道校验 SPOF | 刘敏然一人执行交叉检验，已弱化 | 人员变动时校验失效 |
| IA 合规无拦截 | FIN003-A 确认超标已付款不可追回 | IA 合规风险极高 |
| 收款映射无版本 | DIM_PAYEE_MAPPING 变更无留痕 | 追溯困难 |
| FIC 双倍计算 | Commission plan+license call 组合不唯一 | 佣金支出错误 |

### 1.3 端到端链路缺口

dim_process 中 COM 仅定义到 L4-COM-09，但调研显示实际业务需要：
- **COM-10**: 保单信息整合与应收核算（Cici 录入→JoJo 匹配→娜娜复核）
- **COM-11**: 银行到账确认与实收对账（永明等保司账单→实收拆分）
- **COM-12**: 应派金额拆分与渠道对账（Excel 手工拆分）
- **COM-13**: 实派清单确认与财务制单（财务手工制单）

> 当前链路：接收→拆解→外发（COM-01~03）**缺失** 应收→实收→应派→实派（COM-10~13）

## 二、L3 变更建议

### 2.1 L3-CBD / L3-CMU / L3-CVI → 废弃（deprecated）

**变更理由**:
1. Mark 已裁定合并，当前并存状态与裁定冲突
2. 两份规则清单（EFA003-A/FIN003-A）均未独立引用 CBD/CMU/CVI
3. D1 价值节点清单未映射 CBD/CMU/CVI
4. CBD/CMU/CVI 的自动化评分显著低于 COM（CMU-01=3 vs COM-01=12）

**变更内容**:

| 原 L3 | 原 L4 | 处理方式 | 新归属 |
|---|---|---|---|
| L3-CBD | L4-CBD-01 永明源头佣金差异化拆解 | 降级为 COM-02 配置变体 | L4-COM-02-永明 |
| L3-CBD | L4-CBD-02 拆解结果合规验证 | 降级为 COM-02 子步骤 | L4-COM-02-验证 |
| L3-CMU | L4-CMU-01 永明保司佣金政策接收与校准 | 降级为 COM-01 配置变体 | L4-COM-01-永明 |
| L3-CMU | L4-CMU-02 佣金政策标准化分发 | 降级为 COM-01 子步骤 | L4-COM-01-分发 |
| L3-CVI | L4-CVI-01 永明与非永明佣金多源整合验证 | 归并至 COM-03 | 并入 L4-COM-03 |
| L3-CVI | L4-CVI-02 佣金标准化外发 | 归并至 COM-03 | 并入 L4-COM-03 |

> **配置变体说明**: 不新增独立 L4，在 COM-01/02 的交付物中增加"保司类型"字段（永明/太平洋/周大福/万通/其他），由同一 L4 统一处理。

### 2.2 L3-COM → 补充 L4-COM-10~13

**变更理由**: 调研 COM_V2.0 显示应收/实收/应派/实派四个步骤实际存在且有明确交付物，dim_process 缺失导致端到端不完整。

| 新增 L4 | L4 名称 | 交付物 | 责任人 | 说明 |
|---|---|---|---|---|
| L4-COM-10 | 保单信息整合与应收核算 | 《应收明细清单》 | Cici（录入）/ JoJo（匹配） | 原无 L4，实际存在 |
| L4-COM-11 | 银行到账确认与实收对账 | 《实收清单》+《差异对照表》 | 财务(A) | 原无 L4，实际存在 |
| L4-COM-12 | 应派金额拆分与渠道对账 | 《应派清单》+《理财师对账单》 | 蔡依娜 / 中台支持 | 原无 L4，实际存在 |
| L4-COM-13 | 实派清单确认与财务制单 | 《实派执行表》 | 财务 | 原无 L4，实际存在 |

**端到端链路完整化**:
```
保司PDF/Excel → COM-01 接收与校准 → COM-02 拆解与验证 → COM-10 应收核算
                                                        ↓
实收数据 ← COM-11 实收对账 ← 银行流水/保司账单
            ↓
        COM-12 应派拆分 ← 协议参数/权益规则/基本法
            ↓
        COM-03 整合与外发 → COM-13 实派制单 → 付款执行(COM-14/15)
```
