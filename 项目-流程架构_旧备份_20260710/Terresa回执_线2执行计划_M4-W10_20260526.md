## 三、L3 流程蓝图执行方法

**每个蓝图生成步骤：**

1. 从 `L3与价值流全量分析汇总表` 取该L3的价值流阶段与价值活动数量
2. 从 `L4_核心交付物全量表_v5` 筛出该L3下所有L4及核心交付物
3. 从 `L3_L4完整性审计表_v5` 取L4溯源和当前状态
4. 按标准模板填写：触发条件 / 输入物 / 关键步骤（≤7步）/ 判断节点（≥2个）/ 输出物 / L4拆解表

**W1 优先顺序（VS-1 保司投放，7个L3，按价值流阶段顺序）：**

| 编码 | 名称 | VS阶段 |
|------|------|--------|
| L3-IAO | 保司合作接洽与评估 | VS1-S1 |
| L3-IAC | 保司授权与合作框架 | VS1-S2 |
| L3-IRI | 保司资源整合与深度对接 | VS1-S3 |
| L3-IBE | 保司业务运营赋能 | VS1-S4 |
| L3-IPI | 保司产品上架与业务运营 | VS1-S5 |
| L3-IMF | 保司市场反馈与数据回流 | VS1-S6 |
| L3-IRR | 保司绩效评估与续约决策 | VS1-S7 |

VS-1 完成后，从 VS-2（机构合作）按阶段顺序补齐 3 个，达到 CP1 的 10/25。

**产出路径：** `02_过程成果-工作产出/L3流程库/流程蓝图_{L3编码}_{L3名称}_V1.0.md`

## 四、L4 交付物桥接表执行方法

**新桥接表字段（任务书要求）：**

```
L4编码 | L4名称 | 交付物名称 | 主责岗位 | 协作岗位 | 关联数据表 | 产出频率
```

**生成步骤：**

1. 从 `L4_核心交付物全量表_v5` 筛出 KA线（L3-KAOP/L3-KAM/L3-CBD等）和佣金线（L3-COM/L3-SSVA等）共约 60 条
2. 对照 `交付物桥接_L4岗位桥接表.csv` 补充主责/协作岗位
3. 对照 FCT_ 表设计方案补填"关联数据表"列（如 FCT_COMMISSION / FCT_POLICY）
4. 根据 L4 性质判断产出频率（日/周/月/事件驱动）

**产出路径：** `02_过程成果-工作产出/L4-核心交付物/交付物桥接_KA线佣金线_V1.0.csv`
