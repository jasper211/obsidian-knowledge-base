## 二、核心架构前提

### VS-4战略地位
- 代理人事业部APE占比**36.25%**,是最大业务单元
- 是"**人效400万→800万**"战略目标的主要载体
- VS-4在M1之前**完全没有L3覆盖**,M1第一次系统化流程化

### 四层运营体系(来自代理人事业部线索挖掘方案.docx)
```
HQ/交付团队 (事业部总部)
    ↓
分公司 (地区经营)
    ↓
团队长 (直接督导)
    ↓
理财师 (执行层)
```

### 基本法驱动
所有VS-4的L3都围绕"基本法"节奏:
- 月度考核
- 季度晋升
- 年度评估

### 双主体分离(管理公司 × 牌照公司)
- 管理公司(NGM/NGA): 劳动关系 + 培训 + 招募
- 牌照公司(UNIWIN/DW): 监管资格 + 合规 + 销售授权
- 联合评审机制(管理公司40% + 牌照公司60%, 牌照公司一票否决)

## 三、逐条L3评审要点

### S1: L3-FLM 理财师线索挖掘与招募

**V0核心**: HQ策略制定 → 分公司动员 → 多渠道获取 → A/B/C分级 → 月度复盘

**请评审**:
- [ ] "12项核心动作RACI"(来自线索挖掘方案.docx)是否准确映射
- [ ] A/B/C分级标准(基本法潜力评估)是否清晰
- [ ] 三渠道(转介/数字化/线下)比例是否合理
- [ ] 跨区域线索调拨机制的合规边界

**关键问题**:
- 简道云CRM的具体字段是什么? (Carrie对接)
- 线索获取成本(CPL)的基准数据?
- 转介奖励与"被转介人6个月存活"挂钩如何执行?

---

### S2: L3-FOB 理财师入职与合规配置

**V0核心**: 合同签署+基本法归属 → 背景调查+合规培训 → 牌照挂靠备案 → 系统配置 → 就绪Checkpoint

**请评审**:
- [ ] 管理公司与牌照公司的职责分离是否清晰
- [ ] 4项入职任务(合同/合规/牌照/系统)并行执行机制
- [ ] 7个工作日入职周期目标的合理性
- [ ] 基本法归属的上浮授权空间(团队长3%/分公司5%/HQ10%)

**关键问题**:
- 现有双主体分离的具体合同结构?
- 合规一次通过率的实际基线?
- 入职6个月存活率数据?

---

### S3: L3-FTR 理财师基础培训与商考

**V0核心**: 分级培训路径 → 理论课程 → 实战沙龙 → 商考认证 → 进入首单陪跑

**请评审**:
- [ ] 按A/B/C分级的培训深度差异
- [ ] 14天培训周期(7天理论+5天实战+2天商考)的合理性
- [ ] 讲师认证制度
- [ ] 商考题库季度更新机制

**关键问题**:
- 现有培训课程体系的完整度?
- 商考通过率的历史基线?
- 补训与退出机制是否已实施?

---

### S4: L3-FOR 理财师首单陪跑(五个动作) 🔴 **最重要**

**V0核心**: "五个动作"法 = 培训 → 商考 → 沙龙 → 陪访 → 签单

**V0结构**:
- KN1 陪跑计划+冷启动客户资源
- KN2 沙龙组织与客户触达
- KN3 1对1客户陪访
- KN4 方案定制与促成
- KN5 首单结算与评估

**请逐节点评审**:
- [ ] 五个动作的SOP完整度
- [ ] "陪跑双签"机制(理财师+交付经理双方签名)
- [ ] 冷启动客户池的来源与分配规则
- [ ] 交付经理-理财师90天绑定机制
- [ ] 首单12个月继续率追溯奖金机制

**关键问题**:
- 交付经理的人力资源配置? (1:N 比例)
- 冷启动客户池的月度规模?
- 首单APE门槛(当前V0设定≥2万)是否合理?
- 90天首单达成率目标≥70%是否可行?

### S6: L3-FPG 理财师晋升裂变与权益兑现 🔴 **战略核心**

**V0核心**: 基本法晋升评估 → 晋升仪式 → 权益兑现(调L1-05理财师权益) → 团队裂变支持 → 效果回看

## 四、结构性开放问题 (必须问,基于M1复盘)

### Q1 6阶段完整性

- **理财师个人IP打造/自媒体运营**?(参考"自媒体营销策略打法.pdf")

- 理财师离职/流失管理是否应有独立流程?
- "**内部转岗**"(从理财师到团队长、分公司负责人)是否独立?

- "12项核心动作RACI"是否有执行度量?

### Q3 基本法与权益兑现的联动

### Q4 代理人事业部与其他业务线的关系

### Q5 M1未抓到的VS-4真相
