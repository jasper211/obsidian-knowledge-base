## 一、项目背景与Agent目标

**系统目标**：输入任意岗位名称或工作场景，自动输出全维度架构分析报告（M0-M8战略层、L1-L5流程层、KPI、成长路径、Agent化程度）。

**Agent的角色**：用AI替代人工完成数据维护、报告生成、洞察推理三个环节，最终实现"AI执行+人决策"的工作模式。

**三阶段路线**：
```
第一阶段（现在）：数据底座建设 → 人工主导，Agent辅助
第二阶段（数据稳定后）：报告生成 → Agent主导，人审核
第三阶段（M4）：Agent自动化 → Agent执行，人决策
```

## 四、协作模式

### 整体：Plan-and-Solve
任务链路已知，规划层（我 Claude.ai）制定任务顺序，VS Code执行，你决策关键节点。Teresa架构上线后，规划层可由Orchestrator Agent接管。

### 局部：Multi-Agent
```
数据维护协作链（并行触发型）：
源文件更新 → A3增量感知 → A0溯源验证 + A1数据修复（并行）→ A4版本管理

报告生成协作链（串行调用型）：
用户输入 → B-RPT（岗位识别→数据组装→报告渲染）→ Teresa界面 → B-INT（追问）

全局报告协作链（聚合型）：
管理层触发 → B-GRP聚合FACT_CARD → 全局报告 → B8反馈回写
```

### 执行层：Toolformer
每个Agent内部调用SQL/文件工具时，严格按JSON Schema输出，稳定可复现。
