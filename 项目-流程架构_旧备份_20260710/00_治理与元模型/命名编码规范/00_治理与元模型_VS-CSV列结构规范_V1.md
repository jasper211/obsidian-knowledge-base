# VS-*.csv 列结构规范 V1

> 文档类型: 数据规范(schema)
> 产出日期: 2026-04-11 (M2 Week 2 A-14)
> 适用范围: 所有 `02_架构全景/A_业务架构/A2_价值流全景/VS-*.csv` 文件
> 依据: M1 F-02 裁定(旧10列格式obsolete,新框架需新规范)
> 权威性: M2生效,所有VS价值流CSV必须遵守

---

## 一、背景

### 为什么需要新规范
- M1 F-02 裁定: 旧的"4个价值流补全至10列格式"规范已废弃
- 原因: 旧规范基于错误的价值流层级(价值流/价值阶段/价值活动矮了一层)
- M1 D-04后,权益架构修正,L1-05横切能力引入,CSV需要体现"消费L1-05能力"的标注
- M1 E-06后,VS-1扩展为7阶段,需要支持阶段数的灵活性

### 设计原则
1. **层级命名对齐**: 严格按"价值流→价值阶段→价值活动"三层
2. **外部性强制**: 每个VS必须标注利益相关者且必须是外部角色
3. **横切能力关联**: 可标注每个阶段"消费的L1-05能力"
4. **L3关联明确**: 每个价值阶段关联对应L3编号
5. **可扩展**: 支持阶段数灵活(VS-1有7,VS-3有7,其他可变)
6. **可validate**: 结构必须可被validate_kb.py检查

---

## 二、VS-*.csv 标准列结构

### 必填列(10列)

| 列号 | 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|------|
| 1 | VS编号 | string | 价值流编号 | VS-1 / VS-2 / VS-3 / VS-4 / VS-5 |
| 2 | VS名称 | string | 价值流全称 | 保司资源投放旅程 |
| 3 | 利益相关者 | string | **必须外部**,通过外部性检验 | 保险公司 / TOB机构 / KA/TOA / 理财师 / 终端客户 |
| 4 | 触发条件 | string | 价值流的触发事件(外部) | 保司评估MGA合作机会 |
| 5 | 价值阶段编号 | string | 阶段序号 | S1 / S2 / ... / S8 |
| 6 | 价值阶段名称 | string | 阶段描述 | MGA评估与接触 |
| 7 | 价值活动 | string | 阶段内的原子活动(多个) | 保司战略评估MGA模式可行性; 平台展示5大核心价值主张;... |
| 8 | 直属L3 | string | 该阶段的主要L3(可多个) | L3-IAO |
| 9 | 消费L1-05能力 | string | 该阶段消费的横切能力L3(可选) | L3-SRA, L3-RPD |
| 10 | 阶段退出条件 | string | 阶段完成标志 | 签署MGA授权合同并完成监管备案 |

### 可选列(3列,用于丰富)

| 列号 | 列名 | 类型 | 说明 |
|------|------|------|------|
| 11 | 价值交付物 | string | 阶段结束时的可视交付物 |
| 12 | KPI | string | 阶段级度量指标 |
| 13 | 备注 | string | 特殊说明/风险/依赖等 |

## 三、外部性检验规则(第3列强制验证)

### validate_kb.py 应检查:
1. 第3列(利益相关者)的值**必须**在合法外部角色清单内:
   - 保险公司 / 保司
   - TOB机构 / 经代机构 / 家办 / 同行经代
   - KA / TOA / 个人IP
   - 理财师 / 代理人
   - 终端客户 / 客户
2. **禁止值**: "中台"、"支撑组织"、"业务中台"、"业务部门"(这些是内部,违反外部性)

### 违反则:
- validate_kb.py 抛出错误
- CSV不允许提交
- 需要改命名或重新归属(可能应该是L1-05横切能力,不是VS)

## 五、命名规范

### 文件命名
```
VS-1_保司资源投放旅程.csv
VS-2_机构合作伙伴旅程.csv
VS-3_KA上架旅程.csv
VS-4_理财师发展旅程.csv
VS-5_终端客户服务旅程.csv
```

### 阶段编号
- 格式: `S数字` (S1, S2, ..., Sn)
- n 可以是任意正整数
- **不强制固定阶段数**(VS-1是7, VS-3是7, VS-4是6, VS-5是8, 其他可变)

### 价值活动编号(可选)
- 如果需要细分到价值活动编号,可以在第7列内用序号:
  - `1. 保司战略评估; 2. 展示5大价值主张; 3. ...`
