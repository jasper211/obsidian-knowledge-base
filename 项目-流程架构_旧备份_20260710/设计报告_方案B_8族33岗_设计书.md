# 方案B：8族33岗 — 岗位族设计书

> **版本**: v1.0 | **日期**: 2026-04-30 | **基于**: T1数据底座(82 L3 / 400 L4) + HR组织架构V4深度拆分  
> **核心策略**: 打破L1价值链边界，按业务职能重组族结构，实现对HR部门1:1对齐

---

## 一、搭建逻辑

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **族≈HR部门** | 族结构精确对齐HR组织架构的二级部门，实现1:1映射 |
| **职能拆分** | 方案A的重族(JF-03 17L3)按子域拆为独立族 |
| **消除跨职能族** | 拆解方案A的JF-07(KA跨职能族)，KA L3并入渠道族 |
| **L3迁移** | 15个L3需跨族迁移，重新建立桥接关系 |

### 1.2 与方案A的核心差异

```
方案A: L1价值链主轴 → 7族 → 岗位揭示内部分层（零迁移）
方案B: 业务职能重组 → 8族 → 族级精确对齐HR部门（15个L3迁移）
```

### 1.3 三层关系

```
部门（管理维度）  → 谁向谁汇报       HR有14个二级部门
岗位族（能力维度）→ 做什么事、需什么能力  本方案8个族
岗位（执行维度）  → 具体谁来做、做什么   本方案33个岗位
```
