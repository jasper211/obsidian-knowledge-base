## 四、L1-L5层级体系速查

```
L1（5个）: 企业价值链一级域
  ├── L1-01 战略规划与资源投放
  ├── L1-02 销售网络与市场深耕 ← KA/经代主要归属
  ├── L1-03 运营反馈与路由决策 ← 评估/合同/决策环节
  ├── L1-04 能力赋能与增长驱动 ← 赋能/培训/HR
  └── L1-05 价值增值与生态绑定 ← 权益/服务/生态

L2（若干）: 二级能力域
  例：L2-02.3 市场深度运营 / L2-03.4 决策分发与效果评估

L3（~39个）: 核心业务流程 ← 你日常工作的主要层级
  KA: 7个（KAEC→KAET→KASC→KAOP→KAEM→KAOE→KAGA）
  经代: 15个（IBEC→IBRD→...→BSRV）
  权益中台: 17个（CDA→OBC→...→SPO）

L4: 子流程/阶段
  例：L4-KAET-01 画像描述 / L4-KAET-02 需求分析

L5/OP: 经营活动（最细粒度）
  例：OP-KAET-01 "KA完整信息收集（背景调查）"
```
