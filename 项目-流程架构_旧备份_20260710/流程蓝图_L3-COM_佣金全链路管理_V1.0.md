## 三、端到端L4链路

### 3.1 主链路

```
保司PDF/Excel/邮件（季度，永明/太平洋/周大福/万通等）
        │
        ▼
[COM-16] 佣金数据导入与格式转换（PDF→Excel，待注册）
        │
        ▼
[COM-01] 佣金政策接收与校准 ──→ 《标准化政策库》
        │
        ▼
[COM-02] 差异化拆解与验证 ──→ 《各细分市场配置》
        │
        ▼
[COM-10] 保单信息整合与应收核算 ──→ 《应收明细清单》（待注册）
        │
        ├── 银行流水 + 保司账单
        ▼
[COM-11] 银行到账确认与实收对账 ──→ 《实收清单》+《差异对照表》（待注册）
        │
        ├── 协议参数(DIM_PAYEE_MAPPING) + 权益规则 + 基本法
        ▼
[COM-12] 应派金额拆分与渠道对账 ──→ 《应派清单》+《理财师对账单》（待注册）
        │
        ▼
[COM-03] 佣金整合与外发 ──→ 《佣金外发凭证》
        │
        ▼
[COM-13] 实派清单确认与财务制单 ──→ 《实派执行表》（待注册）
        │
        ▼
[COM-14] 财务付款执行 ──→ 银行转账回执 / 支票存根（待注册）
        │
        ▼
[COM-15] 付款回执归档与台账更新 ──→ 转介费派发确认台账（更新）（待注册）
```
