**DIM_DELIVERABLE 补充说明**：

> CREATE TABLE DIM_DELIVERABLE (
>     deliverable_key     SERIAL PRIMARY KEY,
>     deliverable_type    VARCHAR(30),   -- 交付物类型（合同/报告/数据表/凭证等）
>     deliverable_category VARCHAR(20),  -- 大类（文档/系统记录/签字文件）
>     l4_code             VARCHAR(20),   -- 关联L4编码
>     vs_code             VARCHAR(10)    -- 关联价值流

> ```
