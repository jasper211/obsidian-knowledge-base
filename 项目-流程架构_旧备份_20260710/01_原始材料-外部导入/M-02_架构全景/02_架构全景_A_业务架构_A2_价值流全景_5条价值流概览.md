## 一、S2B2A模型与价值流全景

```
              [VS-1 保司资源投放旅程]
                      │
              保司 ──授权──▶
                      │
                      ▼
          ┌────────────────────┐
          │  S = 平台/中台     │  ← 4个正反馈闭环(L1-03)
          │  MGA + 三大支柱    │
          │  (业务中台+支撑    │
          │  组织+服务平台)    │
          └──┬──────┬──────┬───┘
             │      │      │
    [VS-2]   │  [VS-3]  [VS-4]

             │      │      │
             └──┬───┴──────┘
                │
                ▼
          [VS-5 客户权益服务旅程]
                │
                ▼
             终端客户
```

- VS-5从"客户权益服务旅程"重命名为"终端客户服务旅程"，反映权益只是其中一种价值载体

## 三、各价值流的阶段与L3映射

### VS-1 保司资源投放旅程 (E-06后扩展为7阶段)
**利益相关者**: 保险公司 (永明/国寿等)  
**触发**: 保司评估MGA合作机会  
**交付**: 保司通过MGA获得市场渗透+运营能力交付+成本降低+市场洞察  
**核心价值定位**: MGA不是渠道合作，是"替保司运营半个业务"——获取深度授权 + 整合保司资源 + 营销/销售/培训全面赋能

| 阶段 | 名称 | L3编号(V0) |
|------|------|-----------|
| S1 | MGA评估与接触 | L3-IAO 保司合作接洽与评估 |
| S2 | 授权与合作框架 | L3-IAC 保司授权与合作框架(含分销/定价/创新权谈判) |
| **S3** | **资源整合与深度对接** | **L3-IRI 保司资源整合与深度对接** |
| **S4** | **业务运营赋能** | **L3-IBE 保司业务运营赋能** (含L4-MKT营销/L4-SAL销售与场外支持/L4-TRN一线培训) |
| S5 | 产品上架与业务运营 | L3-IPI 保司产品上架与业务运营 |
| S6 | 市场反馈与数据回流 | L3-IMF 保司市场反馈与数据回流 |
| S7 | 绩效评估与续约决策 | L3-IRR 保司绩效评估与续约决策 |

### VS-5 权益服务企业客户旅程 (G4-1 Mark重命名 2026-04-11)
**利益相关者**: 企业级客户(家办/企业/保司大客户部/其他采购方) — 注意:**非VS-2联合运营机构**
**触发**: 企业客户主动请求采购权益服务包 或 销售线索成熟
**交付**: 企业客户获得定制化权益服务方案(含旅游/咨询/活动/规划等)

**VS-2 vs VS-5 边界明确** (G4-1裁定):

### L1-01 新增能力域: 保险产品运营管理 🆕 (G2-新Mark裁定)

**背景**: G2裁定中Mark发现"产品管理"在L1-05和L1-01可能歧义。L1-05特指权益产品,而**L1-01需要独立的"保险产品运营管理"能力域**,避免保险产品相关动作分散在VS-1/L3-MSI/L3-COM等处无法聚合。

**归属**: L1-01 MCV战略与方案赋能 内部能力(与L1-05权益中台形成对称)

**定位差异**:
- L1-05权益产品管理 = 权益套餐设计/生命周期
- **L1-01保险产品运营管理** = MGA作为运营方管理保险产品在平台上的全生命周期(不做精算,做运营)

**能力域范围**:
- 保险产品引入与上架评估(跨保司,不是单个VS-1实例)
- 保险产品组合管理(portfolio level)
- 保险产品适销性管理
- 保险产品业绩与ROI监控
- 保险产品退市决策与善后
- 保险产品合规备案管理

**与现有L3的关系**:
- 现有 L3-IPI (VS-1 S5) 属于保司旅程的单实例,是"一个保司一个产品的上架"
- L1-01新能力域管理的是"所有保司所有产品的组合运营"
- **M2后续需新建L3**(预留,类似与L1-05对称):
  - L3-IPS 保险产品引入评估(待建)
  - L3-IPM 保险产品组合管理(待建)
  - L3-IPR 保险产品退市管理(待建)

**状态**: M2 Week 2 架构补充,L3待建(Park到M2 Week 3)

## 四、消失的构件与去向

| 原构件 | 新归属 | 理由 |
|--------|--------|------|
| 5大"价值体系"(MORM等) | 解构为5条价值流 + L1内部能力 | BIZBOK/TOGAF无此概念 |
| SMPS(细分市场深耕) | L1-02的内部能力分解 | 利益相关者是"支撑组织"=内部,违反外部性 |
| MDF(反馈市场需求) | L1-03的内部运营框架 | 利益相关者是"业务中台"=内部,违反外部性 |
| PACE(经代机构能力提升) | 归入VS-2 S6(能力持续提升) | 是机构旅程的子阶段 |
| CESV(客户体验优化) | 归入VS-5 S5~S8 | 是客户旅程的服务交付阶段 |
| 佣金价值流 | L1-02/L1-03的内部结算能力 | 非独立利益相关者旅程 |
| 18条"价值流"(洞察市场需求等) | 降级为价值阶段 | 层级命名矮一层 |
| 70个"价值阶段" | 降级为价值活动 | 层级命名矮一层 |
