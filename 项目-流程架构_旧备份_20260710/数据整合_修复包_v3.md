### FIX-03：agent_type改为4值

**来源**：`L4_核心交付物全量表_v5.csv`的M2_Tier字段

4值定义（来自文件实际数据）：

| 值 | 含义 | 文件中对应 |
|----|------|---------|
| `Auto` | 规则引擎全自动，无需人工 | M2_Tier=Auto |
| `Aug` | Agent主导+人工审批（Augmented） | M2_Tier=Aug |
| `Hybrid` | 人工主导+Agent辅助 | M2_Tier=Hybrid |
| `Human` | 纯人工，不引入Agent | M2_Tier=Human |

```sql
-- 备份
CREATE TABLE dim_agent_capability_backup
    AS SELECT * FROM dim_agent_capability;

-- 从m2_tier还原（m2_tier是业务评审原始值，优先级最高）
UPDATE dim_agent_capability
SET agent_type = m2_tier
WHERE m2_tier IN ('Auto','Aug','Hybrid','Human');

-- 验证（应与L4_核心交付物全量表_v5.csv的M2_Tier分布一致）
SELECT agent_type, COUNT(*) FROM dim_agent_capability
GROUP BY agent_type;
-- 参考：Auto(约77) Aug(约108+) Hybrid(约176) Human(约39)
-- 具体数字以文件实际为准

-- 枚举合规检查
SELECT DISTINCT agent_type FROM dim_agent_capability
WHERE agent_type NOT IN ('Auto','Aug','Hybrid','Human');
-- 目标：0条
```
