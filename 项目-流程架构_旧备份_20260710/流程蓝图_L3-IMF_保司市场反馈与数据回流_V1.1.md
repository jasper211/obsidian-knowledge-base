## 三、关键步骤（5步）

```
步骤1：数据采集与质量校验
  └─ 执行L4-IMF-01：数据管道自动采集+校验 → 输出《各保司数据集》（Auto）
  └─ 执行L4-IMF-13：多保司数据对比授权确认 → 输出《授权清单》

    【判断节点1】数据质量是否通过校验？
      ├─ 通过 → 步骤2
      └─ 异常 → 执行L4-IMF-10紧急通报 + 返回Carrie修复数据管道

步骤2：分析模型运行与报告生成
  └─ 执行L4-IMF-02：分析模型自动运行 → 输出《分析结果》（Auto）
  └─ 执行L4-IMF-06：实时看板更新 → 输出《实时看板》（Auto）
  └─ 执行L4-IMF-07：定制化报告生成 → 输出《定制报告配置》
  └─ 执行L4-IMF-08：竞品对标脱敏处理 → 输出《对标报告》
  └─ 执行L4-IMF-09：预测分析 → 输出《预测报告》（Auto）

步骤3：报告合规审查与交付
  └─ 执行L4-IMF-03：报告脱敏+合规审查 → 输出《保司报告》
  └─ 执行L4-IMF-04：B族与保司举行沟通会议 → 输出《保司反馈记录》

    【判断节点2】保司是否提出策略调整需求？
      ├─ 是 → 步骤4
      └─ 否 → 进入步骤5数据安全归档

步骤4：策略调整闭环
  └─ 执行L4-IMF-05：整合数据+提议 → 输出《调整建议书》
  ⚠️ 注：《调整建议书》当前实际不存在，无上报模板，蓝图保留框架标记待建设
  → 对接L1-01战略闭环（FCT_POLICY关联）

步骤5：数据安全与反向学习
  └─ 执行L4-IMF-11：合规审计记录 → 输出《合规记录》（Auto）
  └─ 执行L4-IMF-12：数据反向学习沉淀 → 更新《反向学习洞察》
```
