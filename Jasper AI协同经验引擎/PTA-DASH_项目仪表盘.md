# PTA-DASH 项目仪表盘

PTA-DASH_项目仪表盘.py 是 PTA Agent 的一个组件，位于 11_监控与优化_Monitor_and_Optimize/，用于生成以人为中心的项目仪表盘，支持 --project 和 --person 参数（person 可选具体人名或 'all'），显示项目目标、阶段进度、个人任务、关键风险和下一步行动。
