# PTA环境要求

PTA 核心功能仅依赖 Python 3.9+ 和 Git，无需 pip install 任何包。解析 .docx/.xlsx 文件时需要 python-docx 和 openpyxl，缺失时会优雅降级。使用 --daily-scan 或 --discover 功能时需要设置 DEEPSEEK_API_KEY 环境变量。
