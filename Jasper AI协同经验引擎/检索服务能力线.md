# 检索服务能力线

OB Agent 的第二条能力线，为业务 Agent 提供知识检索服务。流程包括：业务 Agent 发起请求 → 判断查询范围/项目 → 混合检索（关键词+图谱+向量 RRF）→ 返回背景上下文包（结构化 dict，非全文）。暴露独立服务接口，PTA 走薄客户端模式，不直接耦合 MCP 协议细节。
