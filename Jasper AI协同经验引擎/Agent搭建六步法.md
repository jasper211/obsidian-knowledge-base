# Agent搭建六步法

Agent搭建必须按六步顺序执行：第1步需求定义（1天）、第2步流程设计（1天）、第3步配置编写（0.5天）、第4步子Agent开发（2-3天）、第5步集成测试（1天）、第6步文档归档（0.5天）。每步有明确输出物和checklist。
