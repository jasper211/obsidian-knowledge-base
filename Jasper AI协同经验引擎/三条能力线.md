# 三条独立能力线

OB Agent 不设计为单一 L3 流程，而是拆分为巡检、检索、概念笔记提炼三条独立能力线。三者触发时机、输入输出、依赖关系完全不同，硬画成一条流程图会互相干扰。三者共享同一套 tools/ 和 memory/workspace.py，但各自独立触发。
