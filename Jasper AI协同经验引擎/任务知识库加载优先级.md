# 任务知识库加载优先级

任务知识库加载顺序：1) --task-map 显式指定文件；2) --project-root 下的 pta_tasks.json；3) PTA 目录自带的 pta_tasks_default.json（兜底）。未定义的任务 ID 会降级为占位步骤，不报错。
