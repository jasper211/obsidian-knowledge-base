# PTA平台无关性

PTA 是一组纯 Python 脚本，通过命令行参数交互，不依赖任何特定 AI 平台或 SDK。任何能执行 shell 命令的 AI 环境（如 Kimi、Codex、Claude、OpenCode）都可以用相同的方式调用 PTA，唯一的平台差异在于触发 shell 命令的语法不同。
