# Agent命名规范

主Agent配置文件名格式为{缩写}_config.json（如VNW_config.json），子Agent配置文件名格式为{主Agent}-{序号}_{名称}.json（如VNW-S01_清单监控器.json），README文件名为{AgentID}_README.md，执行记录文件名为{AgentID}_执行记录.md。
