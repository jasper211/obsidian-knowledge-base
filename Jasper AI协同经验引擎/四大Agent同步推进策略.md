# 三大Agent同步推进策略

VNW、PTA、AIT三大Agent按顺序推进，每个Agent约2周。VNW先完成基础能力，PTA复用VNW部分子Agent，AIT复用VNW信号提取和PTA任务调度。并行策略：W1 VNW需求+流程+配置，W2 VNW开发+测试+归档 + PTA需求+流程+配置，W3 PTA开发+测试+归档 + AIT需求+流程+配置，W4 AIT开发+测试+归档。
