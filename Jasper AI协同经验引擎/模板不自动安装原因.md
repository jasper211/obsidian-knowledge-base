# 模板不自动安装原因

`com.jasper.ob-daily-extract.plist` 故意不自动安装，原因：1. 涉及真实 DeepSeek API 费用，需 Jasper 自己决定是否开始自动跑；2. 模板中的 `DEEPSEEK_API_KEY` 是占位符，需 Jasper 填入真实密钥，不能由 AI 代填。
