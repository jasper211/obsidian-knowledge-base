# 工具链适用场景划分

Python + pandas 适用于 Excel 解析、Markdown 表格提取、数据比对；browser-use MCP 适用于截图证据、网页操作、可视化验证；React + Vite 适用于数据展示草稿；MCP Server 适用于工具化查询接口，复杂业务逻辑应在 Python 中处理。
