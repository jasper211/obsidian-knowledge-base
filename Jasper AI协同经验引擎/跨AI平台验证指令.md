# 跨AI平台验证指令

PTA Agent 提供一组可复制粘贴到任何AI平台（如Kimi、Codex、Claude）的验证指令模板，用于环境验证、单组件测试、完整工作流测试、外部项目分析、故障排查、仪表盘生成、智能分析和自然语言查询。
