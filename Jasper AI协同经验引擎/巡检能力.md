# 巡检能力线

OB Agent 的第一条能力线，负责 vault 健康检查。包含 symlink 完整性检查、MCP 配置一致性检查、MCP Server 连通性检查、F 文件可读性检查、vault 统计、同步完整性抽查六个步骤。支持定时（launchd）和手动触发，输出健康报告到指定路径。
