# PTA 需求边界

PTA Agent 在范围内包括：理解自然语言任务指令、分解任务为可执行步骤、调度子 Agent/脚本执行、监控执行进度并汇报、任务完成后自动同步文档、生成执行记录和复盘。不在范围内包括：不替代用户决策（如技术选型）、不执行需密码/密钥的操作、不修改生产环境文件（只读原则）、不处理非项目相关的通用任务。
