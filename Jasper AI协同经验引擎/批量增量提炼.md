# 批量增量提炼

概念笔记提炼的批量增量模式通过 agent.py --extract-project 触发，按 project_filters.py 的价值分层筛选候选文件，使用 file_diff.py 做增量比对（只处理新增/变更），并通过 atom_embeddings.py 进行语义去重（复用 obsidian-mcp-server 的 embedding 能力，无 API key 时退回精确匹配去重）。
