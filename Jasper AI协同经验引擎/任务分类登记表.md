# 任务分类登记表

task_registry.json 是 PTA-DISCOVER 每次发现任务后按 sha256(来源文件+任务名) 做 key 合并的登记表，同一任务多次出现只更新 last_seen，classification.workstream 自动取来源文件的一级子目录名做轻量分类，但不自动提升为可执行步骤。
