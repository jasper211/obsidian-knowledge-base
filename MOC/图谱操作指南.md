# 🗺️ 图谱操作指南

## 基本操作
- **鼠标拖拽** → 移动画布
- **滚轮** → 缩放
- **点击节点** → 打开该笔记
- **悬停节点** → 预览内容

## 过滤太多节点
1. 图谱右上角 ⚙️ 设置
2. **Filters** → 输入过滤条件（2026-07-18更新为当前schema字段）：
   - `path:EA流程架构项目` → 只看EA项目的知识原子
   - `entity_type:L3流程` → 只看挂了L3编码的原子
   - `authority_layer:"03_已锁定"` → 只看已审核锁定的高权威原子
   - `concept_type:规则` → 只看规则类原子

## 按层级着色
Settings → Graph → Groups，可以按 `entity_type` 或 `authority_layer` 配色分组

## 局部图谱（推荐！）
打开任意笔记 → 右上角三点 → "Open local graph"
只显示当前笔记的1-2级关联，不会太密

## Dataview 查询示例
打开「仪表盘_项目全景」即可看到动态统计表
