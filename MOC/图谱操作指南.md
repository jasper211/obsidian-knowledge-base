# 🗺️ 图谱操作指南

## 基本操作
- **鼠标拖拽** → 移动画布
- **滚轮** → 缩放
- **点击节点** → 打开该笔记
- **悬停节点** → 预览内容

## 过滤太多节点
1. 图谱右上角 ⚙️ 设置
2. **Filters** → 输入过滤条件：
   - `-path:附件索引卡` → 隐藏所有附件索引卡（只看MD笔记）
   - `-type:attachment` → 同上
   - `layer_tag:过程` → 只看过程层
   - `tags:规则` → 只看规则相关

## 按层级着色
Settings → Graph → Groups，已预配置10个层级颜色：
- 🔴 治理 | 🟡 原料 | 🔵 过程 | 🟢 交付 | 🟣 Skill

## 局部图谱（推荐！）
打开任意笔记 → 右上角三点 → "Open local graph"
只显示当前笔记的1-2级关联，不会太密

## Dataview 查询示例
打开「仪表盘_项目全景」即可看到动态统计表
