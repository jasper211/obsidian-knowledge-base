# OB P0回溯与持续更新作业规范

## 窗口与队列

历史批范围为America/Chicago的2026-05-10 00:00:00至2026-11-11 00:00:00（左闭右开，覆盖11月10日）；对应UTC为2026-05-10T05:00:00Z至2026-11-11T06:00:00Z。固定窗口不是文件历史版本快照。首次盘点晚于截止且文件被覆盖时，记录历史版本缺失，不声称还原全部历史。

未来增量从固定截止后接续；首次扫描时记录scan_started_at，每根独立清册。只将mtime小于该扫描开始时间的版本作为本批稳定候选。扫描结束前再次核对候选元数据，有变化则retry。明确UTC/epoch转换，不使用不带时区的日期字符串。

扫描游标scan_cursor与处理游标processed_version分离：扫描成功且文件清单已登记才推进scan_cursor；单项失败保留队列，不因扫描推进丢失。路径+mtime高精度+大小作为观察键；同时间戳重叠查询并按键去重。重命名记新路径候选和旧引用待核，不自动合并；删除仅标missing待核，不删除OB卡。

mtime无法发现人为回拨且大小相同的改写；每月对已接受卡所依赖的允许来源做一次受限摘要复核，远程只返摘要、不下载原文件；这仍不是完整历史审计保证。

## 每批流程与限额

1. 读现行范围和项目规则；项目规则缺失或冲突先hold该项。
2. 元数据初筛先排除P&L/EG、技术/缓存目录和RW远端副本；未知归属、镜像、访问边界先hold。
3. 一轮一个根/主题，初始最多10个MD/HTML候选、总正文片段不超过30000字符；达到限额写剩余队列。超长文按可定位章节拆阅读批，不按字数硬拆知识。
4. 仅对合格内容MD/HTML查定义和引用；技术性MD/HTML排除，混合文件只读明确业务内容。Office等只登记引用，不解析、OCR、计算。
5. 查重和历史原子对照；支持一个可复用定义才候选建卡，允许零卡。没有定义也要记录处置，不产出摘要冒充卡。
6. 源变化先定位受影响引用和关系；逐项区分不影响、需修订、待核、明确替代；不能根据mtime推定替代。
7. 执行者填写回执，核查agent独立核查；退回自行修复，证据不足隔离，业务/权限争议人工升级。核查不可用保持pending。
8. 通过后按主卡契约写索引，做端点/唯一性/版本一致性检查。过程失败回到pending，不假报入库。

## 批次回执模板

每批在`MOC/OB批次/<batch_id>.md`建立实际回执，以下为字段定义而非已发生记录：

| 字段 | 内容 |
|---|---|
| batch_id/root_id/window_utc/scan_started_at/scan_finished_at | 范围及实际扫描时间 |
| source_entries | 每项路径或远程定位、mtime_utc、size、source_id（如已登记）、before/after版本 |
| disposition | analyzed/citation_only/excluded/duplicate/hold/retry；每项理由及证据 |
| project_state/owner/access_scope | 实证或unknown，禁止按目录名填确认 |
| locators/read_chars | 实际章节/行页定位、读取量代理，不把总文件大小当读取字符 |
| cards/relations/legacy_impacts/gaps | 候选和缺口，允许空列表 |
| reviewer/reviewed_version/result/findings | 独立核查对象和版本；修订后旧通过失效 |
| changed_vault_files/checks/published_at | 实际落库变更及验证，未发布null |
| token_usage | 平台数据如可得，否则unavailable，并注明代理口径 |

## 排程与阶段验收

当前heartbeat为PAUSED，仅本轮主动任务执行；不靠改文档恢复调度。若获准恢复，可沿用4小时触发，按变更与待办推进，不保证Mac离线运行。每轮可处理一个有价值批次，无变化即结束。

P0独立通过后P1先检验一份真实版本变更：来源前后引用、变化/不变定义、缺口、旧卡影响均可复核；不要求固定卡数。通过P1后再按服务器在用来源、Agent在用/实验分流、旧EA限定范围扩大。历史回溯和新增变更队列分开统计；源更正/撤回优先于新卡和历史回填。

每周按已分析、仅引用、排除、重复、待核、失败分类汇总；总数能与当批清册核对。先用前两批测实际阅读量、处理量与返工率再估工期，旧本地3680文件/4.5至6个月估算停用。暂无机器自动扫描/校验器上线声明，本规范可由执行与核查agent人工逐批重放。
