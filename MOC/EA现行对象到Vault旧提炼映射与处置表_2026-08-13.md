## 处置口径

本页统一使用 4 类动作：

| 处置动作 | 含义 |
| --- | --- |
| 保留 | 结构仍成立，现阶段可继续使用 |
| 换源 | 页面还能用，但底层依据要切到源项目现行对象 |
| 重提 | 页面主题还重要，但旧提炼单位不再适配现行结构，需要按新口径重做 |
| 退役 | 旧内容已不适合继续作为现行入口 |

## 第一轮总判断

从这第一批映射看，EA vault 旧提炼目前不是“一刀切全部失效”，而是分成了 3 种状态：

### 1. 仍然健康

典型：

- 章程 / OB-GATE 拆分原子
- `L3-COM / L4-COM-*`

特征：

- source 清楚
- 已接现行对象
- 结构仍有复用价值

### 2. 主题没错，但要换源或收口

典型：

- Gate / 熔断 / L3-L4 / KPI / 映射规则相关原子

特征：

- 还能用
- 但必须明确母文件和现行版本

### 3. 需要按新结构重提

典型：

- 交付批次与验证状态类碎片页
- 一部分旧版 D1 / D2 / D3 残留页

特征：

- 用原子句很难表达现行状态机
- 需要回到“对象组”层重新建页
