# 知识枢纽索引

## 一句话定义
573个知识枢纽的入口——把entity_ref/embedding聚类建的hub节点，从"只能被原子反链发现"变成"能从这里主动浏览发现"。之前MOC层完全不知道这些hub存在，2026-07-18补上这一环。

## 两种枢纽
- **正式枢纽**（entity_type=L3流程/价值流/岗位族/KPI）：entity_ref精确匹配的编码，零阈值误判
- **非正式主题枢纽**（entity_type=非正式主题）：embedding聚类(threshold=0.72) + LLM内容连贯性判断过的主题，不是正式编码但内容验证过连贯

## 按entity_type浏览

```dataview
TABLE length(rows) as 枢纽数
FROM "EA流程架构项目"
WHERE contains(file.content, "## 关联原子")
GROUP BY entity_type
SORT 枢纽数 DESC
```

## 全部枢纽（按关联原子数排序）

```dataview
TABLE atom_count as 原子数, entity_type as 类型
FROM "EA流程架构项目"
WHERE contains(file.content, "## 关联原子")
SORT atom_count DESC
```
