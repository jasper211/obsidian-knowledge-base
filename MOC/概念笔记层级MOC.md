## 使用指南

1. **按项目查找**: 从 L1 项目层进入，找到项目相关的所有概念
2. **按方法论查找**: 从 L2 核心方法论层进入，找到跨项目的方法论
3. **按知识管理查找**: 从 L3 知识管理层进入，找到知识管理工具和方法
4. **跨项目关联**: 通过 VNW 和 AIT 两个桥梁 Agent 找到项目间的关联
