# 跨项目关联 MOC

## 一句话定义
跨项目关联 MOC 是**三项目概念网络的跨项目导航枢纽**，通过桥梁 Agent（VNW/AIT/PTA）和共享概念，展示项目间的关联关系。

---

## 三项目全景

| 项目 | 核心目标 | 关键交付物 | 当前状态 |
|------|---------|-----------|---------|
| [[流程架构项目_jasper]] | 价值节点驱动的六层闭环流程治理 | 价值节点清单、流程蓝图、规则空白地图 | Phase 1 进行中 |
| [[RW权益项目]] | RW 权益 Layer B 事业线建设 | 权益资产台账、四对象运营平台 | Phase 0 启动 |
| [[Jasper_AI协同经验引擎]] | AI 工程能力跃迁 | Agent 产品化、Skills 发布 | Phase 1 完成，Phase 2 进行中 |

---

## 桥梁 Agent（3 个）

### VNW → 流程架构项目
- **作用**: 价值节点驱动工作流 Agent
- **输入**: [[价值节点]] + [[流程蓝图]]
- **输出**: [[信号基线]] + [[规则空白]]
- **关联概念**: [[六层闭环]]、[[D1-D4 交付物]]、[[三层递进提取法]]

### AIT → RW 权益项目
- **作用**: AI 协同转型咨询 Agent
- **输入**: [[RW权益项目]] + [[四对象]]
- **输出**: AI 方案 + Agent + SOP
- **关联概念**: [[权益资产]]、[[SKU Pipeline]]、[[MVP]]、[[合规红线]]

### PTA → 通用任务协同
- **作用**: 项目任务协同 Agent
- **服务对象**: 所有三个项目
- **功能**: 自然语言指令解析、执行记录、归档文档
- **关联概念**: 任意项目/任务

## 共享概念（跨项目复用）

### 流程架构 ↔ Jasper AI 协同经验引擎

- [[合规红线]] — RW 权益的架构约束，AIT 的咨询约束

## 跨项目工作流

### 工作流 1：价值节点分析（流程架构 → Jasper AI）
```
价值节点清单 + 流程蓝图 → VNW 分析 → 信号基线 → 规则空白地图 → Mark 裁定
```

### 工作流 2：权益资产咨询（RW 权益 → Jasper AI）
```
部门访谈 + 流程文档 → AIT 分析 → AI 方案 → Agent 设计 → SOP 输出
```

### 工作流 3：任务协同（任意项目 → Jasper AI）
```
自然语言指令 → PTA 解析 → 子 Agent 执行 → 执行记录 → 归档文档
```

### 工作流 4：知识管理（三个项目共用）
```
概念笔记 → 双向链接 → MOC 聚合 → 知识图谱 → 导航发现
```

## 使用场景

1. **跨项目查询**: "价值节点和权益资产有什么关系？"
   → 通过 Jasper AI 协同经验引擎找到关联

2. **Agent 选型**: "这个任务该用哪个 Agent？"
   → 流程架构用 VNW，RW 权益用 AIT，通用任务用 PTA

3. **知识迁移**: "流程架构的方法论能用在 RW 权益吗？"
   → 通过 AIT 进行 AI 转型咨询

4. **全局视角**: "三个项目的整体进展如何？"
   → 通过跨项目关联图查看全局状态
